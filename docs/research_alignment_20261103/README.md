## 2. 本轮最重要的代数等价

设 $H_d(m)=[1+m/d]_+$，锚决策 $B\in\{0,1\}$，$d=\max(|a|,\kappa)$。当前正常逐行代理是

$$B-B\operatorname{clip}(-m/\kappa,0,1)+(1-B)H_d(m).$$

恒有

$$1-\operatorname{clip}(-m/\kappa,0,1)=\min\{1,H_\kappa(m)\},$$

故完整 adaptive 设计可写为

$$U_0=\operatorname{mean}_{Y=0}\big[(1-B)H_d(m)+B\min\{1,H_\kappa(m)\}\big],$$

攻击保留则为

$$U_1=\operatorname{mean}_{Y=1}B H_d(-m).$$

**解释：正常部分是按锚状态选择普通 hinge／截断 hinge，攻击部分是对原 TP 施加 hinge。** “修复信用”是这种代理的一种解释，不是另一个独立学习机制；攻击不抵扣也是 negative-flip 保护的既有含义，不能仅换领域称新原则。

这些表达的数值恒等，非折点梯度也一致；在 $m=0,-\kappa$ 等非光滑折点，不同运算组合的自动微分可能选择不同次梯度。不能将这一实现约定当作新的机制。后续适配应固定同样的折点规则。

[等价核验](../../tests/test_risk_alignment.py)使用固定种子的连续合成 margin，覆盖 fixed／adaptive 和三种 kappa，核对值与非折点梯度；另记录折点次梯度、作者源码形状反例及旧 FP 的零梯度区域。**本轮 9 项检查通过。** 它们是文献／实现对齐证据，不是新增 IDS 实验或创新工作量。

另一个需验证的失效机制：当正常样本本来是锚的 FP（$B=1$）且学生仍报警（$m>0$），正常代理为常数 1，对 $m$ 的风险梯度为零。共同 hard 项仍可推动纠错；但风险项本身不会在误报侧主动把它推过边界，只有进入 $-\kappa<m<0$ 后信用才产生该方向梯度。不能把信用解释成新的纠错发动机，也不能由此断言完整目标无法修复。若 C 初始 FPR 已超预算，必须观察 hard／teacher／risk 各自梯度，而非假定增大 dual 就能修复。

同一等价表达不另算“可超越基线”，也不重复花训练预算。如果两实现的非折点梯度不同，应先查实现；如果相同，就不声称 credit 优于数学上相同的方法。

## 4. 哪些主张保留，哪些下调

| 表述 | 本轮处理 |
|---|---|
| 有具体算法设计、可计算经验代理和候选训练流程 | 保留，由设计／代码／数学检查支撑 |
| 修复信用是一种独立的新损失机制 | 下调：完整式等价于锚条件 hinge／截断 hinge |
| 攻击新 TP 不抵扣旧 TP 丢失是新原则 | 下调：与已有 NFR 保护直接相关 |
| 对偶更新／旧锚＋新教师／组风险约束有首创性 | 不保留；已有直接近邻 |
| 锚尺度、条件预算与特定压缩问题的联合适配有价值 | 仍可研究；尚不能称新的知识迁移机制 |
| 真实低 FPR 退化已解决、v3 已显著提升 | 不保留；没有对应真实结果 |

当前 v3 宜定位为**锚条件受约束蒸馏候选／机制研究原型**。下一步可以验证适用条件和风险取舍，但应先排除成熟目标、旧正确保护和重加权已经解释所有效果的可能，而不是继续叠模块。

## 5. 必要的反证与预算取舍

1. 保留同标签 F∪C 的 hard、无 KD 约束控制、matched-soft、无风险 KD；这些区别是真实不同目标。
2. 加入论文语义的 PCT 逐行加权，以及有依据的双源 FD 二分类适配；不利用源码广播偏差制造弱对手。
3. 在同风险和成本下比较成熟低 FPR 分类目标（例如 CVaR-pAUC）及 adapted EKD；不只比较普通 BCE／KD。
4. 对锚尺度作定向控制：在同标签、同锚决策状态、同风险分层中置乱间隔幅度，保持保护 mask 和尺度分布，检验幅度信息是否必要。随机打乱全部标签／符号会同时改变保护对象，不是同一个问题。
5. 数学等价的 capped-hinge 仅做等价性检查；关闭信用是不同目标，可保留消融，但不能单独证明新机制。
6. 通过开发筛选后再做多 seed、双环境／新来源与真实 CPU 成本。失败或无 KD 足以解释收益时，下调为约束适配／机制实证，不承诺算法创新成功。

这些是后续比较准入，不表示本轮已经运行。真实训练继续在实验室 RTX4090D；本轮未修改算法核心、配置或封存工件。
