# 根本设计审查：课题方向成立，当前贡献构造需要重来

2026-11-04。只读审查正式题目截图、最初项目规划、v2/v3/v4协议与已核验回传结论；未训练、未加载模型、未改变实验或完成标记。本文件审查研究问题与贡献链条，不以修复实现问题代替算法有效性或新颖性判断。

**结论：原来的“轻量化机器学习入侵检测”方向没有被这些负结果推翻，但从起步的贡献假设到后续v3/v4的构造，确实存在结构性问题。** 最初的稳定选择＋冗余过滤只是待验证组合，尚没有足以独立支撑方法创新的机制；后续为加强创新而转向风险预算、旧模型翻转保护和guard，没有先证明这些机制解决了原课题的主要瓶颈。当前不能把“使新门槛通过”当作恢复了论文主线，也不宜把v3/v4继续包装成核心新算法。

## 2. 第一处根本偏差：轻量化预算从活跃变量变成背景标签

原主问题至少有三条活跃轴：原始字段／模型资源预算、低FPR下检测、真实CPU部署成本。v3/v4的主要条件使用同一[32,16]学生和相同全字段输入，新增的是训练目标及接受规则。它们可以研究“同成本学生如何更可靠”，但**不会因为加KD、代理或guard就进一步减少字段、参数或推理成本**。

同结构hard是必要对照，并没有错；错误是让它承担了整个压缩研究。若当前学生已经足够小，仍须回答它相对哪个必要资源更高的参照、在哪个检测容忍度下形成Pareto改善。若不改变预算，只得到0.08pp条件化召回变化且FPR更高，这不能直接补足原课题的轻量化贡献。

此前压缩证据有保留价值：既有复核记录UNSW树模型到小MLP的体积／CPU收益及检测代价、CIC 82→MI24的部署收益。它们来自早期冻结模型，不能拿来证明新KD机制的成本收益，但说明应继续围绕资源取舍研究，而不是把问题换成guard合格率。

**应重建的比较单位：**同一部署预算下hard、成熟低FPR目标与KD的检测差别，以及相同检测容忍度下谁能使用更低的字段／参数／CPU预算。两条比较分别成立，不能用“同结构不变”证明压缩，也不能用“体积变小”回避检测恶化。

## 3. 第二处根本偏差：先规定必须蒸馏，再寻找教师知识的必要性

当前教师是更强归纳偏置的HGB，学生是小MLP；这足以构成合理KD候选，但不自动保证低FPR区域有可迁移优势。三折OOF教师每折只见F的约2/3，而F约占原train的70%，即每折约见原train的46.7%。OOF有防止自身训练行过度自信等合理作用，但也减少教师拟合信息、可能丢失罕见族支持；它不是所有合法KD都必须遵守的唯一形式。其成本与收益应有专门对照，不能把普通训练内教师目标一概称泄漏。

目前还缺三项先决证据：

1. **目标工作点的教师优势。** 教师在相同阈值规则、同一评价总体上的低FPR TPR／pAUC及家族支持；不能用accuracy、整体AUC或平均教师置信度替代。v3完整教师FPR=1还存在float32比较诊断问题，必须先修正这项资格证据。
2. **纠错互补性。** 教师是否能识别学生漏掉、而且不会相应制造大量正常误报的记录？教师总体更强仍可能在学生困难区域犯同样或更多错误；反过来，教师总体不占优也可能有互补信息，不能用单个总体分数一刀切。
3. **学生可表示性。** 若更少字段使正常／攻击在学生可见输入上不可区分，教师的额外观测无法在部署时凭空恢复。KD可改善估计／正则化，但不能给学生增加测试时不存在的信息。只有在明确字段预算后，才能区分缺失信息、容量不足与训练目标不当。

因此，下一项核心审计应是“教师价值与学生瓶颈”，而不只是继续找一个能通过约束的更新。若教师没有目标区域的可靠纠错余量，调β／换KL／加guard只能重新分配已有监督，不能证明获得了新知识。

## 4. 第三处根本偏差：评价目标、蒸馏目标与部署决策没有形成同一条链

实际目标可以写成在资源预算内提高攻击检出、限制正常FPR。普通加权BCE与平均KL是训练代理，优化它们不等于优化1%FPR附近的排序和阈值。需要证明代理与目标的联系，而不是只因loss可微、界有效就认为构造合理。

v3把教师报警margin取sigmoid后放进BCE，在CIC产生正常目标约0.5的退化。这是目标语义及表示构造问题，不能全部归结为学习率或数值bug。v4修正为raw KL是必要控制，但raw KL仍在平均拟合分布；它不能自动解决低FPR尾部问题，也不能凭“恢复正确KL”构成新方法。

冻结旧raw-logit阈值研究的是模型版本兼容性；每候选R重校阈值研究的是另一个部署规则。两个都可以研究，必须事先区分。v4起点失败已显示，固定某个R最低阈值会把“这一阈值不合格”误当成“这一分数模型没有可行阈值”。精确阈值区间能纠正这种错判，但它仍是有限训练池决策分析，不会单独提高分数排序，也不是新的蒸馏机制。

## 5. 第四处根本偏差：把同容量hard参照升级为未论证的业务契约

控制误报有明确检测应用意义，保留关键攻击能力也合理。问题是当前“原锚点任何原TP丢失不得由新增TP抵扣、每个支持族各限1%”这一升级契约，尚无具体部署需求、发布场景或损失代价模型支撑。正式题目没有要求替换某个既有生产版本且逐族非退化。

它会引入额外冲突：一个候选总体低FPR检出提高，但交换少量旧TP与更多新TP，仍被判不可取。若该交换在真实应用不可接受，这种约束有价值；若没有这样的需求，它就在优化一个比原题更窄、可能更难且未必更有用的任务。约束难以满足不等于题目因此更有研究价值。

小家族的整数配额也须解释。Botnet C支持88时，1%实际预算允许丢失0条；支持≥30并不使这个约束变得统计稳定。C没有Portscan等族时，有限池保护不能扩大为覆盖所有攻击。当前CIC的Phase-I失败实际仅由normal触发，不能再以罕见族零容忍解释这一轮失败。

若保留升级主线，应明确部署变更：例如完整模型被更低字段／更低CPU预算模型替换、或者真实时间版本发生变化，再论证哪些旧能力必须保留、为何不能做净收益取舍。同容量同字段的继续训练主要是因果控制，不能单独替代真实压缩替换任务。

## 6. 第五处根本偏差：创新构造从“差异机制”滑向“新增门槛”

最初“稳定性＋冗余过滤”是合理基线候选，但仅组合并不新；v3的修复信用经审查又与已有锚条件截断hinge等价。对偶、PCT式保护、工作点排序、raw KL和后置接受都有直接基础。当前可保留的是适配、失效机制与可审计实证，不能用模块组合恰好没有同名来证明原创。

v4 guard的重复拒绝是工程／优化策略缺陷：停止空转节省成本；调整方向或trust radius可能改善搜索。但“修复自己制造的不可行性／停滞”不能自动成为论文主要算法贡献。合格只是可接受性，不是超过简单hard的价值；尤其两环境计划48、实际16、CIC新条件全未启动时，更不能以合格率变化代替原收益闸门。

已有设计文档对这些限制相当坦诚，这是应保留的研究纪律。但问题在于后续工作往往转向修复新门槛，没有先回到“核心资源取舍是否变好、为何非KD不可”的问题。现在需要重设主线，而不是再给相同结构加一个新的控制器名称。

## 7. 应停止、保留与重构什么

| 处置 | 内容 | 原因 |
|---|---|---|
| 停止作为既定核心贡献 | 风险预算蒸馏／修复信用是新学习原理；guard可行就代表升级有效 | 已有代数等价及方法近邻；效果与压缩增量没有成立 |
| 停止无依据扩展 | 增加相同宏步、继续扩展KD/gate矩阵，直到某个seed过线 | 已证实确定性吸收态；收益和teacher必要性尚未证明 |
| 保留 | 低FPR评价、数据／组身份、真实CPU计时、同监督hard、对照和负结果 | 这些直接服务正式题目且可支撑有效研究 |
| 保留但降为诊断 | 阈值区间、代理间隙、旧TP翻转、guard接受率 | 能解释失败；自身不等于检测／压缩算法创新 |
| 重构 | 资源预算—学生信息瓶颈—教师纠错—目标区域优化—独立确认这一证据链 | 使算法改动有明确必要性与退出条件 |

建议重新冻结的主问题是：

> 在明确的原始字段或CPU部署预算下，压缩学生在低误报区域丢失了哪些可恢复的信息；完整观测／更强教师是否能提供超出同预算hard、标准KD及成熟低FPR排序控制的增量，并形成更好的检测—资源取舍？

这是一个待验证研究问题，不是已经有新算法的声明。若选择完整特征教师／少字段学生，就必须回应学习带特权信息与容量／观测受限蒸馏的直接近邻，不能把“教师多看字段”本身作为原创。若选择模型安全升级，应另行明确真实替换场景与业务契约，避免两个不同主问题相互借用成绩。

## 8. 下一轮应先回答的最少问题

先完成一个“主线是否值得继续”的审计，再决定是否进入新训练矩阵：

1. **资源轴。** 固定一个确有意义的学生预算，明确参照与部署收益；全字段与少字段、较大与较小结构分开，保留同预算hard。不得从CSV列数直接推断PCAP提取成本。
2. **教师轴。** 使用正确的native分数／阈值规则，测教师在目标区域的优势与师生分歧方向。保留原clip目标供解释，不用新teacher悄悄改写旧实验。
3. **可表示信息轴。** 在合法训练角色分析压缩视图中的标签冲突、交互丢失与teacher可纠错区域；把经验不可区分性与容量／优化失败分开，不把训练内碰撞当总体不可识别性定理。
4. **必要简单控制。** 阈值注册修正、hard与成熟低FPR排序先作为强解释；若它们解释全部收益，就将贡献定位为相应方法适配／机制实证，不再宣称KD知识选择创新。
5. **确认轴。** 旧test与多轮已使用的V不能承担新主张的独立确认；在扩大新机制前规划真正未使用来源及输入契约，避免每轮开发均值反复积累成虚假的泛化证据。

历史v2提出的0.5pp、多seed方向和资源晋级要求是开发闸门，不是所有论文通用标准；但不能在看到微小收益后仅降低门槛来保留KD。若改为“检测容忍度下大幅降低资源”，也应重新明示主目标、固定容忍度并进行相应公平对照，而不是拿不同目标互相救场。

**现阶段根本性的改进是重建问题和证据链。** 修阈值、保存失败模型、停止重复拒绝应当完成，但这些完成后仍不能跳过教师价值、压缩收益、近邻差异与新来源确认。只有前提通过，再设计针对性的新目标，才有理由谈更强创新；前提不通过则应换主机制或收缩贡献表述，保留扎实的系统与负结果。
