## 小试提供的研究线索

以下均为**同一有限开发样本、一个seed、20epochs上限**的结果。阈值来自本次validation，实际FPR均为19/1923≈0.9880%。不能与历史全量结果直接排名。

| 条件 | CPU最终开发攻击召回 |
|---|---:|
| hard小MLP | 78.6608% |
| 权重匹配matched-hard | 77.6306% |
| 普通KD | 80.1815% |
| 默认门控KD | 78.6117% |
| hard＋ranking | 76.4778% |
| 大hard MLP | 80.6475% |
| 固定小预算TabM | 65.2686% |

普通KD相对hard为+1.5207pp，相对matched-hard为+2.5509pp，提供了继续分解软目标与类权重的线索。默认gate及ranking未自动胜出，不能将组合复杂度当成收益。许多条件的最佳轮仍在上限20，尤其不能据此认定TabM已经充分训练或劣于MLP；该模型的宽度、成员数、嵌入和调参预算也是本项目适配，不是作者最强配置。

训练设备的逐epoch曲线与CPU重载后的最终开发成绩分开：本次large-hard最佳轮的CUDA曲线为3289/4077检出，CPU最终为3288/4077；分别按各自分数选择开发阈值，FPR都为19/1923。原值和差异保留，现有证据不能单独确定数值原因。正式部署与报告以保存的CPU分数和阈值为准，不能用训练曲线替换。

本次release训练与自动测试存在共享开发条件，`training_seconds`仅是实际运行记录，不属于独占资源性能基准。正式CPU三轮及训练资源比较必须另外按协议测量。
