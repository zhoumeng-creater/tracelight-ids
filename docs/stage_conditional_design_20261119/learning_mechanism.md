# 一致正常解释与局部偏离学习：可实现候选及其边界

2026-11-19。本轮保留一个具体学习机制，作为设计候选：**一条查询连接只能由同一条完整正常参考解释；学习哪些局部偏离值得作为攻击证据，同时把完全相同的正常表示锚定在全局最低分。** 本文不登记训练批次，不作真实模型前向，也不读取 C 或保留来源。

这项设计的可检验变化是正常解释的约束和学习监督的作用位置。min/max、非负条件代价、最近参考和多实例学习本身都不是新数学。若后续同信息的简单完整序列近邻已解释全部效果，就应采用简单实现，不把它包装成额外贡献。

## 1. 依据与要解决的问题

历史 R30 已出现训练中存在的正常计数形态仍持续高分；后续最坏组风险修补没有解决。这里能据此定位的是“已见正常支持没有落实到预测行为”，不能直接断言原因是阶段错配或正常嵌入塌缩。

本轮[共有阶段账本](shared_stage_evidence.json)确认：F 有 503 条 HTTPS 控制（santos 30、Unraveled 473），全部首段的方向及唯一字节量在 F 正常段词表中出现；没有一条控制的全部段均在该词表出现。可作为参考来源的 F 正常 TCP 共 6,840 条，精确方向／唯一字节 profile 为 2,797 种。fox 的 15 条控制前两段与 6 条同 intranet 正常连接完全共享。这支持“不应把控制连接的正标签复制给全部阶段”，并不证明已经找到了各段都正常、组合才恶意的真实样本。

因此本候选同时保留两种预测要求：

- 一个完整正常参考能够解释整条连接时，不因其偏离总体正常中心而报警。
- 不能让各阶段分别从不同正常业务中挑参考，拼出材料中不存在的完整正常解释。

第二项约束相对独立阶段匹配只会提高或保持分数，不能自动降低误报。它保护的是对不一致组合的识别能力；降低正常误报仍依赖真实完整正常参考的覆盖和学习后的局部代价。

## 2. 输入、参考和对齐先独立固定

查询 X=(z_1,…,z_T) 为完整连接的方向交互段。z 保存已经可提取的数值属性；端点、端口、绝对 SEQ/ACK、采集名称和标签不进入局部比较器。分段、方向、变换与可用时刻均先固定，不能由标签反推阶段。

参考库 R 仅由 F 内有整连接正常依据的真实连接构成。保留每条参考的完整有序阶段，不将不同连接的段拼成一个合成参考。训练正常查询时，排除自身及同一物理测量的别名参考，避免用自配恒零掩盖泛化问题。同活动组排除不能机械套用：Unraveled 正常目前有聚合 observation_set，整组排除会把正常匹配改造成无依据的跨来源要求。来源／活动独立性仍按冻结的数据角色约定，不把库内拟合重述为独立泛化。未知连接不进入正常库；攻击低分阶段也不自动扩入正常库。

固定等长、同方向对角匹配只用于原型中分离 min/max 的次序。完整可变长度版本采用同方向的单调编辑路径：允许匹配、查询插入和参考删除；每个阶段必须被匹配或通过带代价的空节点边消耗。方向不相同的两个真实阶段禁止直接匹配，不能按标签改变规则。

空节点增加 presence=0；真实阶段 presence=1。所有 gap 都由同一个非负局部成本计算，分别是 c(z,null) 与 c(null,r)，不凭空增加常数 γ。presence 差异使有限参数下的 gap 成本严格为正，真实数值零也不会被当成缺失。可要求路径至少含一次真实—真实匹配，用一个是否已有匹配的 DP 状态实现。

‘至少一次匹配’只能排除全 gap，不能排除‘匹配共有首段、其余全 gap’。本轮控制流首段普遍在正常词表出现，这个退化必须保留为具体反例。学习可能把 gap 成本压得很低，因而完整覆盖不等于语义上充分解释。本文不再叠加没有业务依据的 gap 比例限制；由同成本的去参考控制、匹配／gap 路径统计检查算法是否实际使用完整正常参考。

## 3. 局部代价及正常全局锚

对阶段 z 与允许匹配的参考阶段 r，令 δ=z−r，使用以下条件代价：

\[
c_\theta(z,r)=\sum_{k=1}^{D}\delta_k^2\,\operatorname{softplus}\bigl(h_\theta(\delta,r)_k\bigr).
\]

h 是小型共享 MLP；方向由匹配约束处理。这个式子学习“在该正常模式附近，哪个数值方向的偏离更值得惩罚”，不要求所有正常模式靠近同一个中心。h 可依赖参考的数值属性，因此 c 不必对称，也不必满足三角不等式。

h 使用带符号的 δ，不能换成 |δ| 后仍声称能区分参考两侧的偏离；后者会强制 c(r+δ,r)=c(r−δ,r)。这个限制与非负性无关。

它有两项直接性质：c≥0；c(z,z)=0。局部学习不能给完全相同的查询与参考产生正的自配代价。这里的正权重和条件度量是已有构造，贡献不能单列为“新的权重层”。

令参考库固定，允许的编辑路径集合为 P(X,R_b)：

\[
S_{\mathrm{joint}}(X)=\min_{b\in R}\min_{P\in\mathcal P(X,R_b)}\max_{e\in P}c_\theta(e).
\]

每条路径覆盖查询和参考，局部边可以是同方向匹配或 presence 明确的 gap。它可以用瓶颈编辑 DP 实现：从每个前驱状态转移时取 max(前驱值,当前边成本)，多个合法前驱之间取 min；另加一位状态禁止全 gap。空路径初值 0，不可达状态为 +∞。若没有合法路径，返回不可用，不输出可比较的数值分数。

这是最能解释整条查询的正常参考及其路径，其最强未解释偏离。若参考库含与 X 完全相同的完整表示，则 S_joint(X)=0；所有其他查询分数也非负。冻结模型后，只要正常校准阈值按非负分数取得且判正使用严格大于，完全相同的正常表示不会成为误报。这是有限的代数保证，不覆盖近邻扰动、同四个原始计数但不同阶段的连接、或没有参考的正常业务。

训练用 logit=α S_joint−β，其中 α>0；不把非负 S 直接当无偏置 logit，否则正常概率不能低于 0.5。校准可保存 S，或保存冻结后的仿射 logit；两者的排名一致，整体最低点分别为 0 和 −β。

先前考虑过有符号比较器 e(z,r)=MLP(z−r)−MLP(0)−b。它虽满足 e(z,z)=−b，却允许其他正常分数小于 −b，校准阈值也可能更低；因此不能由自配 −b 推出正常不告警。把它改成奇函数还会错误地要求相反偏离方向互为相反证据。正式候选采用上面的非负成本，有符号版本仅作为被反例排除的设计记录。

## 4. 它相对独立阶段原型确实改变了什么

在等长对角版本中，最直接的同信息对照使用完全相同的 c、参考库和对齐，但允许每个阶段独立找正常解释：

\[
S_{\mathrm{independent}}(X)=\max_i\min_b c_\theta(z_i,r_{b,i}).
\]

在上述相同匹配域中有 S_joint≥S_independent，并且可以严格不等。可变长度 DP 的独立控制必须使用对应的放松路径域，不能未经推导把简单矩阵不等式直接推广给不同路径算法。例如两个完整正常参考与查询的阶段代价为：

```
             阶段 1   阶段 2
正常参考 A      0        1
正常参考 B      1        0
```

独立匹配给出 0；一致参考给出 1。这是非等价预测偏置。它表示各阶段分别正常，不足以构成同一个完整正常业务的解释；这个小矩阵没有被当成真实攻击证据。

同样必须保留反例：若合法正常业务确实可由两个旧模式组合而成，一致约束也会提高其分数。所以候选不会把“组合新颖”定义为恶意标签，而是让完整正常连接的监督决定哪些偏离应低成本。若正常组合没有覆盖，方法仍可能失败。

若 c 固定为欧氏距离且采用同位置匹配，这就是完整模板的瓶颈最近邻；若允许路径，则接近瓶颈 DTW／离散 Fréchet 结构。不能通过改名否认这个等价近邻。可学习部分必须相对该固定度量控制提供额外价值；一致解释部分必须相对同一学习成本的独立原型控制提供额外价值。

## 5. 监督、梯度与不可识别性

只采用已可靠标注的完整连接二元标签：

\[
L(\theta,\alpha,\beta)=\sum_{X\in F}\operatorname{BCEWithLogits}(\alpha S_{\mathrm{joint}}(X)-\beta,y_X).
\]

所有方法使用相同 F 标签、自身／同测量别名排除和既定类别采样规则。没有新增阶段标签、阶段真值、伪正常池或隐含主机标签。这里只给目标函数，不根据结果追加损失系数矩阵。

在最优参考 b*、最优路径和最大成本边 i* 唯一的点，梯度为：

\[
\nabla_\theta L=(\sigma(\alpha S-\beta)-y)\alpha\nabla_\theta c_\theta(e^*).
\]

局部 h 的梯度还含 δ_k² sigmoid(h_k)。对某参考完全匹配的阶段 δ=0 时，该阶段的局部成本与局部梯度均为零。正常查询会降低其最佳完整解释中的最大偏离；正查询会提高最容易被解释为正常的那条参考下尚存的局部偏离。瓶颈可能是 gap，甚至只是删除一个参考阶段；因此还要区分查询匹配证据与 gap 证据，不能一律称为恶意阶段。

这与“把正标签赋给所有阶段”不同，也不要求所有正常查询与所有正常参考都彼此相近。后者会再次压平正常多模态。并列最优时使用固定的合法次梯度即可；需要记录实现采用首个最优还是均分梯度。

仅有连接标签仍无法确定真实攻击发生在哪一阶段。两个阶段若总是共同出现且都可支持正确连接判别，监督不能识别哪一个是命令、握手或响应。应输出“支持当前判决的阶段—参考差异”，不称“已定位恶意报文”。也不能把正连接中的未选中阶段当成有正常标签。

## 6. 为什么第一版不加 softmin / softmax

硬 min/max 与精确重复的参考、精确重复的局部代价无关。普通 logsumexp 会随参考数量或阶段数量变化；取 log-mean-exp 虽消去所有项相同时的整体数量项，复制其中一种正常模式仍会改变结果。这样可能只因某业务在参考库中更常见，就改变攻击分数。

因此数学原型先用硬 min/max，验证分数、梯度和参考一致性；不预设温度。若训练后确有优化困难，再研究能否在冻结的训练协议内使用平滑；不能把温度扫描作为本轮设计成果。硬瓶颈自身的梯度稀疏也是实际风险，不能只宣称它可解释。

## 8. 最小必要比较及成本口径

下面是识别机制所需的逻辑对照，不是已发布训练清单。

| 比较 | 必须固定什么 | 能支持或击穿什么 |
|---|---|---|
| 固定局部距离＋完整参考瓶颈分数 | 同阶段、参考库、对齐与查询时刻 | 若它已提供全部收益，则只需普通完整序列近邻 |
| 同一个学习成本，独立阶段 min 后 max | 同参数、初始化、训练标签、参考库 | 直接检验一致解释是否有增益，以及它新增了哪些正常误报 |
| 同阶段输入的强简单 HGB／小序列模型 | 相同输入和监督，可访问同正常参考信息；成本记全 | 防止新增阶段信息或参考数据被误算为算法改动的收益 |
| 全体阶段复制正标签的同容量模型 | 同观测与模型容量 | 检验弱标签只约束连接是否减少共有背景的错误正监督；它是解释对照，不能刻意弱化为唯一基线 |

不必为每篇近邻各训练一次。上述因素能够回答机制问题后，不以增加论文模型数代替验证。

设合法参考有 B 条、查询 T 段、参考最长 U 段、每段 D 维（包括 presence）；h 为一个隐藏层宽度 H 的 MLP，输入 `[δ,r]`、输出 D。参数量约 `3DH+H+D`，另加 α、β。等长对角控制的时间为 O(BTDH)；完整编辑 DP 在全部局部代价直接求值时为 O(BTUDH)，DP 本身 O(BTU)，参考库存储 O(BUD)。参考库、活动排除索引、阶段提取和等待完整连接的成本都必须计入。不得只报小 MLP 的权重大小，也不能把大参考库排除在“轻量化”之外。

模型库若要降 B，必须与相同压缩后的所有对照共用库；当前没有硬性 K 上限，不因成本未知就先造压缩问题。

## 9. 本轮能定下来的推进边界

主代理已实现纯合成的代数／梯度及编辑 DP 原型，并生成真实共有阶段账本。本文已对实现作数学审阅，见下一节。保留它的理由是“整连接标签不扩散、完整正常解释一致、exact正常锚可证明”这组明确的预测约束，而不是泛泛的图、注意力或多原型。

尚未建立的是：真实攻击是否需要这一致性约束；完整正常参考能否覆盖待判正常业务；局部学习是否比固定度量和强简单模型有额外收益。若无合法参考的连接较多，或剩余差异仍只是总字节量／来源，不能靠自由 gap、扩原型或调阈值把方案补成可跑状态。

本轮因此保留“设计候选＋数学原型”，不把它登记为已成立创新，也不立即发送新训练批次。

## 10. 对已实现原型的数学审阅

审阅对象为 `scripts/stage_design/reference_model.py` 与 `check_prototype.py`，来自独立工作树 `stage-conditional-design-20261119`；没有改动根代理代码，也没有重复运行旧包表示检查。

- `RelativeCost` 按 `[reference, signed_delta]` 计算 softplus 权重，满足非负与自配零；最后的 presence 坐标由 `Sequence` 要求为 1，null 为全零。
- `bottleneck_edit` 使用 `(i,j,matched)` 状态，匹配仅向同方向开放，两类 gap 均显式消耗相应阶段。转移是前驱瓶颈与本边成本的 max，候选之间取 min；这与定义的完整路径最小瓶颈一致。
- `require_match=True` 排除全 gap。已保存的反例仍只有一个共有首段 match，其余为两个低成本 gap，说明代码没有把“至少一次”误当充分解释。
- `relaxed_score` 是有效下界：任意合法完整路径中的每个查询阶段，必由一个兼容 match 或 query-gap 消耗；独立控制对所有参考／位置和 query-gap 取局部最小，再对查询阶段取最大。它丢弃参考删除、单调性与同参考约束，因此不可能超过完整最优路径的瓶颈。但它并非只改变参考一致性的一因素消融；等长对角对照才隔离了 min/max 次序。
- 对完整正常自配，存在全对角零成本路径，且其他路径不可能负，因此全局锚为零。这个结论不需要已训练网络。
- `torch.min` 采用稳定分支；`torch.maximum` 在两个值并列时可分配梯度。因此仅在活跃参考、路径及瓶颈唯一时，梯度才集中到单条边；不能把 trace 里的单个位置说成所有并列情况的唯一学习原因。

现有 [prototype_checks.json](prototype_checks.json) 记录 9 个小规模路径穷举与 DP 一致；活跃参数解析梯度 −0.15980599137079043，有限差分 −0.15980599132880968。这里确认的是具体实现与数学定义相符，没有产生真实检出率、正常误报或部署开销。

实际正常参考存在长尾：共有阶段账本含 610、798 和 1,220 段的正常连接。完整 DP 成本不能只按攻击的 3—11 段估算。完全相同 profile 的无损去重与别名索引可用于一致的输入工程；这不自动构成新的压缩研究。

当前模块没有数据加载、拟合或校准入口，参考只由调用方显式传入。F 来源资格、自身及同测量别名排除属于后续数据管线合同；原型数学正确不代表这些流程已经实现完毕。
