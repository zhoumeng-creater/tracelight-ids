# 阶段参照机制：直接近邻、严格等价与可检验差异

2026-11-19。本报告服务于一个具体候选：让同一条正常参考连接解释待测连接的全部阶段，并在各参考都不能解释时寻找可学习的局部攻击证据。已读当前 AGENTS、连接内部交互结果；本轮没有运行真实模型、选阈值或读取 C／保留来源。

## 1. 可以保留什么设计

可以保留“整连接一致参考下的局部证据学习”作为待验证偏置。它与每阶段分别挑正常原型再汇总有明确差别：前者禁止把来自不同正常业务的阶段拼成一条实际不存在的正常解释。

这项区别没有自动解决正常误报。对同一代价矩阵，整参考约束的分数不低于独立阶段匹配；如果仍用同一阈值，它只能增加或保持警报。新出现的合法正常组合，也可能没有任何一条库内参考覆盖。候选能否在重新训练但相同校准规则下取得更好的检出—误报取舍，尚无实测。

目前真实材料支持“连接级正标签不能复制给每个阶段”的风险：根代理已核得部分攻击前段与正常阶段一致。尚未核到某条真实攻击的所有阶段都能分别被正常参考解释、但不能被任何整参考解释的实例。因此，不能把下述拼接反例说成本项目已经发生的失效。

## 4. 候选的量词、等价和边界

先假定各参考已经与查询对齐。令 `C[i,r]=w_theta(query_stage_i, reference_stage_i)`，大值表示该阶段支持攻击，小值表示与正常参考相容。两个算子分别为：

```
独立阶段解释 S_ind = max_i min_r C[i,r]
整参考一致解释 S_coh = min_r max_i C[i,r]
```

取 `C=[[0,1],[1,0]]`，则 `S_ind=0`、`S_coh=1`。这是量词不交换的确切反例：每一阶段都有某个正常解释，并不保证存在同一个参考解释全部阶段。它只证明算法偏置不同，没有构造真实攻击。

对任意实数矩阵都有 `S_ind <= S_coh`。这是设计必须报告的不利方向：整参考条件更严格，未知正常业务最容易受到影响。它不是降低误报的数学保证，也不能用更高分数冒充更强检测能力。

以下仅说明瓶颈 DTW／Fréchet 近邻；最终原型使用显式计价插入／删除的编辑 DP。对异长序列，若允许路径 `pi` 单调、从首端到末端且覆盖两条序列的每个阶段，可写：

```
S_coh(X) = min_r min_pi max_(i,j in pi) w_theta(x_i, r_j)
D[i,j] = max(w_theta(x_i,r_j), min(D[i-1,j], D[i,j-1], D[i-1,j-1]))
```

当局部 `w` 为距离时，这就是离散 Fréchet／瓶颈 DTW 最近正常模板。改成有符号神经局部代价，不改变这套 min–max 路径求解；其新内容只能是局部证据的学习条件与交通任务中的归纳限制，不能声称发明新的对齐算法。对有界 signed 代价作统一常数平移，min–max 分数也只平移同一个常数，因而负值本身不是表达优势。

如果所有参考在每阶段都相同，或同一个参考同时达到每阶段最优，两种量词退化相同。若正类证据只在一个独有阶段出现，独立阶段匹配通常已能发现；此时整参考一致性不应预期有额外价值。

允许任意跳过不匹配阶段会破坏上述解释：候选可能丢掉真正攻击段，只保留正常握手。因此必须明确是覆盖全部阶段的单调路径，还是有计费的编辑模型；不能在得到结果后调整跳过规则。

## 5. 可实现的学习条件

本轮最终采用非负条件局部成本，以整连接标签学习；有符号配对版本已因正常锚不构成全局下界而撤下，详见 learning_mechanism.md。正常连接希望至少有一个合法整参考能解释所有阶段；正连接希望每个合法正常参考至少留下一个局部不相容证据。两类监督都在连接级汇总后计算，不能把正连接所有阶段置为正。

正常参考只来自已允许的训练来源。训练正常查询排除自身及同一物理测量的别名；不机械排除整个聚合活动组。否则自匹配会掩盖正常覆盖，而过宽排除会额外制造跨来源条件。参考库规模、样本标签、段信息与查询时刻须同时提供给控制方法，不能给候选额外正常标签。

`w_theta` 如果只是 `distance - bias`，模型就是可学习距离的正常模板方法；如果忽略 reference，则外层 min 失效，退化为普通 MIL。必须检查这两种退化。训练后可以用已冻结的模型检查 reference 置换是否真的改变连接决策，并检查独立阶段版本是否同样有效；这些不能在本机提前做真实 forward。

同一特征／编码器下的完整序列分类器仍是重要对照。不存在“MLP／小 TCN 理论上不能表示这种功能”的结论；我们比较的是数据支持下的归纳偏置和成本，而非笼统的模型表达能力优越性。

## 6. 最小可否证结构

以下是设计所需的区分，不是新增实验注册：

| 比较 | 必须保持相同 | 可以击穿什么解释 |
|---|---|---|
| 整参考一致 vs 独立阶段参考 | 局部 witness、参考库、标签、编码器及可见全部阶段 | 若没有额外价值，量词一致性主张结束 |
| 学习条件成本 vs 固定距离的整模板方法 | 完整对齐与参考预算 | 若距离方法相当，新增学习目标没有必要 |
| 候选 vs 同信息完整序列简单分类器 | 方向／字节段、质量字段、完整观察截止和监督来源 | 若收益只来自包输入，不能称机制收益 |

真实依据应先回答：未见的可信正常连接有没有一条不依靠同活动重复的可比整参考；攻击的阶段是否真的会被独立参照错误拼成正常；这些现象与体积、端点、采集来源是否可区分。现在已知前段共享，但尚无全阶段拼接攻击，故候选可以继续原型与必要条件分析，不能把本报告当作已有充分训练依据。
