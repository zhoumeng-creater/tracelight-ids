# TraceLight IDS：成果全景、创新审查与研究路线重构

核查日期：2026-11-03。对象：轻量化机器学习入侵检测毕业设计。依据：正式论文、作者全文与代码、模型卡、官方产品文档，以及本项目已归档的实验结果。本轮是研究审查；未新增真实数据训练或部署成绩。后续真实实验在实验室 RTX 4090D 执行。

[离线阅读与检索版](report.html) · [结构化对照记录](source_index.json)。四专题共 72 条对照记录（含跨专题重叠，含型号、基准和产品，不等于 72 种不同算法）；194 个不同外部来源链接。数量说明覆盖范围，不代表全部全文精读或已复现数量。

## 1. 直接判断

**目前“特征筛选＋树教师／小 MLP 蒸馏＋置信门控＋困难样本排序＋检测界面”的创新主张偏弱。现有证据不足以把它写成一套有显著优势的新算法。** 本轮找到的直接近邻，比此前列出的通用 KD 与表格基础模型更接近当前设计，应据此调整论文定位和下一轮比较。

前五轮实验的价值是建立了可信基线、量化压缩代价，并暴露了可研究的失败现象。新的研究应解释并改善这些现象，同时回应最接近的已有方法。实验次数、最新模型名称、漂亮界面和多模块组合，都不能替代这个要求。

判断需要分开：

| 评价维度 | 当前有的证据 | 当前缺的证据 |
|---|---|---|
| 完成度／工作量 | 五轮既有实验、双数据环境、字段／容量／KD 消融、独立校准与最终测试、CPU 成本和工件复核 | 新路线的正式实验室结果与新的确认来源 |
| 算法设计 | 已实现损失、门控、匹配权重控制、分组训练与部署适配 | 相对最强近邻的明确差异、独立作用和稳定收益 |
| 创新性 | 已有具体失败线索，研究问题可以收窄 | 现有组合被大量先例覆盖，尚无充分证据支持原创方法成功 |
| 前沿性 | 已核查 2025／2026 正式论文及近期技术报告、基础模型与流量预训练 | 近期强方法的同协议实测；仅在综述中出现不等于实验跟上前沿 |
| 实际效果 | CIC 字段压缩有成本收益；UNSW 换小模型的代价也已量化 | 可靠的跨分区低误报保持、困难家族保护、应用全链路成本 |

本科论文是否达到学校要求，还取决于任务书、导师评价和论文论证；不能仅凭当前分数作保证。按用户提出的“有分量、有算法设计、有效果、有辨识度”目标，研究尚未完成。

## 3. 最需要正面回应的已有成果

### 3.1 工作点感知蒸馏不是新的大概念

[Evaluation-Oriented Knowledge Distillation for Deep Face Recognition，CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/papers/Huang_Evaluation-Oriented_Knowledge_Distillation_for_Deep_Face_Recognition_CVPR_2022_paper.pdf) 已经按 TPR／FPR 工作点识别关键关系，用排序迁移减小师生评价差距，并考虑小学生的表达能力。这直接削弱“围绕低 FPR 传递关键边界关系”的泛化新颖性。

人脸验证和二元 IDS 的样本单位、关系定义不同；可以研究任务适配与未解决机制，但更换应用不能自动构成新的学习方法。需要将其关键机制作为近邻对照，说明二分类适配究竟改变了什么，不能只比较普通 KD。

### 3.2 选择性轻量 IDS 与校准置信指导已有直接先例

[DistillGuard，Computers & Security 2025](https://doi.org/10.1016/j.cose.2025.104417) 已有 Transformer 教师、轻学生、选择性知识传递与解释。其选择隐藏表示的机制与当前输出 gate 有差异，但“选择性 KD＋轻量 IDS”的大框架不能作为首创。

[Adaptive Conformal Guidance for Learning under Uncertainty，ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/0b08d733a5d45a547344c4e9d88bb8bc-Abstract-Conference.html) 利用校准预测集合表达不确定性、加权指导，并研究教师受噪声／变化影响的情况。因此“加一个校准不确定度门控”同样不足以获得新颖性。该方法的覆盖目标与本项目正常类误报率仍需区分。

### 3.3 基础模型蒸馏、OOF 与合成查询也已有近邻

[Distillation of Tabular Foundation Models into Efficient Predictors，2026-10 预印本](https://arxiv.org/html/2610.01435v1)、[结构化医疗表格蒸馏，ICML 2026 SD4H workshop](https://arxiv.org/html/2605.18702v1) 已直接研究 TFM 到高效模型的迁移。后者含 OOF、适应性温度与置信权重；前者在自己的设计中比较 full-context 和 OOF，不能只摘取支持某一协议的结果。

[GEAR，2026-08 预印本](https://arxiv.org/abs/2608.18849) 进一步使用合成协变量查询、真实数据与 OOF 锚定。换成 TFM 教师、增加合成数据、保留 OOF、部署时删除教师，都需要更具体的新问题和增量证据。

合法使用 train 标签的 full-context 软目标，不自动构成测试泄漏。当前研究坚持 OOF 的主要理由是要评估教师对未见训练行的错误、置信和门控选择；它是本研究问题对应的控制条件，不是所有蒸馏的唯一合法方案。

### 3.4 低误报迁移与安全级联也已有较近工作

[Neyman-Pearson Classification under Both Null and Alternative Distributions Shift，ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/33870b3e099880cd8e705cd07173ac27-Abstract-Conference.html) 同时处理正常与攻击两类条件分布的变化及负迁移。不能把“在漂移中保持误报预算”称为无人解决的问题。

近期 [C-GUARD，Future Internet 2026](https://www.mdpi.com/1999-5903/18/8/431) 已涉及 OOF 救援模型、只翻转基线阴性、conformal gate 和显式新增 FP 预算，详见[近邻报告](nearest_work_and_novelty.md)。所以“按需升级到大模型并控制误报”的备线也需重新查明差异。对 SAFE-KD 等预印本，本轮还发现作者校准实现不足以直接推出所宣传的早退条件错误保证；有先例和保证成立同样需要分别审查。

## 4. 当前创新主张逐项处理

| 原有或容易提出的主张 | 本轮近邻／问题 | 当前可用表述与处理 |
|---|---|---|
| 稳定 MI＋去冗余是新特征选择 | FSNID 等已研究信息贡献与字段压缩；现有稳定性未带来普遍收益 | 作为受控选择策略／消融保留；不宣称新选择理论 |
| 树教师蒸馏小 MLP 是核心创新 | 轻量 IDS KD、TFM distillation 已有 | 作为研究载体；收益必须超过同学生 hard 与权重匹配控制 |
| 正确性＋置信 gate 是原创 | 质量指导、自蒸馏、conformal guidance 等近邻 | 写清公式及适用问题；不以模块命名称新方法 |
| 工作点关键关系＋排序迁移 | CVPR 2022 EKD 直接近邻 | 增加关键机制对照；必须有超出任务替换的贡献 |
| top-normal pair loss 直接优化 1% FPR | 当前实现约 10% batch hard mining、有 pair cap／组权重，非精确 pAUC | 称启发式排序代理；补 CVaR／NP 训练对照和尾部支持检查 |
| 基础模型＋OOF＋合成查询 | 2026 TFM 蒸馏／GEAR 已覆盖 | 优先筛合格教师；不能靠换教师制造算法新颖性 |
| 校准 1% 即保证测试／部署 1% | 第五轮 UNSW 已有反例；统计假设也不成立 | 报告冻结阈值的实际 FPR；明确经验预算与概率保证的区别 |
| 语义字段遮盖／CSV→图像预训练 | SAFE、ConTextTab、Lens 等已有 | 只在能证明派生字段捷径等具体问题时进入候选 |
| 低成本级联＋FP 预算 | 级联／选择性分类、C-GUARD 等已有 | 先核错误互补，再与简单路由及近邻机制比较 |
| 实时检测＋解释面板是算法创新 | NFStream、Zeek、Security Onion 等已有成熟链路 | 算作实现与研究展示；以真实输入和证据闭环提高成果质量 |

这不意味着现有实验应丢弃。恰恰需要它们支撑：为什么增加这些控制、为什么舍弃无效机制、为什么选择某条改进路线。论文可以有明确的方法设计与有价值的实证贡献，但必须按证据表述其创新程度。

## 5. 本项目现有结果给出的真正问题

以下数字取自第五轮实验室归档与既有独立复核，不是文献成绩。三个训练 seed 的变化不等于三个独立网络环境。

| 已确认现象 | 研究含义 | 不能直接推出 |
|---|---|---|
| UNSW：RF 召回 88.9004%、FPR 2.5694%；小 MLP 召回 86.1959%、FPR 3.2063% | 小模型的存储与吞吐优势伴随实质检测代价；两者校准 1% 的阈值都未保持 | 不能宣称“小 MLP 基本无损、低误报已解决” |
| UNSW：约 29 MB→40 kB；单条 CPU p95 4.653→2.414ms | 压缩收益真实且可量化，值得研究更好的检测—成本取舍 | 不能以参数／文件缩小代替检测提升 |
| CIC：82→MI24，召回 99.2155→99.1539%；p95 7.011→2.276ms，批吞吐 3.19× | 字段压缩在该设置有用，需解释为何一些家族／seed 仍退化 | 均值接近不是统计等效；不是原始包全链路 3.19× |

第五轮报告位于实验归档 `20261103_第五轮实验室4090D/复核分析/第五轮最终测试复核.md`。当前正式任务是分别训练／评价两套数据，并非源域训练后直接迁移到另一套数据。旧 test 已揭晓，新路线在这些旧结果上的改进只能称开发／再分析。

## 6. 优先研究方向：把假设写到可被推翻的程度

### A. 优先验证：压缩中的一侧错误迁移与正常组集中风险

**具体问题：**在同一预设校准 FPR 目标、相同小学生与推理成本下，普通 KD 的损失是否主要来自新增正常误报与丢失教师已检出的困难攻击？把这两类分歧分开建模，并限制少数关联组对训练尾部的支配，能否超过 EKD 适配、普通 KD＋pAUC 和无 KD 的同组权重训练？实际评价 FPR 分别报告，不假定相同校准目标产生相同测试风险。

它仍是待检验候选，不是本轮已经证明的新算法；EKD、AdaConG、pAUC／NP、group DRO 与类条件迁移理论都是必须回应的近邻。若具体机制与这些方法等价，应撤销相应原创主张。

将师生在各自冻结工作点的二元决策记为 $T,S$，$P_0,P_1$ 分别表示同一评价总体的正常与攻击条件分布，在同一批样本上有直接计数恒等式：

$$
\mathrm{FPR}_S=\mathrm{FPR}_T+P_0(S=1,T=0)-P_0(S=0,T=1),
$$

$$
\mathrm{TPR}_S=\mathrm{TPR}_T-P_1(S=0,T=1)+P_1(S=1,T=0).
$$

这只是分析工具，不称原创定理。它要求同时观察新增 FP、修复 FP、丢失 TP、挽救 TP，而不是仅看总体 KD loss 或置信均值。教师到学生的四格差异首先描述压缩，不自动说明 KD 的因果作用；须对 hard、matched-hard 和 KD 同时计算，并比较同初始化的配对差异。诊断必须使用实际 KD 教师；既有 RF→MLP 的差距不能代替 HGB 蒸馏的归因证据。若教师自身超预算，单纯压低学生新增 FP 也不能自动保证总 FPR。

待研究的改动应落实到以下三点，而不是先给算法起名：

1. **信号对齐。** 用合法训练范围内的教师工作点／边界余量定义迁移信息，比较概率软目标与关系／分歧信号；明确加权教师分数不等于部署后验。
2. **集中度控制。** 检查正常尾部由哪些重复／关联组主导，在相同更新与 pair 预算下比较逐行、组均衡、随机 pair 与标准 pAUC 训练。组均衡改变估计目标，须同时报告真实逐行 FPR，不能将两者混称。
3. **困难攻击保护。** 在 train 内定义有支持的攻击子集，检查教师正确检出的样本是否被压缩丢失；推理不能读取真实家族标签。与简单类／族重加权和同结构更好训练作对照。

特征重复组用于检查模式集中，会话关联组用于防泄漏与依赖分析，环境组用于迁移评价，三者不能互相替代。只有重复 hash 时，不主张会话独立或 mixture 稳健。组均衡也不同于最坏组约束或 group DRO。

建议的最小步骤：先筛教师→折内产生训练信号→固定学生与初始化／batch 顺序→比较已有方法和候选→独立正常校准→冻结阈值→新来源确认。需要教师工作点时，所用正常样本不得来自旧 test；训练内再划校准／交叉拟合的成本计入账本。分组 OOF 只能隔离已知关联；训练折彼此重叠，也不会使组内 flow 独立。独立统计单位及跨分区关联未经核验时，仅作经验结论。

**最强击穿实验：**候选与“hard＋pAUC＋同组权重”、EKD 关键机制适配采用相同学生与计算预算。如果优势消失，说明收益由已有目标或重加权解释，不能主张新的知识迁移机制。替换为同 gate 的真实标签目标仍同样有效时，也不能将收益归因于教师软信息。

### B. 备选：语义字段族与派生捷径下的低误报压缩

**具体问题：**字段缩减造成的检测退化，是否与确定性派生字段、环境代理和罕见攻击所需信息有关？同字段数的简单 MI 为什么失败，条件信息选择或有约束的表示学习是否真正改善低 FPR 取舍？

最近邻为 FSNID、SAFE、表格遮盖预训练和 TabFSBench。先建立字段语义／派生关系字典，用固定其余字段的移除／恢复验证具体失效机制；再决定是否值得设计条件信息选择或语义整组遮盖。没有实际提取器时只测 CSV 编码／推理成本，不能用主观“昂贵字段”权重声称降低网络采集成本。

**最强击穿实验：**同字段数 MI、冗余控制、经审计可行的 FSNID、同架构随机遮盖、从头训练，使用相同数据与总预算。如果语义方案只改善重建 loss、不能保护低 FPR／困难家族，停止该路线。它在数据和工程上较可行，但目前的新颖性也需要进一步收窄。

### C. 有数据条件的扩展：富输入教师到轻量流特征学生

TrafficFormer、Lens、netFound-v2 和 tFusion 展示了包级／多模态信息的价值。但现有聚合 CSV 不能恢复包序列，也没有自动保证 PCAP 与每行特征的对应。只有获得可核查对齐和预训练来源后，才值得研究额外信息能否帮助小学生；需比较同输入教师、富输入教师和无蒸馏，排除额外数据／标签解释。privileged information／跨模态蒸馏已有基础，不因使用流量模型就称首创。

该路线数据与验证负担明显更大，作为条件扩展保留。当前优先 A；B 在明确失效证据需要它时推进。

## 7. 先做哪组实验，什么时候停止

这是一份研究取舍建议，尚未运行，也不更改前五轮冻结结果。已有 research v2 的 13×5 实现矩阵可用于机制诊断；它的存在不意味着当前组合已经值得作为创新方法全面扩跑。

| 闸门 | 必须回答的问题 | 建议工作／关键对照 | 继续条件 |
|---|---|---|---|
| G0 强参照与教师资格 | 问题是否只是弱基线／弱教师？ | CatBoost、LightGBM、合理调优 TabM；现有 RF／HGB／小 MLP；再对 TabICLv2 作折内上下文与显存检查 | 教师在开发低 FPR 指标和家族支持上合格，资源可接受；否则先解决教师问题 |
| G1 机制淘汰 | 软信息是否超过既有目标与重加权？ | hard、matched-hard、普通 KD、hard＋pAUC、KD＋pAUC、EKD 关键机制适配、质量门控、组权重无 KD、候选及去关键机制控制 | 增益不能被权重／低 FPR 目标／学生训练差异充分解释 |
| G2 稳定性与压缩 | 效果能否跨 seed、输入预算和教师保留？ | 通过 G1 的少量候选增加训练 seeds；再改变教师／容量／字段，分别受控 | 同一 CPU 成本或明确 Pareto 收益，困难家族退化透明，集中组之外仍有支持 |
| G3 新来源确认 | 新假设能否离开已经看过的 test？ | 审核未使用来源，冻结处理、主比较、误报目标、非劣界、区间和停止规则后再开 test | 真正新来源的独立确认；失败也完整报告 |

G1 分两步：G1a 从候选条件池冻结约 5 项，一环境×三种子，约 15 个学生 fit；G1b 只为尚未区分的解释定向追加。约 8–10 项是候选条件池，不是首批全部运行；教师与 OOF 成本另计。每次追加必须明确它可能推翻哪项解释，不以模型数／拟合数代替研究内容。

另在一个固定教师／学生组合上定向比较 FC 普通 KD 与 OOF 普通 KD，保持学生更新与查询预算一致，报告上下文体量、抽样和类别覆盖；无需将整个矩阵翻倍。该比较识别监督构造的作用，不能用 FC 教师在已见行的正确率证明门控可靠。

预算记录：教师 full fit、OOF 辅助 fit、调参、上下文选择、预训练或微调、选择器内部训练、失败和重试分别计时。相同 trial 数不是相同算力，默认配置和预算内调优成绩分列。各模型的早停依据应与推理聚合语义一致。

主效应可沿用既有 0.5pp 开发增益作为事先考虑的闸门，但确认阈值、非劣界与区间方法必须在新数据开封前论证。小家族需要显示分子／分母；独立组少、区间宽时不能宣称“所有家族均保持”。总体 AUC 提高、某个 seed 更好或 p 值显著，都不能代替低误报与部署效果。

### 7.1 不可混用的五个对象

| 对象 | 它回答什么 | 主要限制 |
|---|---|---|
| pAUC | 一段 FPR 区间内的平均排序质量 | 不等于恰好 1% 工作点的 TPR |
| 冻结阈值实际 TPR／FPR | 该模型在该来源上的检出和误报 | 超预算时必须照实报告，不能在 test 调回 1% |
| NP 高概率控制 | 在指定抽样／分布假设下的错误约束 | 正常流相关、分布变化、模型选择会影响条件 |
| CP 集合覆盖／不确定度 | 标签是否被预测集合覆盖等 | 不自动约束正常类 FPR 或早退后的条件错误 |
| 级联总体风险／成本 | 完整决策链产生多少错报、漏报和开销 | 不能只看救援子模型分数或忽略路由成本 |

### 7.2 新确认来源的准入

两套不同 CSV 分别重训后复验，是跨数据环境复验；只有输入语义对齐、源域训练策略冻结、目标 test 不参与选择时，才能评价源到目标迁移。新来源先核：许可与来源、完整哈希、字段定义、采集／会话／时间元数据、重复与跨分区重叠、正常独立单元及稀有家族支持。不能用 CSV 行号造时间，不能将 feature hash 自动当真实独立网络会话。

旧 test 的后续分析限于 v1 已保存预测／模型工件的解释与明确标注的探索，不用于 v2 新模型选择、排名或反调阈值，也不承担新方法的独立确认。新方案的压力测试使用开发分区或另行冻结的新来源。随机缺失、重采样正常组比例、去重复和受控噪声应以准确名称报告，不称真实网络漂移。

## 8. 市面系统对最终成果的要求

成熟系统已覆盖采集、规则／协议分析、流索引、告警调查、PCAP 证据和案例协作。商业 NDR 的公开能力可用于需求比较；厂商宣传数字不作为本项目算法有效性的证据。详见[项目与产品报告](products_and_projects.md)。

本项目最有价值的产品定位是：**可实际检测 CSV、能审查低误报压缩取舍、能追到每个结论工件的研究系统。** 当前已有真实 CPU 推理与双模型离线展示，现有 demo 使用第四轮 seed17／validation 阈值，不自动代表第五轮最终测试或 v2；下一步界面应把研究中新发现的真实问题展示出来。

| 视图／能力 | 必须显示的真实证据 | 验收方式 |
|---|---|---|
| 检测与输入契约 | 字段／单位／缺失检查，实际模型、阈值、预测；有可信真值时才展示错误样本 | 导入合法 CSV 并完成真实推理；错误 schema 给可操作反馈 |
| 压缩对照 | 同一输入的师生预测分歧；有可信真值时再显示四类错误迁移、攻击支持数与误报集中组 | 页面计数与保存的逐样本预测逐项一致；无标签输入不显示 FP／FN |
| 阈值与成本 | 校准来源、冻结阈值、包大小／内存／CPU p95 和测量范围；实际 FPR 只在真值可审计时计算 | 不用目标 test 反调；图形数字可回溯原报告；无标签流不显示经验 FPR |
| 证据追溯 | 数据 manifest、代码／配置／权重哈希、运行设备、实验状态 | 从图表定位到实际工件，不显示硬编码“成功”状态 |
| 可选 PCAP／实时入口 | 真实流提取器、字段映射、流结束等待和全链路延迟 | 只有语义对齐及实际采集验证通过后才展示为支持能力 |

Zeek 与 UNSW／CIC 的同名字段可能有不同统计定义；NFStream 已有模型插件和实时部署示例。直接接提取器并不能证明原 CSV 模型有真实网络效果。是否增加 PCAP 取决于输入对齐和时间预算，不用一个按钮制造能力假象。
