## 为什么改变研究顺序

对 R30 原始固定分数，满足每个单元正常预算的阈值下界为 L_j，保住全部已有 TP 的严格上界为 U。共同区间为 [max L_j, U)。已有算术显示 seed17、43 区间非空，seed29 区间为空且最少损失1条攻击。因此不能把三个模型全部认定为必须重排，也不能把纯阈值方案当成能通过旧三种子零损失标准的候选。

完整逐单元数值、冲突身份与输入 SHA 见 [可行区间诊断](operating_point_reset_20261118/feasible_intervals.md)。该诊断使用已开 ED 标签，只解释能力边界；其数值不得进入部署阈值或校准规则。

## 唯一固定比较

[机器规格](../configs/operating-point-reset-20261118.json)在新参照阈值与判决计算前写定。本研究已看过原 ED 和可行区间，故它是事后开发比较，不是未开数据预注册。

比较对象只有原顺位程序与一个已有标准 NP 校准参照；每个对象使用同一 R30 工件、相同 C 身份和相同 ED 分母，三个种子完整保留。

| 项目 | 原顺位程序 | 固定 NP 参照 |
|---|---|---|
| 风险水平 | 0.01 | 0.01 |
| 置信失败概率 | 不另设 | 固定 0.05，不搜索 |
| 校准数据 | 原 C 的5511条正常分数 | 同左 |
| 一基升序位置 | ceil(99(n+1)/100)=5457 | 最小 k，使 Binomial(n,0.99) 的 P(X≥k)≤0.05；k=5469 |
| 判决 | score > threshold，float64 | 同左 |
| 阈值作用域 | 每模型一个阈值，跨15单元 | 同左 |

这项标准参照此前已在项目其他模型上使用，本次只检验它在 R30 固定分数上的行为；它不是新算法，也不是2025 TLNP或2026迁移NP训练的复现。不增加 F/V 阈值策略：F/V已用于原模型拟合和选择，本次没有新的模型选择步骤；参数由既有方法和任务水平固定，阈值值仅由 C 计算。

NP序位公式要求固定评分函数与独立、同目标正常分布的校准样本。当前 C 被多轮开发利用，流的独立性未建立，且 B 与 D 的正常组成已有差异，不能据其二项尾值宣称未来风险保证，更不能声称15个有限单元同时满足预算。原文与实现边界见 [方法来源](operating_point_reset_20261118/method_sources.md)。
