# 研究主线：在正常业务组成变化下学习可迁移的校准边界

2026-11-20。研究问题固定为：**相同输入与监督下，怎样避免模型把已有支持的一类正常业务整体放在告警尾部，使正常业务占比变化不再直接放大误报，同时保留攻击区分能力。**

本轮形成一项具体学习机制：用训练内真实先后正常片段，联合优化前期校准边界、后期整数误报预算边界及攻击相对边界的分离。已具备真实片段、精确算子、梯度原型、必要对照和结果出口。它值得做有固定出口的机制比较；尚没有真实训练结果，也没有建立新颖性或跨来源低误报保证。

这里不要求先证明所有简单方法都不可能解决问题。已有方法在原任务上未完成要求，足以提出研究问题；当前新来源上的同信息基线必须在同一次比较中给出答案，不能预先写成失败。

## 1. 问题由哪项真实失败确定

R30 的 TabM＋PLE 三种子均检出 B72、D1964，15 个正常单元只有 8／5／4 合规。seed43 的正常四计数成分 `(11,8,1285,4725)` 在 F_B 有 36 条支持；C 的 23 条、D 的 84 条全部告警。三处原分数中位数几乎相同，分别为 −11.836／−11.832／−11.810，C 阈值为 −12.252099。其占比由 C 的 0.417% 增至 D 的 0.878%，一个 D 单元仅该成分就产生 14 个 FP，超过预算 8。

这不是“模型没见过这种正常”的普遍情况。三种子多数 D TCP 误报均有同四计数训练正常支持；训练正负分数又已严格分离。增加已有正负间隔、只平滑组内时长，都未直接解释怎样改变正常成分之间的相对尾部位置。

固定标准 NP 校准后来保留全部 2,036 TP，合规单元提高到 13／11／6，仍未完成全部单元要求。seed17／43 的事后共同可行阈值区间非空，seed29 为空。因此不能声称每个种子都必需重排，也不能将整个问题归为一个阈值数字。

拥有证据为 [正常尾部审查](../R30_NORMAL_TAIL_DESIGN_REVIEW_20261117.md)、[输入与分数机制](../r31_design_review_20261117/input_mechanism.md)、[固定操作点比较](../OPERATING_POINT_RESET_20261118.md)。旧结果用于定义问题，旧 C／D 的错误模式、分数、具体成分不进入新目标、分组或参数选择。

已经结束的历史摘要、ACK 聚合、完整正常参照路线不恢复。新方向作用于评分函数的学习目标，不新增包、端点历史、业务 ID 或正常参照作为预测输入。

## 2. 真实训练情境已经具备

使用当前冻结 F 的 13,252 条拟合连接：12,747 正常、504 控制、1 下载。来源仍为 santos 整 run 与 Unraveled 整 campaign。Q／E 只是 F 内部训练角色，不改变原 F／C／V 分配。模型训练可见全部 F，包含 E；这不是用 Q 拟合后对未见 E 做交叉验证，训练片段通过不能当作前向泛化成绩。

固定采用 UTC 自然日，Q 是同来源在该日开始前已导出的全部可信正常，E 是该日可信正常。第一日没有 Q，留在普通监督项内。选择自然日的理由是：边界无需模型结果，AIT 的已知正常动作连通分量没有跨日，日级分母保留实际整数预算。小时结果仅作分母与关联检查，不进入窗口选择网格。

## 3. 具体机制

评分函数仍为同一 TabM＋PLE，所有臂看相同端口置零 raw8、缺失标记与 F 标签。预测时输出与现有实现一致的 ensemble 分数：成员概率均值的稳定 log-odds，不以平均 logit 替代。来源和日期只用于构造训练片段。

对非空正常集合 X，定义：

\[
b_X=\lfloor0.01|X|\rfloor,\quad
t_\theta(X)=s_{\theta,(|X|-b_X)}(X),
\]

其中分数升序，顺位为一基索引。告警规则保持 `s > t`。这不是默认线性插值的 `quantile(.99)`，也不是总体风险保证。

每个前后情境 e 的正常迁移差为：

\[
g_e(\theta)=t_\theta(E_e)-t_\theta(Q_e).
\]

有一个直接对应真实有限单元预算的关系，重复分数和小样本时也成立：

\[
\#\{x\in E_e:s_\theta(x)>t_\theta(Q_e)\}\le b_{E_e}
\quad\Longleftrightarrow\quad g_e(\theta)\le0.
\]

因此不用先拟合“风险组”、平滑告警概率或比较两分布均值，就能明确训练要改变的两个边界。若当前后期边界更高，梯度同时作用于后期边界样本和前期校准样本；只压低一个固定阈值上的分数没有模拟重新校准后的行为。

仅优化 g 可能抬高前期阈值并损失攻击。令 A 为同一 F 中全部 505 条可信目标攻击，增加相对同一阈值的训练间隔：

\[
h_e(\theta)=t_\theta(Q_e)+1-\min_{a\in A}s_\theta(a).
\]

它是训练内分离要求；不把“新数据上逐 TP 零损失”设成所有候选的永久条件。F 只有一条可信恶意下载，训练间隔不能建立下载泛化能力。A 的控制／下载仍分别报告，不因重复控制量大就把唯一下载的回退平均掉。A 包含前后时期的训练标签，这是离线监督，不将未来标签作为部署输入。

原型附加目标为：

\[
L_{\rm transfer}=\max_e[g_e]_+ +\max_e[h_e]_+,
\qquad L=L_{\rm BCE}+L_{\rm transfer}.
\]

BCE 及其采样、模型结构、初始化、优化步数在各臂相同。系数与 logit 间隔均固定为 1，作为第一份可审查定义，没有根据真实模型结果选择数值。这里的 hinge、max、顺位反传均是已有数学组件，不单独申报原创。

在两个边界无并列的一般位置，正常项梯度包含
`∇sθ(x_E_boundary) − ∇sθ(x_Q_boundary)`。它针对跨片段相对排序，即使正负分类已饱和仍可以产生更新。部署时仍只有原评分器及一次校准所得阈值，不需要维护 Q/E 库。

## 4. 不再把代理改善当成成功

- **整体平移：**同时平移 Q／E／A 时 g、h 不变，正常项不会把统一压低分数当作修复。若把 t(Q) detach，前向值虽相同，平移梯度却由 0 变为 1；这种错误实现用数学检查排除，不浪费一个训练臂。
- **整体缩小：**原始 gap 会随正比例缩放变小，告警计数却可完全相同。攻击间隔提供竞争目标，但不是排除这一现象的证明。因此采用与选轮必须读取准确整数 FP 和攻击得失，不能按 loss 下降宣布改善。
- **全体同分：**正常项会为零，攻击间隔仍违反；不得认定为有用解。
- **抬高阈值：**须同时报告攻击相对同一 Q 的余量；只消除正常 gap 不算完成任务。
- **分数极值作分母：**本轮拒绝。当前 range 归一化可通过拉大无关极值缩小 loss，甚至在 Q={a}、E={b}、b>a 时产生正违反、零梯度。没有引入温度、归一化或权重网格补救。

[算子](../../scripts/normal_tail_mechanism.py)与[检查](../../scripts/check_normal_tail_mechanism.py)已经实现：精确计数等价、并列和零预算、双边梯度、错误 detach、缩放及塌缩反例均可复算，结果见 [operator_checks.json](operator_checks.json)。这些是算子与梯度结论，不是模型收益。训练内 g≤0 也不保证未见业务、任意组成变化或独立未来单元合规。

## 5. 相对近期方法的实质差异在哪里

最直接近邻是 **NeurIPS 2025 Conformal Risk Training（CRT）**：它已将风险校准置于训练内部并反传校准参数，不能再把这一点声称为原创。论文 Alg.2 及作者实现使用随机伪校准／预测拆分，其保证依赖相应可交换条件；本项目的时间组成变化不能继承其保证。[论文](https://proceedings.neurips.cc/paper_files/paper/2025/hash/6559542f75b4452ebaaf82094c7defb7-Abstract-Conference.html)

本项目待验证的差异限定为：**用已有真实正常组成的先后转移替换随机同分布拆分，将每个后期整数预算写成双顺位关系，并与同一前期阈值下的攻击分离共同训练。**它不是新骨干，也不是新校准公式；贡献若成立，应表现为固定信息、预算与最终校准规则下，真实业务迁移的改善超过普通监督和随机拆分校准训练。

这比“给困难正常加权”更具体，也不同于 R31：不以旧 D 错误设置风险桶，不最小化正常分布整体下移，不把代理 H 当作告警风险；学习单元来自 F 自然先后时期，条件直接对应每个 E 的实际整数预算。R31 原训练及原合同不恢复。

近期 MIL／正常原型路线没有优先级：现有阶段材料并无同信息 DeepSets、小 TCN、max-MIL 的真实失败；ProDisc-VAD 的极端片段伪标签与 LogMILP 的删除响应也不能补出这一证据。详细原文、代码及适配边界见 [recent_methods.md](recent_methods.md)。

## 6. 最小比较：三个训练臂解决一个问题

| 臂 | 相同部分 | 唯一用途 |
|---|---|---|
| A：普通 BCE | 同 TabM＋PLE、raw8、F 标签与训练预算，最终同一 C 规则 | 当前可靠来源上强简单模型是否已经够用 |
| B：随机拆分校准训练 | 与 C 相同 g/h、Q/E 大小、来源范围、正常总参与量、复用结构和攻击池 | 可微校准及附加目标本身是否足够；作为 CRT 思路的二分类适配，不声称作者完整复现 |
| C：真实先后校准迁移训练 | 与 B 相同全部目标和预算，只保留真实日级时间／业务对应 | 真实组成迁移的训练结构有没有额外作用 |

B 是训练内打乱对照，保留同来源物理身份与片段成员关系的整体重用结构。严格同时保持分量完整、每片段大小和每条身份参与次数未必可行，当前合同采用**同来源全局一一身份置换**，保持片段 incidence 结构与精确大小；每条身份的复用位置随置换改变，保留的是参与次数的多重集而非每个身份的次数；已知 AIT 活动被拆开时单列。这是故意去掉时间对应的训练对照，不是新的独立划分。不能为了使分量完整而暗改各臂数据量；不能把这类依赖当 IID 保证。C−B 的解释是保留真实时段／业务对应的整体作用，不声称隔离了纯粹的时间箭头因果。

三臂不使用新信息来赢。已冻结 HGB 四臂继续作为另有用途的现成基线，回传可并列呈现，不重跑它们来拼接新对照。使用既有三个种子 17／29／43 作成对重复，三臂共九份工件；不看首个种子结果后再决定是否补跑。种子不等于独立来源。

必要的交付约束已写入 [comparison_contract.json](comparison_contract.json)：模型、评分及角色一致；不使用 V 选择训练目标或阈值；参数与训练日程须在真实评分前一次写定。骨干数值配置可沿用已核 TabM，旧 A/B 采样组及旧 V 选轮不得照抄到新来源。当前代码只完成目标算子，还不是实验室训练包；没有发布可执行新批次。

## 7. 各种结果对应什么决定

| 结果 | 能作出的判断 | 下一步 |
|---|---|---|
| A 已满足登记正常单元，控制／下载能力也达到事先要求 | 当前信息下普通模型已足够，原失败不能自动迁移到新来源 | 采用成熟基线推进系统与论文；不给 C 强行保留创新身份，不扩大模型矩阵 |
| B 与 C 都优于 A，C 没有一致额外改善 | 有效的是校准参与训练，真实先后结构的独特价值不成立 | 保留成熟方法适配结果，结束时间结构的创新主张 |
| C 相比 A/B 稳定减少单元超额，攻击得失及成本可接受 | 真实迁移训练有开发证据 | 冻结机制、参数和选择规则，进入已有独立前向确认安排；不再调整窗口或模型 |
| C 只降低 gap/loss，实际 FP 超额与判决未改善 | 代理或数值变化未兑现 | 判当前实现无有效收益；不靠调阈值、缩放或提高容差解释成功 |
| C 降低 FP，但主要通过攻击丢失取得 | 只证明一种风险—检出取舍 | 完整报告逐条增失；未满足预先能力要求则不采用，不能用总 TP 抵消下载损失 |
| C 训练片段可行，跨 run 开发仍失败 | 训练内约束没有迁移 | 结束这项迁移训练版本，不追加来源、粒度、种子或重新分组挽救 |
| 三臂都未形成可用取舍 | 本次同信息学习方案未解决目标 | 保留失败，结束该固定比较；不能推出所有八字段模型或全部低误报学习无效 |

上述“优于”必须以全部种子的逐单元整数超额、逐类与逐事件增失判断，不按池化 FPR 或最优种子挑冠军。尚未约定的最低控制／下载能力不在看过结果后补数字；未定义的能力只能作描述性结论，不能生成采用标记。独立前向确认的来源资格与流程未就绪前，也不能把开发改善称最终成功。
