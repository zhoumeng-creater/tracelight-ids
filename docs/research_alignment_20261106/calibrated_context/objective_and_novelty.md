# 决策敏感的 KV 原型压缩

2026-11-06 更新：主候选采用 QCOC（2026-10）的常驻 KV 压缩接口，核心改动是状态特异的校准 margin 原型代价。共享头度量已被合成反例否定，修正过程与结果保留在下文。当前只推进这一主候选。

## 主候选：以校准后判定敏感性改变原型几何

具体改动限定在 QCOC 的原型构造：对每个源状态分别计算攻击分数相对于正常阈值的 Jacobian，得到状态特异的联合 K/V 坐标代价；用这一代价完成同槽位数聚类，再沿用 QCOC 的质量计数、原始 N 和闭式 value 拟合。基础模型权重、每层每头的槽位预算和部署推理路径均固定。首版不叠加跨层预算分配、V 的额外监督微调或攻击 margin 门控权重。

“QCOC 初始化＋CRT 目标只调 V”保留为强简单对照。QCOC 附录 F 已固定 K、质量和模型参数，仅调 V；CRT 已把校准阈值写进训练效用。把两者接到 IDS 是明确的任务适配，还不能仅凭这个组合承诺独立算法新颖性。

### A. 目标与梯度

令完整缓存预测的二分类 logit 差为 s(x)，在开发正常伪校准集合 C 上取得 τ(C)。攻击 x 的有效 margin 是 m_x=s(x)−τ(C)。研究对象是压缩导致的 margin 变化，不能只匹配未中心化分数。

在校准分位的排序局部不变、边界分数唯一时，若 c 是决定阈值的正常样本，则

$$\nabla_z m_x=\nabla_zs(x)-\nabla_zs(c).$$

边界并列时，取所有等于边界分数的正常样本的平均 Jacobian，作为该阶统计量在非光滑点的一个广义梯度选择；不把它称作唯一导数。最终评价使用真实分数、严格阈值比较和整组并列。多份事前固定的正常伪校准集合分别产生边界 c_e，减少对一个偶然正常边界样本的依赖。

对第 ℓ 层第 h 个头的第 i 个源状态，采用 QCOC 的标准化坐标 z_i=[k_i/σ_K;v_i/σ_V]。令

$$A_{x,i}=\partial s(x)/\partial z_i,\qquad D_{x,i}^{(e)}=A_{x,i}-A_{c_e,i}.$$

每个层—头独立累计下式，保留源状态索引 i。Q_e^1 是第 e 份开发攻击查询，所有攻击 margin 权重固定为 1；不先对 i 平均，也不跨头平均：

$$g_{i,r}^{\rm raw}=\frac1E\sum_{e=1}^E\frac1{|Q_e^1|}\sum_{x\in Q_e^1}\left(D_{x,i,r}^{(e)}\right)^2,\qquad r=1,\ldots,2d.$$

σ_K、σ_V 沿用 QCOC 在该头全部源 K、V 元素上计算的标量标准差。z 无量纲，A 是 logit 对标准化坐标的导数，g_raw 的单位是 logit²。首版没有温度 T、攻击族权重或可学习门控。

一般实现每个源 token 单独存储，源质量 n_i=1。若纯合成检查把完全相同的源状态分组，n_i 表示重复次数，N=Σ_i n_i；A 必须是单个原始 token 的导数。对整个重复组共同坐标求导所得结果须先除以 n_i，随后代理求和才乘 n_i，防止重复计质量。

可对该头所有状态及坐标乘同一个正数，使质量加权均值为 1：

$$g_{i,r}=\frac{2dN}{\sum_j n_j\sum_tg_{j,t}^{\rm raw}}g_{i,r}^{\rm raw}.$$

这一共同缩放不改变该头的聚类结果。禁止逐 token 归一化，因为那会抹去状态间的相对敏感性。A 与 g 随后 detach，不做二阶反向传播。全头 g_raw=0 时沿用 QCOC 结果。

源状态 i 分配到原型 μ_j 的代价为

$$d_i(z_i,\mu_j)=\sum_{r=1}^{2d}g_{i,r}(z_{i,r}-\mu_{j,r})^2.$$

它是源状态特异的代价，不是整个头共享的对称距离；不能用一次全局坐标缩放后调用普通欧氏聚类来替代。构造代理为

$$\min_{\Pi,\mu_1,\ldots,\mu_M}\mathcal D(\Pi,\mu)=\sum_i n_i\sum_{r=1}^{2d}g_{i,r}(z_{i,r}-\mu_{\Pi(i),r})^2.$$

这一代理来自一阶变化 δm_x≈Σ_i D_{x,i}·δz_i：先对开发攻击及伪校准折平均平方变化，再丢弃跨坐标、跨源状态的乘积项，得到上述对角和。它优先保留同一源状态中对攻击—正常边界差值影响较大的坐标。丢弃交叉项是计算近似，不表示这些项实际为零。

固定原型时，以各源状态自己的 d_i 做分配；代价并列时先比较标准化欧氏距离，再比较原型索引。固定分配时，各坐标的最优原型有闭式解：

$$\mu_{j,r}=\frac{\sum_{i:\Pi(i)=j}n_i g_{i,r}z_{i,r}}{\sum_{i:\Pi(i)=j}n_i g_{i,r}}.$$

分母为 0 时，该坐标对代理无贡献，取簇内普通源质量均值。新旧两法从 QCOC 确定性 farthest-point 初始化给出的相同源状态 ID 出发，均最多 15 轮分配—更新。空簇使用共同固定的修复规则，恢复非空簇后再计数。固定 g 时，非空分配与坐标更新各自不增加代理值；有限迭代不保证全局最优。压缩槽的注意力质量始终是实际分配源数 Σ_i n_i，不能替换成 Σ_i n_i g_i。

### B. 不需要逐缓存参数单独反向传播

对单头查询 q，记 p_qi 为注意力概率，a_q=Σ_i p_qi v_i，u_q=∂s(q)/∂a_q。局部一阶导数可写成

$$\frac{\partial s(q)}{\partial v_i}=p_{qi}u_q,$$
$$\frac{\partial s(q)}{\partial k_i}=p_{qi}\,[u_q^T(v_i-a_q)]\,\phi_N(q).$$

转换到标准化 z 坐标时分别乘 σ_V、σ_K。可从批查询的前向/反向获得 q、p、a、u，再按头和源行分块累积 g。查询之间必须独立；若求和输出的反向包含查询间交互，不能把它直接当作各查询的 Jacobian。

当每份伪校准对应 Q 条攻击查询时，对角累计约为 O(ENQd)，每头额外保存 O(Nd) 的源状态敏感度；逐头处理可避免同时保存全部头的敏感度。状态特异分配仍为每轮 O(NMd)，坐标均值更新为 O(Nd)。完整每源状态 Gram 矩阵会把累计和存储提高到 O(ENQd²)、O(Nd²)，首版不采用。

批内注意力概率及 q、a、u 的暂存不包含在上述 O(Nd) 累计空间中。查询分块时，概率项需 O(bN) 的批级空间，或按源行继续分块重算；完整缓存与反向图另计。QCOC 原有完整缓存目标计算及闭式 V 拟合也仍要执行。上述式子只描述新增代价，不把离线编译当作免费。

### C. 完整编译与接受规则

1. 用 TabICLv2 的同一冻结支持集构建完整缓存；取得 QCOC 的同预算基准压缩缓存。用于梯度的开发查询不进入支持缓存，其标签仅供监督压缩目标使用。
2. 在与支持集隔离的开发查询上，算完整缓存的攻击 logit、正常伪校准阈值及上述敏感度。
3. 只替换状态分配代价及对应坐标均值，重新构造联合原型；原型 V 坐标作为闭式拟合锚点，沿用 QCOC 的支持查询、岭系数和 V 拟合方程。最终重分配仍用 d_i，按完整源状态计簇质量，并保持原始 N。
4. 让候选压缩缓存对全部开发查询真实前向，**用候选自己的正常分数重新校准**。比较相同风险规则下的真实 TP、FP，不凭梯度代理值接收。
5. 初版只生成一轮敏感度候选。候选确定后才使用独立正常材料作最终校准，再在另一份隔离材料上评价。开发伪校准数据不充当最终风险校准数据。

该过程不需要对聚类的离散分配反向传播。Jacobian 只是构造候选的局部度量；最终接收条件使用硬编译产物和重新校准后的工作点。这里的正常集合是参与方法构造的开发伪校准材料，绝不是最终风险校准集。该方法属于有标签的任务适配压缩，不能沿用原 QCOC“不需要额外有标签材料”的描述。

### D. 性质与贡献边界

- s(x) 与 τ 同加常数时，margin 严格不变。任意 KV 扰动若让攻击与边界正常产生相同一阶分数变化，只能推出 Σ_i D_{x,i}·δz_i=0，不能推出每个 D 元素为零。
- 对角代理丢弃不同坐标和不同源 token 的交叉项。它不是全模型 margin 误差的精确表达或上界，也不继承完整 Jacobian 对任意共模扰动的零响应。
- 保留 i 是必要修正。将 g_{i,r} 对源状态平均成共享 g_r 的简化已经在下述反例中失败，不能继续作为当前主方法。
- 固定槽位数、精度和每头形状后，候选与 QCOC 的部署缓存字节及推理结构相同。改进要表现为同字节下更好的校准后检出，或在更低预算点保留相同检出。不能把离线度量计算算成免费。

拟议贡献是“**以每个源状态对校准 margin 的敏感性构造 KV 原型**”。研究假设是：同槽位下先避免混合判定作用不同的状态，能够保留固定 K 后仅调 V 无法恢复的信息。该假设需要完整 QCOC 编译流程和独立校准结果支持。

### E. 已发生的设计否证与必要修正

纯合成单头例子设 4 组状态：K=[(5,0),(-5,0),(0,-8),(0,-12)]，V=[0,1,-100,-120]，源质量 [1,1,49,49]。正常查询包括 9,800 个 (0,-1) 与 200 个 (1,1)，攻击查询为 (-1,1)，目标误报率为 1%。把 4 组压成 3 槽，穷举 6 种合并分区。

标准化联合 KV 欧氏代理与先平均源状态的共享 g 代理都选择合并前两个关键状态。合并后，正常尾部与攻击的注意力向量完全相同，任何只调 V 的方法都无法重新区分它们。在这个例子中，重新校准后均为 TP=0、FP=0。

保留 g_{i,r} 后，代理最优分区合并后两个背景状态。候选用自己的正常分数重新校准，得到 TP=1,000、FP=0。修正消除了这个反例中的信息错误合并；它没有证明一般迭代聚类找到全局最优，也没有完成真实 TabICLv2 或 QCOC 闭式 V 拟合后的验证。

随后执行[实际求解器检查](solver_reference.py)：相同普通欧氏最远点初始化产生源 ID [0,3,1]；普通与逐状态几何在 15 轮后均合并背景状态 [2,3]，都为 TP=1,000、FP=0。额外检查的敏感度初始化也得到同一好分区，首版继续采用相同源 ID 初始化。这个案例没有显示新迭代算法优于普通迭代算法；[求解结果](solver_reference_results.json)与六分区准则结果共同报告。

反例代码按单个原始 token 定义梯度，并检查了解析梯度与有限差分。该例同时说明：源状态敏感度参与原型构造，源质量参与注意力质量，两者不可合并。证据见 [geometry_reference.py](geometry_reference.py) 与 [geometry_reference_results.json](geometry_reference_results.json)。

### F. 三项足以否证的对照

1. **QCOC 原版。** 同支持集、同每头槽位、同最终校准；若没有低误报收益，修改原型几何没有必要。
2. **QCOC＋CRT 风格 V-only 适配。** 使用同开发标签、同校准口径及相近一次性预算；若它达到相同或更优的检测—成本关系，应采用更直接的适配，不能坚持度量方案。
3. **不减正常边界 Jacobian 的同一度量。** 即把 D 换为 A；其余相同。若没有区别，不能把收益归因于校准反馈；收益可能只是一般任务敏感压缩。

首版所有攻击查询等权。平滑 margin 权重不进入当前算法；只有出现足以支持单独假设的新证据时，才另行设计。正常尾部材料不足以产生稳定候选，或新校准后收益消失，分别说明敏感度估计或目标迁移未成立。
