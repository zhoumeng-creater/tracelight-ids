# 预算受限的低误报知识迁移：新研究构造（待实验）

2026-11-04。取代把 v3/v4 升级保护当核心创新的路线。现阶段为可证伪算法设计与实现，不是已证有效或已证原创。

研究问题：固定可用字段和小 MLP 预算时，教师在低 FPR 区域是否存在超出同预算 hard／直接 pAUC 的可迁移信息？区分字段删减、容量限制、目标表示和教师本身不足。保留正式轻量化机器学习 IDS 题目。

## 依据、单一增量与反证

已有证据：旧概率裁剪与工作点中心化令 CIC 正常目标退化；OOF 整组划分使实际 Portscan 教师未见该族；v4 约束起点排除可用模型。不是以增加 guard、保护族或对偶项修补新主线。

新协议沿用已封存 F/R/C 的整组身份，但重新训练：F 是所有教师／学生的唯一拟合标签池；R 正常分数注册阈值；C 是所有方法共有的开发选择池。完整 F 教师在 F 产生训练内目标，不再错误地称 OOF。这是合法有监督蒸馏，可能过拟合，必须在 C 审查价值。历史 validation 仅在全部选择冻结后统一评估，历史 calibration/test 不读。所有结果仍是开发证据，新的独立来源尚缺。

单一候选增量是**正常尾部附近的同类跨样本偏好迁移**。直接 pAUC 负责攻击对正常的类间排序；KD 仅在同标签样本之间迁移教师次序，避免把标签本身重复当作暗知识。教师使用 HGB 原生 float64 decision function，不概率 clip、不让跨折分数混排。以 R 正常分数上尾 5α 的分位数选择兴趣区域；它是训练兴趣窗，不是风险保证。

对每类均匀选一条兴趣行 i，再从同类全 F 选择另一行 j；目标 t=1[T_i>T_j]+0.5·1[T_i=T_j]。损失为 class-balanced BCE((s_i−s_j)/T,t)，缺少兴趣行的类贡献 0 并报告覆盖，不编造支持。教师严格单调变换不改变目标和兴趣集合（离散分位数）；这保证坐标不依赖，**不保证更好检测**。学生 logit 差的尺度仍影响优化。

总目标：class-balanced hard BCE + λp·global-tail pairwise logistic pAUC + λk·同类偏好损失。候选固定 T=1，λp=1，λk=0.3；所有增量对照共用学习率、初始化、pair 数、训练轮数和 C 选择规则。固定参数是预注册的第一轮，不称公平调参后的最佳方法。

正例内部顺序不是 pAUC 的必要条件，复制教师难例次序可能伤召回。只有相对 direct pAUC、raw KL、均匀同类排序、同类内置乱教师都存在稳定增量，才能把收益归于局部且有内容的知识。

## 信息预算与教师资格

用 all／MI24 × small[32,16]／wide[128,64] 的 hard 因子控制观察容量和字段效应。wide 是研究诊断，不计入小模型部署胜利。相同 hidden widths、不同 encoded width 不是精确相同参数数，逐项报告。MI 只用 F，24 字段只是观察预算，不虚构提取成本。

每 seed 训练 full-F HGB 与 MI24-F HGB。后者是 reduced student 的同信息教师，对照额外字段的归因。HGB 是有成熟本地实现的资格探针，不把“新教师名字”当创新；最新 TFM 的 context／查询成本与预训练污染还没有本项目锁定证据，当前不冒称复现。

在 R 定阈值后，用 C 的标准化 pAUC、工作点 TP/FP、错误互补、同输入行的目标歧义及支持审查资格。相同输入歧义只是有限样本不可区分诊断，不是信息论下界。宽模型／同输入教师提高只提示可访问输入中的模型缺口；缺乏提高也不证明不可约信息损失。

## 必要对照

- hard 与直接 global-tail pAUC：排除增益仅来自直接优化任务。
- raw KL、pAUC+raw KL：排除收益仅来自普通蒸馏或加入同一个 pAUC 项。
- ICML2025 RankLoss 的二分类公式适配：近期近邻；类别通道次序在二分类几乎退化，不声称作者原码复现。
- pAUC+全局同类排序：检验尾部局部化是否必要。
- pAUC+尾部排序：候选。
- pAUC+同类置乱教师尾部排序：保留分布、损失和训练预算，破坏教师实例知识。
- reduced student 使用同信息教师的尾部排序：区分额外字段与教师函数／正则效果。all student 的教师相同，使用别名而不重复拟合。

## 最近邻与原创边界

[TMLR2025 Rethinking LUPI](https://openreview.net/forum?id=dg1tqNIWg3) 与作者 `danilprov/rethinking_lupi@04e72da...` 要求排除 PI 归因混淆；[KBS2025 TPD](https://doi.org/10.1016/j.knosys.2025.113338) 已研究不完美特权教师，终稿全文仍未逐式取得，不冒用其保证。[ICML2025 RankLoss](https://proceedings.mlr.press/v267/guan25a.html) 迁移单样本类别通道顺序；作者 `RankLoss-KD@50a61305...` 的通道标准化与 1000 类设置不能直接称二分类复现。本候选迁移同标签跨样本顺序，信息对象不同，但关系／排序 KD 并非新概念。

[TPAMI2026 partial AUC](https://doi.org/10.1109/TPAMI.2025.3637063) 与 LibAUC 作者 `3c02aa98...` 对照说明低 FPR 上尾优化已有。这里的全有限 F 正常上尾 pairwise logistic 是 CVaR／pAUC 的直接适配，不是新目标、不是 LibAUC 随机 u_pos 实现的复现。[2026-10 TFM distillation 预印本](https://arxiv.org/abs/2610.01435) 强调匹配学生和分列成本；不能用换 TFM 替代上述归因。

唯一可申请的候选贡献：在特定资源预算与低 FPR 任务中，说明“局部、同类、次序”知识是否可迁移，以及它相对上述直接目标／近邻的有效范围。创新性须由直接比较和后续更广检索支持，不声称新定理、首创排序蒸馏或已经达到顶会水平。
