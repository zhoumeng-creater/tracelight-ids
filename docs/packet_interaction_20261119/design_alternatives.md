# 连接内部交互：可实现算子、等价边界与真实材料的取舍

2026-11-19。本文完成机制设计与已有 PCAP 的事实核对；没有训练、模型评分、阈值搜索，也没有读取保留来源。真实计数来自本目录 `summary.json`、`relation_evidence.json` 和 `connection_geometry.jsonl.gz`。

## 1. 当前决定

**不把 ACK 前缀积分、字节进度归一化或查询驱动压缩立为本轮新算法，不为它们安排训练。** 三种判断各有依据：

- ACK 前缀积分可以明确实现，但其基础形式与“相同 ACK 合段后逐层做字节加权 DeepSets”完全等价；换成积分符号没有新增信息或学习能力。
- 真实的 518 条 HTTPS 控制连接只有 3—11 个 ACK 合段。普通合段已经保留了本文算子所需的前缀信息，尚无需要学习压缩解决的长序列问题。
- 两条确认的恶意下载，与 329 条作者标注整连接正常、HTTP GET 返回 200 且有正响应体的连接，共享同一归一化两阶段 ACK 拓扑。纯拓扑不能决定下载意图。

这不等于原始包信息没有价值。已证实的表示问题是：相同“前 20 个包”预算在 AIT 控制连接中只覆盖约 2.27% 的唯一有效载荷字节，在 Unraveled 中却覆盖约 97.87%。后续比较若沿用包数截断，必须同时说明各来源实际看到了连接的哪一部分。这属于输入和公平比较问题，不能单独写成算法创新。

这些事实使三项候选前提直接失效：攻击需要复杂 ACK 图才能表达；普通方向块会普遍丢失攻击交互；大量有效交互必须在很小的 K 内学习压缩。不能人为把 K 压到 1 或 2，再把人为造成的信息损失当成项目困难。

## 4. 可实现的学习算子，以及为什么基础版本不构成创新

令方向为 d，反向为另一方向。当前已观察的唯一有效载荷字节集合经去重后，按序列号压成质量坐标区间 `[0, B_d)`。每个区间上的 `a_d(x)` 表示该字节首次被抓到的包所携带的 ACK，覆盖了多少反向已观察字节。它是一个阶梯函数。这里使用全部连接的事后描述；若改成在线算子，所有量都必须改用查询时刻已到达的数据。

给每个区间赋隐藏态 `h_d^l(x)`，一个明确的跨向更新是：

\[
 m_d^l(x)=
 \begin{cases}
 \frac{1}{a_d(x)}\int_0^{a_d(x)}\phi_l(h_{\bar d}^l(u))\,du,&a_d(x)>0,\\
 0,&a_d(x)=0,
 \end{cases}
\]

\[
 h_d^{l+1}(x)=\psi_l(h_d^l(x),m_d^l(x),q_d(x)),\qquad
 z_d=\frac{1}{B_d}\int_0^{B_d}\eta(h_d^L(x))\,dx.
\]

`phi`、`psi` 和 `eta` 可以是共享 MLP；`q` 是每个区间保留的可用属性。没有 ACK 锚点或没有反向有效载荷的情况另列缺失状态，不能以数字 0 冒充真实零前缀。

若输入区间 `[b_j,e_j)` 的隐藏态为常数 `h_j`，前缀积分可直接写成：

\[
 \int_0^a\phi(h(u))du=
 \sum_j |[b_j,e_j)\cap[0,a)|\,\phi(h_j).
\]

这是标准的字节质量加权聚合。完整区间的累计和加上末端部分区间，能够直接求出每个查询，不必显式构建所有“某字节已确认哪些字节”的边。

**细分一致性命题。** 把任一区间分成若干子区间，若它们继承相同的 ACK、初始属性和隐藏态，且更新及读取都按字节质量聚合，则任意有限层的输出不变。证明是积分可加性与逐层归纳。这一结论无需拟合，也不依赖攻击标签。

**精确等价。** 将相邻且所有保留属性一致的区间先合并，再执行上述加权前缀聚合，输出与未合并实现完全相同。因而“同 ACK 合段 + 每层前缀加权 DeepSets”就是这个算子的离散实现。若初始特征只有 ACK 与方向，同 ACK 合段已经足够；若还保留时间、窗口或其他变化属性，则必须保留其变化边界，不能沿用只有 ACK 的无损说法。

FG-SAT 的普通包节点均值没有自动满足细分一致性。例如两个等质量区间状态为 0、1，包均值为 1/2；只把状态为 1 的区间拆成两个节点，包均值变为 2/3，字节均值仍为 1/2。这个区别能证明一种归纳约束，不能证明我们优于加入标准字节权重的 FG-SAT，也不能消除上面的精确等价基线。

还可引入 ACK 相对位置核：

\[
 m_d(x)=\frac{1}{a_d(x)}\int_0^{a_d(x)}
 k_\theta(q_d(x),u/a_d(x))\,\phi(h_{\bar d}(u))du.
\]

它保留前缀内部位置，区别于只取一个均值。如果核是有限阶多项式，算子又可由相应的加权前缀矩精确实现；如果核由神经网络表示，则仍需说明相对带位置特征的加权集合模型改变了什么。当前 3—11 段的真实材料没有建立“前缀内部核学习”所解决的检测失败，因此不新增这个模块来绕开基础版本的等价性。

## 5. 查询保真压缩：数学上可定义，当前不采用

曾考虑的具体问题是：把反向字节域压成 K 个区间后，尽量保留实际 ACK 查询读到的前缀均值，而不是只降低整条曲线的均方重构误差。它有一个能在训练前验证的命题。

令 `P` 为区间划分，`Pi_P h` 为各区间内的均值。设 `||h(u)|| <= H`，查询 `a > 0` 落在 `[l,r]` 内；记 `T_a h = (1/a) integral_0^a h(u)du`。所有完整区间的积分相抵，只有含 a 的区间产生误差，而且有紧的最坏情况界：

\[
 \|T_a h-T_a\Pi_P h\|
 \leq \frac{2H(a-l)(r-a)}{a(r-l)}.
\]

证明：差等于 `(1-t)` 倍左侧积分减 `t` 倍右侧积分，其中 `t=(a-l)/(r-l)`；三角不等式给出右式，左右分别取相反的范数 H 常量可取等。

于是，按查询目标字节质量设置权重 `w_i`，可以直接最小化上界之和。给定候选边界，该目标按区间可加，可用连续分段动态规划求解。它与等宽、等质量分箱的目标不同；若所有查询恰在分箱边界上，这部分误差为零。

反例也明确：在一个分箱里，曲线 A 的前半为 0、后半为 1，曲线 B 的前半为 1/4、后半为 3/4。两者分箱均值都为 1/2，而查询到半箱时分别返回 0 和 1/4。先分箱再查询通常不能恢复先查询的结果。这只是聚合信息损失的数学反例，不是攻击／正常可分证据。

**不采用的原因已经成立。** 当前攻击连接的 ACK 合段最多 11，下载仅 2。直接保留这些段即可，不存在由已证明成本瓶颈迫使我们压成更小 K 的条件。上述界也只控制给定隐藏态的单层源端前缀读取；它不自动控制合并目标节点、改变非线性更新后的多层误差，更不保证检测改善。现在实施该压缩只会增加一个本来不需要的近似步骤。

## 6. `byte_geometry.py` 的数学审阅

审阅对象：`.worktrees/packet-interaction-20261119/scripts/packet_evidence/byte_geometry.py`，未修改该文件。

1. `insert` 返回原区间并集尚未覆盖的部分，并更新不交叠并集。相邻区间合并不会增加字节质量；重复字节保留首次观测副本的 ACK 注释。它解决重复计算，没有恢复真正的原始发送顺序。
2. `Prefix.at` 计算已声明字节区间落在序列位置之前的质量。遇到缺口时，它不把缺失字节补入质量；缺口另计。起点为 SYN 序号加 1，带 SYN 的数据起点也加 1，未把 SYN 计作有效载荷字节。
3. 字节域使用 TCP 头部声明的有效载荷长度；载荷截断另记。因此完整的声明区间可由头部得到，不代表对应载荷内容完整被捕获。后续没有读取载荷内容。
4. 模块的几何条件检查 SYN、双向非零字节、无已知初始缺口、无内部缺口和 ACK 锚定。调用方另排除连接归属歧义及序号跨度歧义。此条件不证明原始传输过程全被观察，也不把所有环境质量问题消除。
5. 扫整条连接取得 SYN 基准、利用最终字节并集计算 ACK 覆盖，适用于已经声明的完整连接描述；它不是前 20 包时即可得到的特征。早期检测不能复用最终并集或最终总量归一化。
6. 相邻且 ACK 覆盖量相同的片段合并，确实无损保存此处的 ACK 阶梯函数。片段首次到达时间、纯 ACK 包和窗口属性不在这个等价关系中。
7. `ack_covered_pair_fraction` 的直接定义是“双向 ACK 覆盖量之和除以双向字节数之积”。只有进一步满足首次观测副本的因果可见性，才能解释为已确定先后的字节对比例。若原始副本漏抓，首次抓到的是携带较新 ACK 的重传，同一字节对可能被两个方向都计入；字节并集无缺口、已观测 duplicate 为零也无法排除它。本轮 8,514 条记录中没有值超过 1，因而没有观察到该异常；一般定义仍不能无条件称为概率。

TCP 的累计 ACK 表示传输层此前收到的字节范围，不证明这些字节在应用层触发了该响应。ACK 压缩、延迟 ACK、TLS padding、丢包及改变 ACK 注释的 offload 合并都超出第 4 节的细分不变性条件。[TCP 规范](https://www.rfc-editor.org/rfc/rfc9293.html)用于核协议含义，不是新算法推荐。

## 7. 对项目研究主线的具体影响

这一轮没有产生新的可宣称算法。它已经把一个可实现候选推到足够具体：知道输入是什么、怎样更新、怎样精确实现、哪种简单方法能替代，以及哪条真实反例使其退出。基础前缀算子不再保留为“待调参试一试”，压缩版本也不保留为候补训练臂。

原包仍有两项可直接复用的产物：一是去重字节／ACK 合段及其质量记录，可作为未来包模型同信息控制的统一输入；二是已经量化的跨来源包预算差异，可约束任何声称“相同前 n 包”的比较。数据处理成果和检测创新分开报告。

若继续提出学习机制，必须指向当前证据中尚未解决的具体失败，例如同等业务阶段下的正常高分，并说明它为什么不能由现有强简单方法吸收。不能把剩余 37 条不能由方向块重建的控制连接直接当成创新依据：其中 23 条来自 AIT、14 条来自 Unraveled，是否是攻击特有差异尚未建立，而正常连接也存在不能重建的情形。本轮不因这 37 条追加来源、增加窗口、改阈值或启动拟合。
