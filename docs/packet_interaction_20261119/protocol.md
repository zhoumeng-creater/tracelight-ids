# 连接内部交互：本轮问题与分析口径

本轮使用已经取得、已经开放的 AIT santos／fox 和 Unraveled 原包，检查连接内部交互是否提供值得建模的信息。OpTC 目前只有日志，不能从流统计还原 SEQ／ACK。不读取 russell 校准来源、harrison 或 Meterpreter；不修改已冻结四臂。

分析在读取本轮包级结果前确定。只抽取头部字段和长度，不读取应用载荷内容；不训练分类器，不搜索阈值，不将描述性差异报告为检出率。

## 需要回答的三个问题

1. **可观测性**：真实正负连接能否可靠关联原包？握手、字节缺口、截断、重传和乱序如何影响内部交互？所有未关联和多候选保留。
2. **信息价值**：在同主机、同协议／端口且尽量同时段的正常业务中，攻击是否呈现不同的字节交换结构？分别报告控制和下载。包头新增信息相对 raw8 的价值，与新学习机制的价值分开。
3. **算法差异**：相对 FG-SAT（TIFS 2025）的包图、方向流段，以及相同信息下的去重＋合段＋简单聚合，是否仍有不可约的机制？若可严格等价实现，不给两个写法安排模型实验。

## 固定描述

- 包→连接沿用已有 Unraveled 映射；AIT 按双向五元组与 Zeek 观测区间匹配，保留全部候选。
- TCP 序列号只用于连接内相对字节坐标，MAC、IP、端口、绝对 SEQ／ACK 不作拟议模型特征。端点只用于关联和业务分组。
- 对每个方向，保存首次观测的唯一字节区间及其 ACK。纯 ACK 不增加字节质量，后见重传不覆盖首见区间的 ACK。
- ACK 仅表示对端 TCP 的累计接收确认，不表示应用已执行命令。ACK 对查询截止时已观测对向字节的覆盖可在完整连接决策时计算；不能倒填到首包。
- 报告包数、唯一字节、重复覆盖字节、方向切换、方向字节块、确认前沿、以及前 20 包覆盖的字节比例。20 来自 FG-SAT 原文的既定比较位置，不从本数据调选。
- 正常全体、同服务正常、攻击活动期间正常分别描述；没有同时段正常时明确记零。相似分布不证明所有分类器失败，明显差异也不证明跨源有效。
- 新机制首先接受代数等价和真实包细分／重复重放检查。变换只用于检查表征性质，不增加真实攻击样本数，也不充当泛化成绩。

## 本轮出口

已有字节／ACK 表示若只能重述已知方法，保留为普通控制。只有提出区别于同信息简单控制的明确机制，并从真实材料找到对应问题，才继续写候选原型。训练安排需另有固定输入、独立划分和 route-changing 问题；本轮不自动创建实验批次。
