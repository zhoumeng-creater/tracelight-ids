# 项目重审与分阶段重构

2026-11-04。本次从原始回包、实际代码和作者实现重新审查，再修改执行入口。此前的 v3/v4 复盘和同类排序撤回决定仍保留；本文记录这次新增证据、已实施修改及后续决策。它取代旧46次矩阵的默认运行建议。

## 1. 问题在哪里

项目的目标仍然成立：在网络流量特征上，以尽量少的部署成本获得低误报检测能力。失效的是推进顺序：未确认教师有什么可迁移信息、学生能表达什么，就先确定窄MLP和新损失，再扩大实验。

| 问题 | 本次核到的证据 | 对研究的影响 |
|---|---|---|
| 把检出增加当成低误报改善 | 从v4原ZIP重算：raw KD相对hard，seed17/29多TP为1/29，同时多FP为1/3；标准化pAUC差值为−0.00092064/+0.00051529，均值−0.00020267 | 总体TPR +0.0838个百分点不能说明低FPR排序改善。Fuzzers的收益同时伴随DoS、Exploits、Reconnaissance损失 |
| 用完整参考教师代替实际教学信号 | 旧OOF折模型已经封存在回包中，但现有零拟合审计没有查询其native margin | 完整F教师的表现不能证明生成OOF目标的折教师合格；补查询不需要重训 |
| 默认窄MLP适合部署 | all/MI24 × small/wide只有同一种标准化标量输入ReLU网络 | 扩宽只能检验该函数类的一部分容量问题，不能排除树式分段表达更合适 |
| 文档撤回、运行入口仍展开 | 旧脚本默认pilot、两环境46次拟合 | 研究判断未落实到实际执行，容易继续消耗算力 |
| 用训练阶段名字掩盖预算差异 | warmup是40轮minibatch，后续是40次全F更新 | 轮数、更新步数、处理行数和墙钟时间需要分开。相同步数不表示相同计算量或优化充分 |
| 未使用的确认来源缺失 | 历史V已多轮参与开发，旧test已打开 | 更换模型或重新划分不能恢复独立性；当前结果只能用于开发研究 |

原始工件、每族配对和计算口径见[独立证据复核](PROJECT_EVIDENCE_REVIEW_20261104.md)。前五轮的字段/部署收益、数据校验、演示和失败记录均保留；本轮不借用它们证明KD有效。

## 2. 重建研究问题

主问题改为：**在可部署的学生函数类中，教师是否提供了超出直接标签学习和直接低FPR目标的增量？**

这要求依次回答四个问题：

1. **部署候选是什么？** 比较实际包大小、CPU单条p95、批量吞吐和低FPR效果。未给定设备硬上限前保留Pareto关系，不凭“参数少”指定赢家，也不编造毫秒或内存要求。
2. **教师有什么额外信息？** 看低FPR余量、错误互补、逐族支持、训练目标是否退化或几乎等于hard标签。教师总体更准、训练内置信度更高都不够。
3. **学生接收得了吗？** 同字段下比较神经网络和受限树；字段减少与学生容量分别记录。完整教师依赖学生不可见字段时，先做同信息教师控制。
4. **增益来自知识吗？** 相同学生、标签、拟合池、初始化/随机规则和选择预算下比较hard、普通KD、同类固定置乱KD；神经学生另保留direct pAUC及pAUC+普通KD。

先建立这个底座，再根据剩余失败提出一个有必要的改动。当前不追加同类排序、风险guard、解释器、合成查询或新的多教师组合。

## 3. 已实施的算法与工程调整

### 3.1 实际OOF教师的零拟合查询

扩展原`audit_upgrade_thresholds_lab.py`：读取封存的fold模型和固定成员关系，逐折查询其F-heldout、R、C；native分数与精确旧clip分数分别保存。在每折R上固定各自阈值，再报告该折heldout/C事件、pAUC和家族支持。

不跨折混排raw margin；聚合只合并使用各自冻结阈值后的事件。OOF部分不查询V、不新增拟合。原有完整参考教师V诊断仍保留并单独标注；不能把整个审计说成完全不读V。

这些结果可以定位“教师没有目标区域信息”“信息被clip破坏”“分折支持不足”，不能证明新学生必能吸收知识。

### 3.2 原生类别树基线与普通软标签接口

新增`native_trees.py`，采用官方CatBoost 1.2.10，保留原始类别字段、F内量化/类别统计、float64原生margin及完整CBM模型。两档初始树容量是64棵深度4、256棵深度6，学习率0.05、L2为3、128个数值边界；这是两个预定探针，不是调优后的方法上限。

hard和soft统一使用`CrossEntropy`，行权重均由F中的hard标签计算。若KD系数为λ，则软目标为：

\[
q=(y+\lambda p_T)/(1+\lambda).
\]

温度为1、行权重相同时，`BCE(y,p)+λKL(pT||p)`与`(1+λ)BCE(q,p)`对学生的梯度相同。适配器训练归一化后的目标；它没有声称缩放前后boosting轨迹一致。λ也不是0到1的混合比例，混合比例为λ/(1+λ)。这是一项成熟方法适配。

CatBoost类别统计可能随soft目标改变，因此若有效，首先归因于完整学生训练的KD增量；不能单凭结果说是叶值平滑。新screen只训练两档hard树，soft API先通过合成验证，不自动进入真实KD矩阵。

[原论文与固定作者源码审查](research_alignment_20261104/student_class_and_teacher_review.md)解释为何先选这个对照。已有TabM+数值嵌入是后备学生，不重复实现新网络；TabICLv2是有条件的后续教师候选。TabPFN3.5-Thinking的API发布不当成本地checkpoint。

### 3.3 默认入口改成只做F/R/C筛查

新`screen`为默认profile。每环境、seed17固定12次拟合：

| 拟合 | 数量 | 回答的问题 |
|---|---:|---|
| HGB，全字段/MI24 | 2 | 同一教师算法的字段依赖及软目标内容 |
| hard MLP，全字段/MI24 × small/wide | 4 | 相同warmup阶段的输入和容量差异 |
| small MLP，两个字段预算各hard/direct pAUC | 4 | 相同继续训练预算下，直接任务目标是否已足够 |
| 原生CatBoost，全字段、两档容量 | 2 | 不同学生函数类的直接学习效果与实际成本 |

两环境共24次，只有原矩阵的约52%，且不训练任何新KD候选。减少拟合数不是本轮方法贡献；价值在于这些结果能决定是否应开展KD。零拟合审计仍先执行，若它已揭示关键前提不成立，先修前提，不机械启动24次。

新screen只解析F/R/C身份并读取prepared train；旧包中V工件仅做字节完整性核对，不解析V结果。R/C共同注册阈值、C做开发选择，输出全部模型及失败信息，不把C称为独立校准。CPU管线在C上取固定样本测量，不借读取V进行计时。

旧pilot/full仍保留作显式机制对照；旧tag、旧恢复校验和历史结果不重写。默认PowerShell入口使用包含脚本的当前clean checkout，避免默默clone到旧46次矩阵的tag。未完成运行继续保留，当前没有逐模型中断恢复；不得把complete-only核验写成断点续训。

## 4. 实验计划和停止条件

| 阶段 | 输入/预算 | 产出与下一步 |
|---|---|---|
| A：已有模型审计 | 新拟合0；原v3/v4工件 | 定位实际OOF/native/clip、阈值和家族支持。不能只看完整F教师 |
| B：基础筛查 | 相同F/R/C；两环境各12次，seed17 | 所有模型的检测/资源坐标、教师内容与互补。先完成两环境，不能事后只扩展有利环境并泛化结论 |
| C：单一蒸馏假设 | B结果确定一个学生/字段/教师后，先另行冻结有限配置 | 树学生：hard/普通soft/固定置乱soft；神经学生加direct pAUC与pAUC+soft。先解决对照，不增加新命名 |
| D：稳定性及确认 | C支持明确增量才扩展预定种子；另取得未使用来源 | 三seed只反映优化随机性。旧V可作为晚读历史开发检查，新的独立确认另行冻结 |

阶段C尚未冻结：若现在指定教师、架构、系数和全矩阵，就会重复先定方法再寻找支持的错误。后续协议需记录每次尝试的时间/样本处理量和所有调参机会，避免hard只用默认值而KD获得大量搜索。

决策应改变实际工作：

- 教师在目标区域缺少优势和有用互补：停止该教师的KD扩展；必要时仅补一位已核实的公开教师，不开模型排行榜。
- 教师目标几乎等于hard：普通KD主要重复监督，先检查教师训练内过拟合/信息表达，不靠增大λ制造差异。
- 更大的直接树已达到所需部署成本：将它保留为实际候选；缩到更小学生必须说明额外节省是否值得检测损失。
- 普通KD不超过同学生hard/direct pAUC：保留负结果，当前教师/学生组合不再扩展自定义损失。
- 真实soft与固定置乱soft相当：撤回实例知识解释，检查平滑/正则作用。
- C改善但晚读V恶化：记录开发过拟合，不用V重新选阈值或回调配置。
- 攻击族支持缺失或单巨组占据：按支持报告，不能拆组或换seed凑成绩；低支持族不作稳定提升主张。
