## 研究设计现在如何处理

维持低误报检测、控制与下载分别评价、实质算法创新、2025—2026 直接近邻、实际成本和完整展示要求。没有约 35KB 学生、顶会级创新、跨任意未知网络、同一新方法包办所有攻击的永久要求。旧 R30/R31 的零损失合同保留原判定；它不自动成为此后每个候选的永久硬门。

先固定预测对象、预测时刻、允许输入、监督范围和目标来源，再讨论机制。一个算法可以针对一个具体困难提出改动，控制／下载和其他已登记能力仍完整报告；不得靠删去退步任务获得成功。完整流、进行中的报文、主机日志对应不同信息条件；改变其中一项须说明，不能悄悄混用。

最终证据仍须包含按数据时间划分的新前向时段；阈值只使用当次告警前可得材料，方法及选阈值规则在确认前冻结。当前 fox／OpTC 的异源开发比较不替代这项证据。角色隔离按已冻结的采集、攻击链或正常活动组执行；本四臂采用整 run／campaign，不把整来源唯一角色推广为永久条件。

在[创新机制探索与原型](innovation_mechanisms_20261119/index.md)之后，已完成[真实先后关系核验](real_order_evidence_20261119/index.md)：125,987 条背景观察、56,220 个查询，未使用 C 或保留来源。正常业务也继承攻击历史；Unraveled 同期正常与攻击表示重叠，匹配后差异仍受当前形态或业务时段影响；OpTC 下载的大方向主要对应少数未知协议／缺失记录的先后位置。当前证据没有建立攻击特有关系。

同信息、同状态量的 P/B 近邻在所有真实查询上都能重建候选读取，最大误差约 6.456×10⁻¹⁴。相对同维度读取，候选实质提高低共现量关系的权重，没有建立该偏置的业务依据与实质创新。因此当前比例记忆版本结束探索，不送实验室训练，不补采来源或扫描半衰期／门控；结论不推广为所有历史模型无效。原始推导、正负事实和完整读取结果均保留。

另外两条路线已获得明确的设计结论：精确条件正常参照在现有 F 中缺少攻击配对、跨来源正常配对，并不能修复 R30 的成分中心高分；简单 Jacobian 正交投影在平方蒸馏中产生相同首步更新。它们不通过追加门控、风险权重或阈值继续试跑。原始问题与要求仍见[设计重建](research_history_20261119/design.md)。

本轮继续完成[连接内部交互研究](packet_interaction_20261119/index.md)：从已有原包抽取 4,961,557 条 TCP 头，形成 8,514 条已开放目标连接的唯一字节与 ACK 映射。518 条 HTTPS 控制仅有 3—11 个 ACK 段，其中 481 条的数据字节前缀映射能由普通方向字节块恢复；该结论不包括纯 ACK、时间或窗口属性。两条恶意下载的归一化拓扑与 329 条小型正常 HTTP 响应相同，这不是等体积下载对照。

字节加权 ACK 前缀算子已写成明确更新式，但基础形式与合段后的加权集合聚合精确等价；查询保真压缩虽可推导误差界，现有段数和项目预算不支持采用。两者均不进入新训练。包输入暂保留为完整阶段信息的简单控制，不能将新增信息或多看包的收益称作算法创新。FG-SAT、FSG-NID、C2Detector、FastFlow 的机制和实现边界已登记；当前四臂无回传，不预设它们的失败模式来设计新模型。

[完整正常参照下的阶段偏离学习](stage_conditional_design_20261119/index.md)的后续真实验证已经完成，当前决定以[正常参照覆盖、必要性与缺口修复](reference_evidence_20261119/index.md)为准。旧候选不再保留为待运行创新臂。

正常库有 6,840 条合格 F 连接、2,797 种精确序列。排自身后的 4,536 条精确支持全部来自同一 capture；fox 的 422 条合格正常无完整精确支持。但相同段数／方向域内，fox cloud、intranet 的最优完整字节倍率中位数仅为 1.117、1.026，说明多数连续接近；95% 分位分别为 2.467、17.097，尾部支持不均。它们不是异常分数或误报率，也不能评价可变长 DTW。库中仍没有充分覆盖各正常单元的证明。

410 条 F 正常连接每个位置都有其他正常连接精确支持，却无完整精确参照；这些不是误报计数。520 条控制和 2 条下载每条至少有一个方向／字节 token 未在 F 正常库出现，尚未找到需靠完整组合约束识别的攻击实例。这不等于简单阶段方法已检出全部攻击。完整参照约束确有数学区别，但本轮撤下其创新主线定位，不以补数据或调阈值继续该候选。

旧可学习 null-gap 允许只匹配共有首段、其余阶段走低成本空节点，结束探索。已另行实现无损相邻成对、完整无 gap 瓶颈 DTW 与真实尾段比较，并保留相同局部学习成本的可微普通对照；后段不再能被删除，路径与梯度检查通过。真实材料中 31 个正常等价组表明 DTW 仍会忽略相同完整对的重复次数。这是标准匹配的适配，没有获得新算法或真实检测收益，不安排新训练。

正常数据、动作多候选、精确与连续支持事实以及局部标签不确定性继续保留。

2026-11-20 固定新的[正常校准迁移研究主线](normal_tail_mechanism_20261120/index.md)：以 R30 已有正常支持仍整组成高分、组成变化放大误报为具体问题。近期 CRT 2025 已有校准反传，因此新主张仅是用真实前后正常组成训练、使后期整数预算边界不超过前期校准边界，并保持攻击相对同一阈值的分离。现有 F 可形成四个自然日前后情境；不读取 C／保留源，不新增预测信息。

双顺位差的计数等价、双边梯度与抬阈值／缩放／塌缩反例已经实现。最低比较固定为普通 BCE、同目标打乱时段对应、真实先后对应三臂；三个既有种子成对重复。当前为设计及算子原型，不是已完成训练包或成立的算法创新。后续继续三臂同预算实现，不恢复已关闭候选；各类结果的采用／结束出口已写定。

## 四臂的固定用途与结果出口

已授权的执行方式仍是实验室从 GitHub 拉取后一次运行，没有远程入口。正式命令和输入继续使用[原实验室说明](COVERAGE_BATCH_LAB_20261119.md)；本次没有修改其 tag、注册、模型、阈值规则或数据。

主臂始终为 `mixed_ports_zero`。主开发解释只使用 fox 的 V 与 OpTC 的 external_development；训练内、正常校准、未知背景分别呈现。四臂的增失是各自拟合和 C 校准后的流程比较，不是单一来源多样性或纯排序变化的因果结论。

回传后使用 [summarize_coverage_outcomes.py](../scripts/summarize_coverage_outcomes.py) 读取已存判决，生成中文得失报告。它不加载模型、不重新评分、不计算新阈值、不选赢家，也不生成算法成功标记。运行方式见[结果出口](research_history_20261119/outcome_policy.md)。

四臂全部报告后，这个覆盖／端口问题即结束。描述性比较不需要临时补一个任意最低召回数；若要作采用结论，必须另有事先明确的能力要求和确认材料。结果不会自动触发新增来源、种子、窗口、阈值或模型。
