# 四臂回传后的固定解释

主臂固定为 `mixed_ports_zero`。本页不修改 `coverage-baseline-batch-v1` 的任何输入、参数、校准或判决。原批次没有总体采用门槛，汇总也不生成一个事后的成功标准。

回传整个原输出包后，在含本脚本的新研究分支运行：

```powershell
python scripts/summarize_coverage_outcomes.py --results 'D:\Research Work\results\coverage-basis-20261119' --output 'D:\Research Work\results\coverage-basis-20261119-interpretation'
```

也可在整理回传的本机运行。脚本只读原结果，不要求实验室重新拟合或评分，输出目录使用新位置。缺少四臂或必要结果时指出缺失文件，不把不完整运行当成已完成实验。

主报告使用 V 与 external_development；训练来源、C 和背景另列。每个角色分别报告控制／下载流 TP/FN、正常分母及逐单元整数预算、四组配对新增／丢失。未知仍是未知，其告警不能计入正常 FP 或攻击 TP。事件下界和上界保留，不能用最有利候选补成确定命中；事件数和流数不相加。

收益、负迁移、端口处理差异和任务取舍可同时出现。一个来源的收益不能抵消另一个来源的退步；总 FPR 不能抵消单元超标。程序不选赢家，不把信号不确定写成“所有模型无效”，也不据结果自动推荐历史、图、蒸馏或新阈值。

模型包和批评分成本沿用原回传口径，不换算成端到端单条告警延迟。相同 seed 的四个模型不是四次独立部署，473 条新增 C2 不是 473 个独立攻击实现。

报告完成即结束本次监督覆盖／端口比较。若希望将某个模型作为最终采用方案，能力要求与独立确认须另有依据，不能由这份描述性报告倒定。
