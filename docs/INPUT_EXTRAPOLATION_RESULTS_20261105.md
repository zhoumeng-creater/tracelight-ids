## 2. 机制与错误代价

四份CIC reduced工件在固定旧阈值下均恢复同一2,272行完整模式。small warmup与direct的原／裁剪R/C数组完全相同，不能算独立重复。该模式所属联合组实际有14,098行、18个完整模式，含13,949攻击和149正常；新增74个C正常误报也是组内的另一个模式。收益集中限制泛化证据，不能据此反向否定局部干预。

双方按既有R+C规则登记后：

| CIC模型 | C TP／FP：原→裁剪 | 四类C事件：修复FN／新FN／修复FP／新FP | R代价 |
|---|---:|---:|---|
| small24 warmup／direct | 66433／1822→68704／1878 | 2272／1／18／74 | 各新增6 FP |
| hard24 | 66433／1876→68705／1878 | 2272／0／72／74 | 新增6 FP、修复30 FP |
| wide24 warmup | 66444／1878→68716／1878 | 2272／0／0／0 | 新增6 FP |

small／direct新增FN的分数未变，是阈值上移造成。hard24的C正常模式分数高于目标攻击；wide24新增的R正常模式分数也高于目标C攻击。单改阈值不能同时保住相应攻击检出并拒绝这些正常模式。

UNSW的C决定均不变，仅all-wide在R修复1条Exploits，pAUC有微小变化。全字段CIC也有代价：all-small和all-direct在C各新增／修复74个FP，净值为0；all-hard的R新增6个FP。

## 3. 成本与现成简单参照

包增量0.432%–5.015%；最大分块p95比为1.243712，故全部过原门槛，不能写零成本。49.2736ms和44.0933ms两次单条长停顿保留，未删点或补测。

CIC hard24裁剪比全字段hard原模型包小49.95%、单条p95低68.11%；但C多16个FN，R多22个FN和114个FP。wide24裁剪包为全字段hard约2.25倍，R误报更多。UNSW24字段hard裁剪只比全字段hard节约12.48%包，C却少检出1,297行。这些是质量与成本取舍，不是全面胜出。

计时为实验室CPU、4线程、DataFrame到预处理与网络分数；不含流提取、文件读取或RSS。全部原始计时与前沿见[成本复核](<E:/OneDrive - Coventry University/中传/毕业论文/工作/零拟合验收分析_20261105/cost/cost_review.md>)。

## 4. 训练决定

本次审计已完整，无需为更好数字重跑。统一裁剪在F编码上恒等，同初始化、批序、损失与优化器时不会改变F训练梯度；重新跑hard最多可能因R/C评估变化改变checkpoint／早停，不能提供新的范围外监督。CIC没有新增普通KD信息依据，也不能为挽救被停止的候选自动追加PLE或损失。

UNSW普通KD的研究依据来自已有F目标内容与教师互补性，独立于本轮裁剪。下一步可保留原全字段small学生和原输入，先冻结实际教师、目标、hard／真实教师／预指定置乱与软化控制、更新和选择预算、seed及退出规则，再决定最小训练。当前不直接启动矩阵；最终确认仍需未用于开发的新来源。
