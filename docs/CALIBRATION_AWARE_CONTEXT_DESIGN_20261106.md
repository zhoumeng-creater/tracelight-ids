# 校准裕量敏感的上下文缓存压缩

2026-11-06。当前主设计；替代同日的原 HGB 拓扑内重估与剪枝提案。已完成近期方法、官方源码、目标函数与构造案例核查，尚未执行真实 IDS 模型实验。

实现进展：[完整／压缩 KV 适配器与最小编译入口](CONTEXT_CACHE_IMPLEMENTATION_20261106.md)已完成普通 QCOC 编译、官方路径合成对照与冷进程导出核查。当前输入为已预处理数值张量；逐状态敏感度构造、CRT 对照和真实 IDS 比较仍是后续阶段。

## 1. 改变研究对象

TraceLight 的新问题是：**在正常误报率目标固定时，怎样压缩一个近期表格基础模型的持久上下文，使少量关键状态不被大量普通状态淹没，并降低完整部署成本？**

旧路线先固定小模型、教师或已有树分裂，再解释为何压不进去。它缺少两项积极依据：待传递的信息确实能改善实际工作点，以及所选表示能保留这些信息。新路线先用完整近期模型建立能力参照，再研究有明确物理预算的表示压缩。完整模型若在目标数据上没有值得保留的低误报检出能力，这条压缩路线就没有成立的前提。

选择 **TabICLv2（ICML 2026）** 为冻结骨干，使用 **QCOC（2026-10）** 的共享 KV 编译框架；新增机制是**每个源状态对攻击分数与正常校准边界之差的敏感度，决定哪些状态可以合并**。所有查询共用一个编译后的缓存，在线不再选择上下文或调整模型。

固定每层每头的缓存槽数 M，先满足物理预算，再比较校准后的检出。成本不再只是精度相同时的附带偏好；也不预设必须压成几万字节。模型权重、列缓存、预处理和推理内存全部计入。

## 3. 要解决的具体失配

普通缓存压缩主要保留平均算子输出。低误报判定却取决于攻击分数相对正常分数上尾的位置。平均误差很小，仍可能把少量正常尾部推到攻击之上；反过来，全部分数一起平移，即使原始分数误差很大，校准后的判定也不变。

另一个问题发生在原型合并阶段：若把区分正常尾部和攻击的两个 key 合并，两个查询可能得到相同注意力权重。此时固定 key 后如何调整 value，都无法恢复这两个查询的区分。

因此，首版只改变一处：**原型分配及原型坐标的代价**。骨干、槽数、数据、精度与部署结构固定。QCOC 加 CRT 式 V-only 调整作为直接竞争者保留，不叠进主方法。

## 4. 数据角色与评分定义

| 材料 | 用途 | 可影响什么 |
|---|---|---|
| 支持集 P | 拟合预处理、构建列缓存与完整 Stage 3 缓存 | 完整模型的上下文 |
| 开发查询 Q | 计算校准裕量的敏感度 | 压缩原型；属于训练用途 |
| 选择材料 S | 候选真实前向，各自重算正常阈值，比较预算点 | 方法与 M 的选择 |
| 独立正常校准集 C | 模型与预算冻结后只确定最终阈值 | 最终决策阈值 |
| 独立评价集 T | 评价冻结模型及阈值 | 不再反馈设计或选择 |

按来源、会话及重复组处理跨集合关联。Q、S、C、T 均不进入 P 的预处理或列缓存；从 Stage 3 删除某一行不能消除它已进入列状态的影响。旧 R/C/V/test 已参与开发或揭晓，不承担新方案的独立确认。

首版使用一个集成成员，以减少机制比较的混杂；其余对照也相同。完整官方默认集成配置另作系统参照，不能把成员数减少的收益记到压缩上。若以后使用多成员，评分固定为类别顺序对齐后的平均二分类 logit 差，梯度必须穿过相同聚合器。

定义分数 s(x)=logit_attack−logit_normal，越大越倾向攻击。目标正常误报率 α=0.01，报警规则严格为 s(x)>τ。对于 n 个正常分数的升序序列，采用

\[
r=\left\lceil(n+1)(1-\alpha)\right\rceil,\qquad
\tau=\begin{cases}s_{(r)},&r\le n,\\+\infty,&r>n.\end{cases}
\]

并列分数全部按严格比较处理。若开发折的 r>n，该折不能提供有限正常边界，应报告材料不足，不用另一个随意分位替代。最终模型冻结且正常校准数据独立、可交换时，此规则对应对校准随机性取平均的正常误报控制；它不是一次校准后以 95% 置信保证总体 FPR≤1%。分布漂移也不由这条规则消除。

## 5. 核心算法：逐源状态的校准裕量几何

### 5.1 对可替换缓存求导

完整支持缓存由 P 一次构建。把每层每头的 K、V detach 为独立叶变量，冻结骨干权重与查询前两阶段表示。求最终分数对这些变量的偏导，保留查询经过后续层的路径；不反传穿过支持缓存的构建过程。

令某一层、某一头的第 i 个源状态为

\[
z_i=[k_i/\sigma_K;v_i/\sigma_V]\in\mathbb R^{2d}.
\]

σ_K、σ_V 是该头全部源 K、V 元素各自的标量标准差，零标准差取 1；不按单条状态独立归一化。

将 Q 按隔离组固定拆为 A、B 两折。两个开发情景分别使用 A 的正常样本决定边界、B 的攻击样本计算裕量，以及 B 正常、A 攻击。令情景 e 的完整模型正常边界为 c_e，攻击查询集合为 Q_e¹。边界唯一且排序局部不变时，

\[
m_e(x)=s_F(x)-\tau_e,\qquad
D^{(e)}_{x,i,r}=\frac{\partial s_F(x)}{\partial z_{i,r}}
-\frac{\partial s_F(c_e)}{\partial z_{i,r}}.
\]

边界并列时，对所有处于该边界分数的正常查询梯度取平均，作为非光滑点的一个确定选择。实际评价始终重新计算真实排序，不使用这个局部导数代替阈值。

### 5.2 不把状态索引平均掉

攻击等权，不加温度、攻击族权重或可学习门控。每个头累计

\[
g_{i,r}=\frac12\sum_{e=1}^{2}\frac1{|Q_e^1|}
\sum_{x\in Q_e^1}\bigl(D^{(e)}_{x,i,r}\bigr)^2.
\]

必须保留 i。可给整个头的全部 g 乘同一个正标量稳定数值；禁止每个状态各自归一化，那会抹去状态间敏感性的区别。需要平均的是**各查询梯度的平方**，不能先平均梯度再平方。

### 5.3 以固定 M 构造原型

通常每个源 token 的质量 n_i=1；N=Σ_i n_i。若为了合成算术合并完全相同的源状态，g 仍定义为单个原始 token 的敏感度，再以 n_i 计入代理。

求 M 个联合原型 μ 与分配 a，优化

\[
\mathcal D(a,\mu)=\sum_i n_i\sum_{r=1}^{2d}
g_{i,r}(z_{i,r}-\mu_{a(i),r})^2.
\]

这是状态相关的分配代价；不能把它实现成全头统一缩放后调用普通欧氏聚类。固定原型时按各状态自己的代价分配；固定分配时，逐坐标更新

\[
\mu_{j,r}=\frac{\sum_{i:a(i)=j}n_i g_{i,r}z_{i,r}}
{\sum_{i:a(i)=j}n_i g_{i,r}}.
\]

分母为零则取该簇的普通源质量均值。全头 g=0 则返回 QCOC 的普通几何结果。距离并列先比较标准化欧氏距离，再比较原型编号。

初始化沿用 QCOC 的确定性最远点框架：在标准化联合 KV 上使用普通欧氏距离，不以源质量改变选点，首源 ID 固定，所有几何对照使用相同源 ID 的初始原型。最多 15 次分配与中心更新。按 QCOC 原文第 3.2 节，最后一轮分配 C 用于确定中心，再对最终中心重分配 D 用于统计质量，二者分别记录；此前“不再重分配”的设计措辞已修正。普通 QCOC 按欧氏代价重分配，拟议逐状态方法按自身代价重分配。空簇从含至少两个源状态的簇中取当前失真最大的源状态修复，按源 ID 解平局；最终 D 修复只改变质量分配，不追加中心更新。M 不超过源状态数，有限轮数不保证全局最优。

最终原型反变换回 K/V。每槽注意力质量为 w_j=Σ_{i:a(i)=j}n_i，Σ_j w_j=N；**w 不能换成敏感度之和**。

### 5.4 完整编译与真实评价

以原型 V 为锚，沿用 QCOC 的完整支持查询、完整注意力输出目标和固定岭系数完成 V 拟合。这里的查询来自完整模型的支持前向，不随前层压缩重新生成；所有层拟合结束后再组装候选。拟合求解线性系统，不显式计算矩阵逆。

每层每头部署状态为 (K̃,Ṽ,log w,N)。其注意力写成

\[
\widehat a(q)=\operatorname{softmax}\bigl(\phi_N(q)\widetilde K^\top+\log w\bigr)\widetilde V,
\]

φ_N 包含官方 QASSMax 与缩放点积分工，必须保留原始 N，不能因为物理缓存变短而改为 M。Stage 1 的长度语义保持原样。

候选在 S 上执行完整真实前向，用**候选自己的正常分数**重新确定 τ，再比较攻击检出；不能沿用完整模型的旧阈值。选择完方法和 M 后，才用 C 决定最终阈值。

```text
COMPILE(P, Q, M):
    fit preprocessing and build full column/ICL cache from P
    freeze backbone; collect full-support attention queries and targets
    cache query representations for Q through the frozen column/row path
    for each layer and head:
        expose its full K/V as independent differentiable cache variables
        accumulate mean per-query squared calibration-margin Jacobians
        construct M prototypes using source-specific allocation and centroids
        retain true source counts; keep original attention length N
        fit prototype V using the unchanged QCOC anchored solve
    assemble all compressed heads; export a candidate without full row storage
    return candidate

SELECT(candidate, S):
    execute the complete candidate; recompute its normal threshold on S
    compare actual TP/FP and complete cost against registered controls

DEPLOY(frozen_candidate, C, new_rows):
    calibrate threshold once from C normal scores
    preprocess each new row -> Stage 1/2 -> compact Stage 3 -> score > threshold
```

主候选只计算一次完整缓存敏感度，不增加外层重编译搜索、可变层预算或额外 V 监督训练。

## 6. 机制证据与尚未成立的部分

代理来自 δm≈Σ_i D_i·δz_i，然后忽略平方中的跨坐标、跨状态项。它是可计算的一阶对角近似，**不是全模型裕量误差的上界**。大幅压缩会改变正常边界排序；多层同时压缩会改变后续查询；最后的 V 拟合也会移动原型值。三者都必须经过完整候选的真实前向检查。

已有[参考程序](research_alignment_20261106/calibrated_context/geometry_reference.py)构造四组状态、100 个源 token，固定压成三个槽，并穷举六种两两合并分区：

| 构造准则 | 选择合并 | 重新校准后 TP / FP |
|---|---|---:|
| 完整四组状态 | 不合并 | 1000 / 0 |
| 普通标准化联合 KV 失真 | 两个关键状态 | 0 / 0 |
| 曾考虑的全头共享敏感度 | 同样两个关键状态 | 0 / 0 |
| 保留源状态索引的敏感度 | 两个背景状态 | 1000 / 0 |

关键状态合并后，正常尾部与攻击的注意力向量完全相同，所以任何固定 K 的 V 调整都无法在该单头例子中恢复区分。共享头敏感度因此已撤回。六分区结果证明新准则在这个例子中偏好正确分区。

随后补入了[实际迭代求解检查](research_alignment_20261106/calibrated_context/solver_reference.py)：相同欧氏最远点初始化选出源 ID [0,3,1]，普通几何和逐状态几何在 15 轮后都得到背景合并，均为 TP=1000、FP=0。另查敏感度最远点初始化也得到同一好分区，首版不增加它。**这个案例没有证明新迭代算法优于普通迭代算法。** [求解结果](research_alignment_20261106/calibrated_context/solver_reference_results.json)与穷举结果共同保留；后续 V 拟合和完整 TabICLv2 尚未核验。

程序另核对了解析梯度与有限差分、真实质量计数、整体分数平移不改变判定，以及正常分数 MSE 仅 0.00125 时检出仍可归零的反例。[机器可读结果](research_alignment_20261106/calibrated_context/geometry_reference_results.json)保留全部数值。当前证据支持继续验证这项具体机制，尚无 IDS 检出提升或真实加速结果。

## 7. 能推翻设计的比较

| 比较 | 共享条件 | 回答的问题 |
|---|---|---|
| TabICLv2 完整 KV | 同 P、输入、checkpoint、精度、成员数、校准规则 | 完整模型有没有值得压缩保留的能力？ |
| QCOC 原版几何与编译 | 同 M、骨干、支持查询及拟合系数 | 改变几何是否必要？ |
| QCOC＋CRT 式 V-only 适配 | 同 Q 标签、正常边界、选择材料；独立记录离线预算 | 保留普通原型，只改 V 能否解决？ |
| 不减正常边界 Jacobian 的相同几何 | D 换为攻击分数 Jacobian，其余相同 | 收益是否确实来自校准反馈？ |
| 全头共享敏感度消融 | 同初始化、预算和编译流程，仅对 i 平均 | 保留源状态索引的必要性是否超出构造准则？ |
| TACO 2026 官方模型 | 同可用数据与完整资源口径，模型差异单列 | 相对近期专用压缩架构是否仍有实际价值？ |

QCOC 原方法不使用 Q 标签。报告中明确这一监督差异，不能把相对它的全部收益归为新几何；同标签的 V-only 与去边界对照承担因果解释。V-only 使用校准后攻击效用的可微目标，仅更新缓存 V，其具体更新预算在实验协议中与新增梯度编译成本一起冻结。

首版比较 M/N∈{1/8,1/16,1/32}，取不超过 N 的有效整数槽数；这些是预算点，不是三个独立算法。完整材料选择前不得根据旧测试错误挑 M。报告每个预算点的实际缓存字节、完整包、RSS、单条 p95、批吞吐和一次编译成本。

主结果用固定 α 下的攻击召回、实际正常 FPR，以及相同查询上的修复/新增错误；同时报告攻击族与来源分组。置信区间和独立评价的统计单位须服从来源关联，不能把重复流量行当成独立重复。

如果完整模型缺少有效检出，停止这条保留能力的压缩路线。如果原版 QCOC 或同标签 V-only 达到同等或更好的检测—成本关系，撤回新几何的必要性。如果去边界对照不差，撤回“校准反馈产生收益”的归因。如果只有缓存变小而完整成本没有改善，只能报告缓存压缩，不能声称系统轻量化成功。

## 8. 真实部署结构与完整成本

保留：骨干权重、预处理参数、Stage 1 列 KV、每层每头紧凑 Stage 3 KV/质量/原 N、冻结阈值。移除：原始支持行、标签数组、预处理缓存行、完整行表示、完整 Stage 3 KV、编译查询和梯度。导出后用冷进程只读紧凑包验证依赖。

设 A 为成员数、L 为 Stage 3 层数、D 为其宽度、H 为头数、b 为每个元素字节数：

\[
S_{\rm fullKV}=2ALND b,\qquad
S_{\rm compact}=2ALMD b+ALHM b_{\rm mass}+S_N.
\]

\[
S_{\rm deploy}=S_{\rm weights}+S_{\rm preprocess}+S_{\rm columnKV}
+S_{\rm compact}+S_{\rm metadata}.
\]

以官方分类结构、A=1、FP32、42 个有效字段、N=8192、M=512 为**源码推导示例**：Stage 3 KV 为 384→24 MiB；质量约 0.1875 MiB；列 KV 约 17.25 MiB；仅 Stage 3 主要权重矩阵就至少 96 MiB。因此缓存槽缩小 16 倍时，完整常驻张量的缩小比例至多约 3.62 倍，实际 RSS 收益还会更小。这不是硬件实测。

在线查询的上下文注意力项由 O(ALBND) 变为 O(ALBMD)，但前两阶段、投影和 FFN 不消失。新增敏感度累计每头约 O(2|Q_e¹|Nd)，累计存储 O(Nd)，还需完整模型前后向及批级激活。聚类每轮 O(NMd)。QCOC 原有编译仍包含支持查询目标和线性拟合，不能把离线编译视为免费。

分别记录编译时间、峰值内存和模型前后向行数。只有单次查询节省为正，才计算摊销查询量：额外编译时间 / 每条查询节省时间。

官方 FlashAttention3 分支不支持所需的自定义质量 bias。必须同时给出“相同后端的完整 KV 对照”和“官方最快可用完整 KV 对照”，避免把后端差异隐去。CPU 与 GPU 分开，B=1 延迟与固定批量吞吐分开。

## 9. 实现接口与交付顺序

官方版本固定为 `d83091b845a8c5f7c087bd54964f755a9e560f45`，checkpoint 名为 `tabicl-classifier-v2-20260212.ckpt`；权重尚未下载，运行前还需锁定文件哈希。[源码审查与成本推导](research_alignment_20261106/calibrated_context/architecture_and_cost.md)列出文件定位。

| 待实现接口 | 必须保持的语义 | 第一项核查 |
|---|---|---|
| `FullCacheAdapter` | 官方完整 KV 的评分、预处理和标签顺序 | 未压缩时与官方缓存路径一致 |
| `DifferentiableStage3` | 冻结权重，独立缓存叶变量，保留残差/FFN/decoder | 缓存方向导数与有限差分；不能直接调用被 no_grad 包裹的 predict_proba |
| `MarginSensitivity` | 两折边界、逐查询平方、源状态索引 | 不出现平方平均梯度、重复质量或查询标签入缓存 |
| `StatePrototypeCompiler` | 共同初始化、状态相关分配与逐坐标中心 | 固定 M、真实质量、零敏感度与空簇语义 |
| `WeightedKVEntry` | key/value/log_mass/source_count | 迁移、拼接、切分、序列化后四项均保留 |
| `CompactPredictor` | 只访问紧凑包，原 N 缩放 | 冷进程预测一致；无原始库与完整缓存依赖 |
| `ComparisonRunner` | 所有候选各自校准，完整成本口径 | 同信息对照与逐行修复/新增记录 |

实施先完成官方完整缓存与压缩缓存的同语义适配，再做梯度及原型编译，最后接实验室对照入口。真实训练、近期方法对照和正式资源测量仍在实验室 RTX4090D；本机只进行代码、数学与合成核查。

拟议论文贡献集中为一项：**在给定上下文缓存预算下，利用逐源状态的校准裕量敏感度决定原型构造，以保护普通几何和固定 key 后 value 调整可能丢失的判定信息。** 基础模型、缓存复用、质量修正、原 N、V 拟合与校准反馈分别归属于所采用的 2025—2026 成果。
