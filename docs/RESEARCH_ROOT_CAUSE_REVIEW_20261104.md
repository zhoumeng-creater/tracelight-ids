# 根本设计复盘：保留课题，重建算法贡献的证据链

2026-11-04。针对用户提出的“是否从问题定义、创新思路和构造就有偏差”，本次回看正式课题、2026-10-27原规划、各轮设计／作者论文与实际回传，而不是只修v4代码。结论是：**原始课题方向合理，但现有v3/v4不足以作为已经成立的核心方法创新；研究主线需要重构。**

本次推进的不足在于：工程记录、约束和对照逐渐完善，却没有让“蒸馏为什么必要、哪些知识可被小学生利用、它比强简单方法增加什么”成为新算法启动前的硬门槛。继续增加模块或训练次数不能补齐这条证据链。

负结果本身不等于最初设计错误。这里作出上述判断，依据的是目标漂移、贡献与近邻重叠、目标表示退化、阈值限制排除已有可行系统、确定性拒绝吸收态及教师资格缺口，而不只是因为分数不好看。

## 1. 原始问题没有错，贡献构造尚未成熟

正式题目为 **Research and Implementation of Lightweight Machine Learning Methods for Network Intrusion Detection**。原题及10/27规划要求公开数据、随机森林／小型神经网络、字段筛选、攻击召回／正常FPR／推理时间及可操作演示。资源—检测取舍具有明确研究与应用意义。

原规划当时已经说明，稳定选择、冗余控制、蒸馏或量化只是待验证方案，组合不能自动成为创新。后续用户进一步明确要求完善知识蒸馏、算法设计与前沿近邻，这一要求仍有效；不能用“最初蒸馏可选”来取消现在的研究任务，也不能预设KD一定取得正增益。

最初薄弱处是没有先锁定一个由证据支持的特定困难：究竟是少字段丢失信息、学生容量不足、正常尾部排序不佳、教师不可靠，还是部署工作点不匹配。几种困难需要不同方法。先把它们合成一个复杂目标，再解释失败，会让每轮局部协议自洽、整个研究主线却漂移。

## 2. 当前活跃问题偏向模型升级保护

v3/v4主要在全字段、固定小MLP `[32,16]` 上继续训练，增加原锚点TP保留、攻击族限制、代理约束、对偶更新与后置接受。模型升级非退化本身是合理研究问题，但正式需求没有给出已部署旧系统必须保持哪些历史检出、为何新增TP不能抵扣旧TP等业务契约。

因此这些保护条件目前更像研究者加上的新目标，而非由原轻量化任务推导出的必需条件。若要把升级保护作为主问题，应另有具体需求、风险定义和对应近邻；若主问题仍是轻量化IDS，资源预算与低FPR检测应保持主轴，升级保护只能在需求成立时作为条件或分支。

数据支持也不等于业务风险选择。CIC的Portscan在C中没有支持，Botnet的88行在1%预算下实际不允许丢失一条；规则在数学上可定义，却不自动说明它覆盖了最重要的部署风险。先订逐族保护口号，再按“有多少数据”开关约束，不能代替对保护范围、风险成本与统计支持的需求论证。

**同结构hard/KD学生是正确的控制。** 固定小预算比较是合法研究，不要求每轮再缩小模型；HGB教师到小MLP也确实可以是模型压缩。本项目已保存的完整F教师包约1.50–1.53MB，hard小MLP约23.4KB(CIC)／34.6KB(UNSW)，说明小学生本身具备较小磁盘体积。这里比较的是模型包而非实验ZIP；这还不是CPU速度／内存／特征提取成本证明。

真正缺口是：**同样小的hard学生也已经获得这项体积优势，KD是否在固定预算上额外保留有效检测知识，尚未证明。** 只有“教师大、学生小”不能归因于蒸馏。现有字段预算、CPU实测和系统工程应保留，但不能拿它们为新KD机制背书。

## 3. 教师资格和可迁移性没有成为前置门槛

至少有三层不同问题：

1. 教师是否在目标低FPR区域有优势或与学生形成有价值的错误互补？更高总体accuracy不是充分条件，也不要求教师每项总体指标都更高。
2. 教师的哪些信息可以被受限学生的输入和函数类表达？完整字段教师知道的内容，不一定能由少字段学生逐条恢复。
3. 这些信息能否通过所选soft目标、优化预算和损失权重传递？“教师有信息”不等于“这个KD目标有效”。

这三层没有先通过实测。完整教师V诊断还发生float32阈值回cast错误，原包中FPR=1不能用于判断教师能力；CIC正常约99.63%的边界soft target退化到0.5，说明目标表示本身也未被资格检查拦住。

监督预算还不同：完整reference教师只在F拟合，约占原train70%；实际OOF每折只在F的2/3拟合，约46.7%；最终学生hard使用F+C，约90%。完整reference教师仅是诊断，不是实际产生所有OOF目标的模型。不能用它的优势代替OOF目标质量，也不能把它与学生的差别当作公平方法排行榜。

OOF是可研究的设计选择，能控制目标的训练内拟合影响；它并非监督蒸馏唯一合法方式。在合法训练集上训练教师再给训练行提供soft targets，本身不等于test泄漏。OOF减少每个教师的拟合支持、增加拟合成本，需要与实际价值对应，而不是因“更严格”就无条件保留。

新的封存目标审查还发现一个具体支持性问题：CIC的139,618条F内Portscan都在同一联合组，它们的OOF目标全部来自fold2，而该折教师训练数据中的Portscan数量为0（仍有其他攻击样本）。三个seed的raw攻击预测中位数分别约0.001682、0.001659、0.028935，按0.5判断均未检出；按各折自己的低FPR阈值却全部检出。这不证明教师无用或OOF不合法，而是表明**有用排序、绝对置信度、家族支持与学生监督并非同一件事**。完整F教师见过该族，其质量不能替代这些实际OOF目标的资格检查。

## 4. 目标表示、代理界和任务效果被跨层联系

v3把教师相对工作点的margin取sigmoid，并明确将它定义为软报警目标，而非自然流量攻击后验。BCE接受这种soft target在数学上并不非法。缺少的是：这个表示与尺度是否保留有用信息、是否与hard目标兼容、是否对目标工作点有益。

CIC概率clip加nextafter使正常目标几乎都在0.5，EKD三阈值重合；UNSW实测raw KD首步梯度又与hard强反向。它们分别是目标退化和优化冲突的证据。仅把BCE改写成KL减去教师熵，学生梯度不变，不能算根本修复。

raw KL是必要的普通分数控制，也不是已被证明正确的最终答案。Portscan例子说明教师可以有有效的工作点排序而缺少可直接当作学生类别置信度的分数；新的传递对象要由低FPR尾部信息价值和学生可表示性决定，不能只在几种损失坐标间替换。

同样，代理可微、经验上界成立，不证明代理足够紧或有利于求解。v3许多实际事件预算可行的状态被代理拒绝；capped hinge等价表达不构成新损失。不能跨越以下链条：

> 数学表达成立 → 目标确有作用 → 优化能找到有用解 → 超过同预算hard／直接目标 → 改善部署取舍 → 与近邻存在原创差异。

每一箭头都需要自己的证据。单元测试、拟合数和正确完成标记主要覆盖工程契约，不能替代后面的结论。

## 5. “不可行”部分来自设计限制，而非模型能力

模型的决策系统由分数函数和阈值共同构成。v4先把阈值固定为当前R池允许1%FPR的最低点，再要求C也可行，这只检查一个特定注册点。

UNSW seed43、CIC seed29/43的Phase-I末态已有反证：更高的旧阈值满足全部C预算；因R报警集合随阈值提高缩小，R预算也满足。这些状态存在联合有限R+C合法阈值，v4却仍判起点失败。这里应研究参数与阈值的共同可行性，而不是继续让hard BCE在固定注册规则下跑更多步。

另外，guard完整回滚后重复相同全量梯度与同一提议，形成确定性吸收态。318次重复拒绝不是“模型还没训练够”。修复已完成停止空转和保存失败Phase-I状态，但这是实现／求解机制修正，不能当作新的算法创新。

## 6. 创新构造必须重新与最近邻对照

| 当前内容 | 合理身份 | 核心创新主张处理 |
|---|---|---|
| 标准raw KL、class-balanced reduction | 必要简单控制 | 不作为新KD发明 |
| 中心化margin／固定网格rank matching | 待验证适配 | 先排除退化与尺度解释，再对照EKD等机制 |
| capped hinge／primal-dual | 成熟代理与优化工具 | 等价式、改名或组合不构成原创 |
| post-AdamW接受／回退 | 经验可靠性机制 | 不保证总体风险、进展或收敛 |
| R+C精确阈值区间 | 基本次序统计诊断 | 不当作新NP理论，也不称R-only证书 |
| 全字段教师→少字段学生 | 合理候选问题 | LUPI／TPD已有直接先例，不能据此单独宣称创新 |
| 新表格基础模型作教师 | 条件研究路线 | 版本更新与模型名字不等于方法新颖 |
| 特征预算、可追溯工件、CPU演示 | 可保留的研究工程基础 | 用真实指标说明价值，和方法原创分开 |

本次重新核对的2025/2026原文、作者实现与取得限制见[新颖性审查](research_alignment_20261103/novelty_reset_20261104.md)和[教师信息审查](research_alignment_20261103/teacher_value_audit_20261104.md)。其中TMLR2025对LUPI收益归因、KBS2025对不完美特权教师、2026表格基础模型蒸馏对matched student／成本的研究，都说明当前不能以“给教师更多信息／换更新教师”跳过因果对照。论文可见、代码可用和本项目已复现分别记录。

## 7. 建议重构的主问题

保留正式题目，以一个明确问题统领算法：

> 在预先给定的输入字段／模型容量与CPU部署预算下，学生为何丢失低误报区域的攻击检出？教师是否含有可被该受限学生利用、且超出同预算hard与直接低FPR目标的纠错信息；若存在，怎样传递并改善效能—成本取舍？

这个问题允许KD保留为必须研究的方向，也允许否定某个KD假设。它尚不是新的算法名字或已证创新点。固定小模型是一种合法预算；若使用少字段，也必须先核观测损失与字段可获取性，不凭字段数虚构提取成本。

进入新算法前先固定：具体资源预算、现有方法的具体失效、教师信息价值证据、学生可表示性、唯一主增量、能推翻解释的控制以及成本／退出门槛。没有这些，不再次扩展大矩阵。

## 8. 立即行动与后续分支

当前零拟合入口已从单纯阈值排错扩成**主线价值审计**：检查已有模型的合法工作点；加入原完整HGB教师的native raw score与旧clip score；在R确定阈值后查看V的错误互补、尾部区分和teacher/student信息预算。原OOF目标另做分布／拟合支持诊断，不冒称已取得native OOF能力。所有这些只查询既有模型，不新拟合。

之后依证据选择：

1. 若主要是阈值注册：把它修为共同评价／部署基础，不能把校准收益算KD增益。
2. 若教师确有可迁移余量且资源预算有实际意义：再围绕单一信息瓶颈构造方法，并与同样小的hard、matched-target／置乱信息、成熟pAUC及最近邻比较。
3. 若只存在低FPR排序缺口：先用成熟直接目标作强控制，KD保留作待证增量；不将已有pAUC换名。
4. 若教师没有有用增量或学生无法表达：重选教师／输入预算／传递对象前给具体证据，降低当前KD贡献主张；保留负结果，不用更复杂loss掩盖。

真正未使用来源的确认、强基线调参和正式CPU重复资源测量仍需完成。已有数据已经多轮用于开发，不能提供新的独立成功确认。

**当前不应把v3/v4继续写成已确定的新算法主线。** 工程和负结果可以保留，核心问题、机制假设与贡献声明需要按上述证据链重新建立。
