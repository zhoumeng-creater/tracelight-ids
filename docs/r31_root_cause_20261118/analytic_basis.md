# 单侧目标为什么不能推出正常组成变化后的低误报

这是对 R31 目标公式的解析反例，不是新 IDS 实验，也不是对回传模型生成新判决。分位数直接由分布公式求解，没有搜索阈值。

设组内原分数分位函数为 $Q_g(u)$，池化正常分位为 $Q_0(u)$。先忽略有限样本同输入修正，在连续、严格递增条件下，R31 理想目标的组内分位为：

$$T_g(u)=\min\{Q_g(u),Q_0(u)\}.$$

因此各组变换后的分布函数为 $F'_g(t)=\max\{F_g(t),F_0(t)\}$。它们都不会比原分数更高，却**不一定相同**。只降低分数不能保证重新按同一校准规则取分位后，各组告警率都降低。

取两个正常组：$g_1\sim U(0,1)$、$g_2\sim U(1,2)$。训练参考与校准正常各占一半，所以原池化分布为 $U(0,2)$，$Q_0(u)=2u$。攻击分数全部为 3。

| 对象 | 原分布/值 | 精确实现 R31 目标后 |
|---|---|---|
| $g_1$ 分位 | $u$ | $\min(u,2u)=u$ |
| $g_2$ 分位 | $1+u$ | $\min(1+u,2u)=2u$ |
| 校准正常 99% 分位 | $1.98$ | $1.96$ |
| $g_1$ 告警率 | 0 | 0 |
| $g_2$ 告警率 | 2% | 2% |
| 攻击检出 | 100% | 100% |

如果评价正常中 $g_2$ 占 75%，其误报率始终为 $0.75\times2\%=1.5\%$。正常目标完全拟合、没有正常分数上升、攻击全部保留，仍未达到 1%。失败不需要优化器错误、训练不足或保护冲突。

这个例子否定的是“该目标充分解决组成漂移”的推论，并不证明 R31 的具体数据上不存在有益参数，也不否定观察到的 H 改善。结合 R31 的实际失败，下一设计应更换优化对象，不能只延长目标拟合。

同样，改为所有组的共同分位下包络，在理想可辨组且条件分布不变时可以消除组成影响；但有限 F 的输入等价修正、组内变化、网络能否实现和 D 支持仍需另证。因此本次不把另一条分位公式直接登记为下一训练方案。
