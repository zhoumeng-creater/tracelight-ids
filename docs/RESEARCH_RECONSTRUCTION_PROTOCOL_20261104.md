# 重构后的科学协议：教师价值、输入／容量瓶颈与候选增量

2026-11-04。配套[设计](BUDGET_TRANSFER_DESIGN_20261104.md)、[近邻与损失审查](research_alignment_20261104/new_design_review.md)及 `src/ids/budget_transfer.py`。这是公开冻结的**开发研究协议**，不是新测试集、部署证书或已成立的效果结论。真实拟合／正式CPU测量只在实验室RTX4090D进行；GitHub源码、配置、运行指南和回传工件共同构成可复核交付。

## 1. 主问题与唯一算法增量

主问题：给定可用原始字段和小MLP预算，学生在低FPR区域损失的检测能力中，是否有教师能够补回、且直接hard／pAUC不能解释的部分？不再把旧模型升级保护当作轻量化研究的核心目标。

候选是在共同的hard＋全F正常尾部pAUC目标上，**只新增同类跨样本教师偏好损失**。教师提供同标签行之间的次序，不是重复提供已知的攻击／正常标签，也不把任意报警margin当自然类别后验。teacher-R正常上尾5α定义兴趣采样；高分攻击可能大量落入该集合，所以不能将它称作仅包含紧邻阈值困难攻击的窗口。

偏好BCE、关系蒸馏、分位点和pAUC均有已有研究。本轮独立实现的是特定任务的候选构造及其反证协议；不能用组件组合、改名、拟合数量或测试数量证明首创。学生可表示性也不由教师更大、更多字段或更高accuracy自动推出。

## 2. 固定数据角色与选择时序

| 角色 | 唯一用途 | 必须保留的边界 |
|---|---|---|
| F | 字段MI选择、预处理拟合、全部教师／学生拟合及KD目标 | 所有条件拥有相同F标签；单一完整F教师产生F训练内native margin目标，明确不是OOF。 |
| R | 每个模型的正常分数阈值、教师尾部兴趣分位点 | 相同模型的F/R分数使用同一native坐标；不能混排不同折教师的raw margin。 |
| C | 各模型共享的正常阈值约束、checkpoint选择、教师价值诊断 | C是重复使用的开发选择池，不是独立验证／风险证书。 |
| 历史V | 全部模型、checkpoint和阈值冻结后统一评分 | 已多轮开发使用，晚读仅防本轮选择直接查看V；不会使它重新成为独立确认集。 |
| 旧calibration／test | 本轮不读 | 已打开的旧最终test不能为新候选排名、调参或提供新确认。 |

沿用封存的整组F/R/C身份，不因巨组、家族缺失或不理想结果重抽。使用native HGB `decision_function` 的float64目标；普通KL和近期近邻控制也须保留native坐标，不能先变回旧clip-logit目标。

每个模型的工作点为R正常与C正常各自保守有限样本阈值的最大值，因而控制这两个**训练开发池**的经验正常报警数。随后在C按固定的TPR、标准化pAUC、FPR顺序选checkpoint。此规则适用于教师、hard、直接目标和KD，不以候选名另设优惠。C阈值参与训练选择，明确不称R-only校准。

`FROZEN_SELECTION.json`必须在首次加载V特征／标签前写定，随后V仅按其中的模型与阈值评分。不得在V重新寻找最佳阈值、挑最优seed或只报告通过预算的候选。

## 3. 研究矩阵和预算含义

原始字段预算为all／MI24，MI只用F且本轮固定选择seed；容量探针为small `[32,16]`／wide `[128,64]`。四组warmup拥有相同训练阶段预算，用它们的配对结果分别观察字段和容量效应。不能将只跑warmup的wide与又继续优化40步的small差值当纯容量因果证据。相同hidden widths在不同encoded维度上不等于参数严格相同，必须报告真实参数数。

每seed、每环境拟合两位HGB教师：完整字段F教师和MI24-F教师。完整教师与受限教师的算法／超参／拟合标签池相同。教师实际输入、训练样本、查询角色与耗时分开记录。完整教师相对受限教师的增益只说明其额外字段可能有价值，不证明学生能逐条恢复不可观测字段。

小学生比较如下，所有继续训练组从相应预算的同一个已选warmup状态开始：

| 条件 | 要排除的简单解释 |
|---|---|
| hard | 充分继续训练及相同学生本身已经足够。 |
| direct_pauc | 收益仅来自直接优化低FPR排序。 |
| raw_kd | 普通native KL已经足够。 |
| direct_raw_kd | 收益仅来自把普通KL与直接pAUC相加。 |
| direct_channel_rank | ICML2025类别通道RankLoss的二分类语义适配；原1000类源码不能直接宣称复现，二类关系几乎退化。 |
| direct_rank_uniform | 同类关系有用，但尾部兴趣采样不必要。 |
| direct_rank_tail | 本轮唯一候选增量。 |
| direct_rank_shuffled | 保持每类teacher分布／尾部质量和训练预算，破坏教师实例对应；若同样有效，不支持“有内容知识”归因。 |
| direct_rank_matched | reduced学生使用同信息教师，检验额外字段归因；all预算与候选完全相同，记录别名而不重复拟合。 |

置乱映射每run固定，SHA随工件保存；不在每个macrostep重新随机生成教师内容。pair采样可以随固定seed／step变化，所有pair使用完整F池定义的分布、全局class-balanced分母和同一次优化前的参数。分块只是计算实现，不允许每块独立top-k或各自取均值。

合计每seed、每环境为17个学生继续训练条件、4个warmup和2个教师，即23次拟合。两环境单seed pilot为46次；三seed full为138次。若pilot后另开完整full，seed17被重复拟合，不能把该重复当第四个独立seed，全部离线耗时仍要记账。

## 4. 教师“资格”是诊断，不能成为选择性删结果的门

配置中的 `qualification_min_tpr_gain=.002`／`qualification_min_pauc_gain=.002` 定义了C上的headroom标记：完整教师相对direct_pauc的工作点TPR增益至少0.2pp，或McClish标准化pAUC增益至少0.002。二者单位不同；pAUC增益不能直接写成同等工作点TPR增益。

该标记用于分层解释和决定是否值得扩大后续研究，**不删除本轮任何seed的KD条件**。没有通过标记的seed仍运行同一预注册候选与控制，并完整回传。教师整体不占优仍可能有错误互补；标记失败不等于教师无知识或KD在原则上不可能。

每个方法按全部计划seed列出已训练／失败／缺失；比较只使用双方相同seed。不得用三seed hard均值与一、二seed KD均值作排行，也不得只在有利seed上报告候选。若发生工程失败，保留失败信息并先修具体原因，不能通过删seed生成正面平均数。

冻结后统一在V查询两位教师、四组warmup探针及全部学生，保存逐行分数和决定。这些诊断查询不新增拟合。这样可以检查C所见教师优势是否在V仍存在，以及输入／容量探针是否与候选增益一致；V差异不能再反过来改变本轮模型。

## 5. 指标、机制和真实成本

主工作点指标为冻结阈值后的正常FP／FPR、攻击TP／TPR，逐家族列出支持和检出。V超预算的方法不能凭高TPR升格；也不能只报告合格集合而隐去失败集合。另报ROC、raw pAUC、McClish标准化pAUC，写明它们分别衡量什么，不把区间排序指标替代工作点结果。

机制诊断包括教师／学生错误互补、首步各目标的梯度范数／夹角、同类与正常尾部次序一致性、teacher目标ties／饱和质量、同一encoded输入下的教师分数／报警歧义。相同输入歧义只约束观测到的有限重复行；零歧义不能证明学生可表示，正歧义也不证明总体信息论界。

同时报告资源约束：原始字段数、encoded维数、参数数、模型包字节以及同CPU／线程／批量口径的预处理→预测→阈值延迟。教师和小学生都测同口径CPU流程，教师拟合／查询及学生训练成本另记。实验ZIP大小、字段数量不等于模型体积、包处理吞吐或字段在线采集成本；已经抽好的CSV不提供PCAP字段提取测量。

## 6. 继续、撤回和后续确认标准

pilot的作用是验证研究链是否可执行、教师是否留下可疑余量、候选是否值得扩大；单seed的小幅正负差都不能证明稳定优劣。先审阅完整pilot回传，再决定是否值得执行已准备的三seed full；不得只挑pilot有利的环境／预算／家族扩展并把结论泛化给全体。

事前扩展参考：V实际FPR不超预注册1%时，候选相对direct_pauc与direct_raw_kd的TPR增量以0.2个百分点作为值得扩展的开发门槛，同时检查uniform／固定置乱和家族损失。它是工程研究的实用筛查值，不是业务SLA、显著性检验或总体保证。未达此值但pAUC改变，只能形成另外的排序机制观察，不事后把任意微小正差改称亮点。是否扩大仍需完整解释两个环境；该门槛不能用来删除本轮不利结果。

| 观察结果 | 必须采用的结论或下一步 |
|---|---|
| candidate不超过同预算direct_pauc | 当前KD增量未获支持；不再用更多guard或模块保护候选。 |
| 不超过direct_raw_kd | 当前不能证明同类次序传递比普通KD必要。 |
| 不超过同类置乱 | 撤回有效实例知识解释，优先检查正则／抽样解释。 |
| 不超过uniform同类排序 | 撤回尾部局部化必要性。 |
| 完整教师和同信息教师结果无稳定差异 | 不归因于额外字段；可以研究教师函数或正则效果，但另写主张。 |
| 教师V优势／互补不在目标区域持续 | 收缩该教师价值解释；不以训练内拟合或C选择成绩替代。 |
| 检测增量存在但部署成本无有意义变化 | 只能声称固定预算检测增量，不能虚构轻量化Pareto胜利。 |

full的三个seed仍共享同一个F/R/C/V拆分，衡量的是优化随机性，**不是三个独立测试集**。固定拆分、巨关联组和家族支持限制必须随结果报告。若HGB不同seed产生相同教师，也不能把重复拟合当独立能力证据。

目前固定学习率／损失系数是第一轮预注册起点，没有完成各近邻的相等调参预算或充分敏感性分析。因此结果只能支持固定预算开发比较，不能宣布调参后的SOTA优胜。近期类别RankLoss的二分类退化也不能单独充当“击败前沿强KD”的证明。

真正的算法经验贡献至少需要：关键配对对照下稳定增量、有内容／局部化归因未被反证、资源含义明确、失败范围透明，以及新增未使用来源上的冻结确认。新来源须有可核来源／提取器／schema／组隔离与不重叠证据，在查看其结果前冻结模型、阈值注册和结论标准。没有取得新来源时，就明确停留在开发研究，不能把重新分割旧V或已打开旧test称作独立确认。
