# 模型设计与训练方案重审

2026年11月16日。依据R17、R18、R26、R27实际结果、当前源码和作者实现。本文确定后续设计；本轮没有新训练或真实模型前向。

**应修改任务、输入和训练流程之间的对应关系。现有证据不足以认定网络容量或优化器是主要失败原因。未来以官方TabM为唯一新增梯度训练模型，与HGB做同条件系统比较；旧MLP保留参照。停止默认混合旧来源、统一遮蔽全部任务端口、固定末轮交付，以及失败后临时增加模型和参数。**

### 一项训练前就应识别的不可行条件

去端口后，最大相同输入组含261正常、2638扫描、40条C&C。S合并训练池有4096正常，1%允许40个误报。**只使用这六项信息、同一确定性逐流分数和共同阈值时，检出这40条控制必然误报261正常。因此，在这个S训练池守住1%预算，C&C检出上界至多16/56，即28.57%。** 其他混淆还可能降低上界。

该组正常/扫描来自CTU1-1，控制来自CTU8-1，属于S内部而非S/T冲突。上界不适用于采集身份路由、各采集独立阈值或D，不证明标签错误。这40条控制的低召回不能直接判为网络小或没训好。

## 2. 模型实际要完成什么任务

保留论文的低误报检测、逐类得失和实际成本目标。扫描、控制、下载分别保留证据状态，缺失攻击族不计成功。当前可直接开展的监督开发任务是：**利用目标环境已有历史标签，在完整Zeek流记录可用后检测控制通信。** B/D是同Merlin实现的不同传输；跨独立攻击实现能力尚未建立。

这不将课题永久缩为单一C2任务，而是限定当前资料能检验的结论。旧扫描记录与AIT下载事件不能仅凭“攻击”总标签直接拼入同一训练池。联合训练需要相同标签含义、可用输入和实际业务目标的依据。

P的180条控制全部是UDP；正常中有9004条TCP、1081条UDP和417条ICMP。当前没有TCP控制正例，协议与标签存在很强的来源关联。改成正确类别编码也不会补出TCP控制监督。因此，TabM比较检验的是成熟流程在这个有限支持上的作用，不能预设其结构会解决D的TCP迁移；单靠当前训练成绩也不能判断一般C2能力。

完整流检测、早期检测与跨实现检测必须分别定义。后续B的72条控制流中，36条时长不超过120.35秒，另36条至少9583.73秒，约159.73分钟；约81分钟的中位数是两簇中点，不是典型连接。当前代码由流起止构造逻辑时钟，并未测到真实导出/送达时间。应分列流观察跨度、日志可用时刻的已知状态和模型处理耗时。要研究早期检测，需另定义固定前缀或窗口输入，不能靠更快的网络消除等待完整统计的时间。[时钟实现](../src/ids/response_evidence/tqh.py#L114)

## 4. 输入表示的保留与修改

原始八字段和身份全部保留用于审计。目标C2主比较使用五个连续量、协议类别及缺失标记，两个端口不进入学习器。这结合了作者的身份捷径提醒和R26目标结果，**只适用于当前目标C2比较，不推广为所有来源的统一表示**。

| 对象 | 固定处理 | 依据 |
|---|---|---|
| duration_seconds、orig/resp_pkts、orig/resp_ip_bytes | -1还原缺失；拟合分区中位数填补；非负值log1p，再用拟合分区均值/标准差缩放 | 避免负哨兵冒充真实量，保留长尾与训练范围外的数值差异 |
| 五项缺失标记 | 各保留二值输入，不送入连续量数值嵌入 | 区分未观测与真实零；标记不会补回缺失行为 |
| ip_protocol | 显式类别，保留未知/缺失状态；不用连续数值距离解释协议编号 | 不再靠旧NF字段名名单隐式决定变换 |
| 两端口 | 原始记录保留，目标C2主模型排除，既有端口规则单列参照 | 降低已知捷径，不声称端口对扫描任务无用 |
| IP、UID、来源名、动作和未来真值 | 只作分组、关联与评价 | 不让身份或事后答案代替行为 |
| Zeek统计 | 保留originator/responder方向、IP字节与payload区别、缺失和生成版本 | R27临时包统计不能直接冒充原八字段 |

作者示例允许StandardScaler，也展示QuantileTransformer。本任务采用log1p＋StandardScaler：QT对超出训练极值的量会饱和，不适合作为本次外推方案默认处理。填补、缩放与分箱仅在拟合分区建立；记录FP32转换/嵌入前后精确合并、缺失及范围外值，不按它们挑有利样本。

全缺失连续列填0并保留缺失标记；零方差缩放因子设1；标准化后的常量列沿用已有适配的固定分箱边界[-1,1]，不从V/C/E/D求边界。协议采用项目已知语义表1/6/17/58/132加UNKNOWN，五个缺失标记各用固定0/1类别，不参与PLE。原始解析已合并的未知与缺失协议不能伪造为可区分状态。所有规则和实际参数随模型保存。

HGB与TabM使用相同允许信息和上述数值处理；类别分别通过显式one-hot及TabM官方类别接口展开。比较的是完整学习流程，不把预处理、目标与结构同时改变的结果称为纯架构因果试验。

TabM沿用作者AdamW：lr0.002、weight_decay0.0003、batch256、梯度范数裁剪1；各成员分别计算BCE，预测平均成员概率，稳定计算联合分数/NLL。最多200轮，验证完整选择规则连续16轮无改善即停，恢复最佳权重；到上限不加轮。

### 共同阈值对应合并验证指标

主选轮固定为**V合并记录的标准化partial AUC，FPR区间[0,0.01]**，使用scikit-learn1.5.1的`roc_auc_score(..., max_fpr=0.01)`。同分取更低V自然权重NLL，再取更早轮次；按有限原值比较，不增加可调改善幅度。各单元指标保存作诊断。

不以各单元内部pAUC的平均作主指标：来源内排序对分数整体平移不敏感，可能掩盖共同阈值不能同时使用的问题。合并pAUC也不能替代最终逐单元误报验收。

HGB完成最多200阶段，以官方逐阶段预测在V选迭代数，再以该数在P拟合；不调用当前1.5.1没有的新版外部X_val接口。TabM在P从头训练V所选轮数，重新用P拟合预处理及分箱，不再用V二次选择。重训改变样本量、尺度与更新数，属于预定完整流程；原V最佳成绩不是最终P模型验证成绩。

每轮保存路径loss、轮末F/V损失、主选轮指标、更新数和最佳检查点。最终P模型另存轮末训练分数。复用R17已有机制，不再仅保存固定末轮。所有模型先冻结，再读取C/E/D评分；作者教学例中逐轮展示test的代码不复制。

## 6. 强参照、采用与停止条件

C正常身份固定，每模型按既有严格次序规则登记共同1%阈值，E/D不重标定。1%是校准规则与评价工作点，不是对相关流或来源变化的总体概率保证。每完整单元、UTC日报告正常分母、FP及整数预算、控制TP/FN、同服务正常、旧检出的新增/丢失和实际成本。

主配对对象是本批同条件HGB；已有能力参照固定为原阈值HGB与UDP/443持续30秒规则的并集。另完整报告纯规则、原HGB及R26 target/端口置零HGB和全部MLP种子；B能力保持对照已取得的72/72。输入、训练权重和阈值来源单列，不拼成虚构的最强模型。新候选间共享P/C信息；旧模型承担已有能力对照，不能据此归因单一网络组件。

**B已72/72，新方案的价值须体现为保持B能力、改善D合规检测或明确成本收益。** D没有TCP/8443同服务正常；B的651条UDP/443正常最长约1.20秒。现有资料没有证明一般正常长连接与控制可分，也不能把D进步称为独立攻击实现泛化。

采用判断用以下同一规则，不事后更换比较对象：

1. 合规定义为每单元`FP <= floor(0.01 × 正常数)`。候选必须在全部3个B和12个D单元合规，并保持B总TP=72。
2. 对每个固定参照逐单元比较。参照合规的单元，候选TP不得低于它；参照超标的单元，候选合规属于合规性改善，参照的超预算TP完整报告，不作必须追赶的合规检出上界。
3. 相对本批HGB和旧HGB并集两个参照，各自至少有一个D单元出现合规性改善，或在双方合规时TP严格增加。三个TabM种子必须分别满足以上条件。任一合规单元TP退步则只报告取舍，不进入默认替代候选。
4. PLE检出作用按相同种子配对，使用最终C阈值，在全部B/D单元依照第2条无退步，且至少一个D单元有第3条严格改善；三个种子同向才记为本任务的检出收益。V的pAUC或训练loss改善不替代该结论。

上述按单元TP数量判断，不保证逐条旧TP无损；新增与丢失身份仍逐一报告。成本单列完整结果，不以未预设容差的“检测相近”触发自动采用。

| 一次比较结果 | 固定决定 |
|---|---|
| 三个TabM种子分别满足上述两参照、逐单元合规与TP采用规则 | 列为开发候选；旧TP身份有丢失就不称无损替代 |
| 仅pAUC改善，固定C阈值下仍有单元超标 | 不认定部署改进，不在E/D搜索阈值 |
| 仅某种子获益，或靠单元之间抵消退步 | 报告不稳定/取舍，不挑幸运种子或追加种子 |
| 完整TabM相对去PLE的三个同种子配对均满足第4条 | 支持该配方/开发任务的数值嵌入检出作用，不直接称原创算法 |
| 去PLE相近或更好 | 嵌入收益未成立，不再临时换分箱数或宽度 |
| 两种TabM均不满足采用规则 | 保留HGB为主参照，结束本次结构分支；HGB自身超标时不产生合格的新部署模型 |
| 出现检测—成本取舍 | 输出完整比较，不自动采用；不以事后定义的“相近”掩盖检测差异 |
| 只在当前短正常业务下成立 | 保留受控任务结论；补匹配业务与实现覆盖，不能靠模型复杂度替代 |

检测增量须同时给净增和旧TP丢失；逐单元有退步不能称全面替代。成本复用已有独占计时方式，分列CPU单流/批处理、GPU吞吐、预处理、冷启动及内存；训练并发吞吐不冒充部署时延。执行故障与算法负结果分列。没有教师净优势、学生可用信息与成本依据，不启动KD。

## 7. 八权重诊断的作用与实施范围

已准备的8份旧权重补算只解释R26，不负责产生模型提升，也不是完成本设计的前提。mixed若已见T排序受损而target/HGB保持，说明混合流程折衷；若T/B保持而D退化，指向跨传输支持与泛化；若S错误集中于不可分组，则按表示上界解释。最终BCE减无约束经验下界不能直接称优化误差，其中还可能包含函数类和正则化影响。

| 保留 | 修改 | 暂不加入 |
