OpTC 新增的可信正常业务分两级：42 条 HTTP 连接有完整网页对象、浏览器进程和 UID／五元组证据；41,588 条 TLS 连接有作者正常背景、浏览器进程和已建立站点 TLS 证据，未解密内容。5,026 个正常网页对象涉及 559 条父连接，其中 517 条未满足整流正常规则，整流标签保持 unknown。正常对象中已有 59,678-byte 图片，对应连接响应 59,965 bytes、52 个响应包；攻击工具为 59,392 bytes，对应 59,598 bytes、52 包。可比体量确实存在，未据此挑选正常分母。[正常业务记录](optc/README.md)

## 算法方案与必要的最小对照

当前只保留两个学习臂的设计：

1. **单流 HGB**：统一 raw8，即协议号、双端口、时长、双向包数、双向 IP 字节数。
2. **同一 HGB＋固定历史摘要**：当前 8 字段加 19 个历史值——最近一条已可用流的 8 字段、此前流的 8 字段在线均值、距上一条可用时刻的 `log1p` 间隔、是否相同对端、空历史标记。数值统一 `log1p`；缺失保留，不搜索时间窗。

IP 仅作关联键；PID、进程名、域名、路径、来源名和攻击时间不进入模型。同刻记录先全部查询、再更新，完整组之间清空。每主机摘要状态为常数，离线排序程序整体仍占 O(N) 内存，不将它包装成已经完成的在线部署。实现和时间检查见 [prefix_context.py](split_method/prefix_context.py)。

两臂必须使用相同标签单位、F/V/C、当前流输入、HGB 容量、选择规则和正常工作点。评价同时给出逐业务单元误报、完整攻击组命中、逐身份新增／丢失、告警时刻，以及特征导出、缓存和模型成本。AIT 多义动作只报告候选全命中／任一命中的下上界，不能据最有利候选记成确定命中；受损候选不从分母中消失。

这两个臂回答“额外历史是否提供可复现信息”，尚不检验原创性。[EarlyCrow、GraphIDS、GESR 等已核近邻](../source_method_route_20261118/algorithm_sources.md)已经覆盖主机摘要、图邻域和上下文重建。学习选择器只在成熟摘要确有收益、且存在明确的内存或信息保留损失时才有立项依据；若立项，必要对照才增加为同预算的最近／均匀选择。当前不新增图网络、关系损失或模型矩阵，也不以同 PID 生成因果关系监督。

## 真实历史导出与当前执行决定

已完整扫描两份既有 OpTC conn 轮转，抽取指定主机的全部观测，包含未标注流、UDP、ICMP 和响应端视角：9/19 的 17 台主机共 44,944 条；9/24 Empire 主机共 365 条。没有按标签筛历史。[声明范围与输入收据](optc/context_inputs_receipt.json)

实际可用时刻在原件中缺失，现有导出采用明确的离线完成流重放。**已实际生成全部 45,309 条背景记录的历史摘要；按声明的离线时钟检查，历史时刻违规为 0。** 其中统一表的 42,173 条开发连接全部接通，形成 46,682 条事件—摘要关联；预留 Meterpreter 未生成上下文、未参与选择。[实际导出与接线收据](unified/context_binding_receipt.json)

Empire 两条 DNS 的原始 duration 为空，各只有一个观测包。`ts` 为首包时刻，所以唯一观测包同时也是末包；新派生文件据此补入离线观测末时刻，全部 raw8 原值及两条 duration 缺失保持不变。该推论依靠包数与首包字段语义，不要求猜测 OpTC 的精确 Bro 版本；[Bro 标准源码](https://github.com/zeek/zeek/blob/v2.6.1/scripts/base/protocols/conn/main.bro)也表明 duration 只在正值时写入。没有推导实际 UDP 超时或日志导出时刻。[两条修正及原件哈希](optc/context_replay_inputs_receipt.json)

轮转文件包含此前结束、延后写出的记录；完整流统计也可能包括 duration 未覆盖的尾部包。离线排序检查证明的是声明时钟下的先后关系，不能代替实际在线可用性或早检证明。

统一表经过独立的 29 项来源／链接／角色核验；历史模块的 12 项测试覆盖未来与同刻记录隔离、完整组清空、未标注背景、双主机视角和缺时钟整组处理。[统一表核验](ait_attack/review_unified/verification.json) · [摘要模块测试](split_method/test_prefix_context.py)

**本轮不登记训练。** 装配结束仍不足以开始两个学习臂：AIT 攻击下载缺损；动作与流的多义没有消失；新 F/V/C 尚未成立。数据装配产物已交付，不继续以调阈值、补损失或猜测时间窗推进。后续拟合材料仍须同时覆盖控制和下载，下载正例必须来自完整、可归组的传输；受损 AIT 不能补数，现有 OpTC 保持外源评价角色。
