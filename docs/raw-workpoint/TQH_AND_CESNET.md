# TQH 的八字段漏检与独立 QUIC 应用流对照

R23 用两份训练期 IoT-23 来源拟合二分类 HGB，以两份更早的正常记录（1,826 条）登记固定阈值。raw 只用流记录中的协议、两端端口、持续时间、双向包数和双向 IP 字节数。TQH 四组各有 12 个试验单元（时隔 30、300、1,800、3,600 秒，分别与三档抖动组合），按每个单元的正常真值独立核对 1% 预算。[TQH-C2 作者资料](https://zenodo.org/records/23905375)

| 配置 | raw 误报 / 正常 | 达标单元 | C2 检出 / 漏检 |
| --- | ---: | ---: | ---: |
| A · Sliver/TLS | 116/84,111 | 12/12 | 9,933 / 2,105 |
| B · Merlin/QUIC | 28/21,472 | 12/12 | 0 / 324 |
| C · Mythic/HTTP | 9,378/9,608 | 0/12 | 176 / 12,628 |
| D · Merlin/HTTP2-TLS | 15/9,564 | 12/12 | 1,694 / 270 |

同单元内，15,327 条漏检 C2 中没有任何一条与正常流八字段完全相同。移除高基数的发起端口和持续时间后，用剩余六字段精确匹配仍为零。A、D 的全部 14,002 条 C2 都有一端是 TCP/8443，整个 TQH 的正常流中没有这种记录。这个端口能在本试验台区分两类流，无法证明它在其他实际网络也能区分两类流。

B 组的 324 条 C2 和 2,394 条同服务正常通信均使用 UDP/443。正常持续时间最长 1.774 秒，C2 中位持续时间为 1,476.8 秒。冻结 raw HGB 全部 200 棵树的持续时间分裂点均不超过 2.999299 秒。将 311 条超过末次分裂点的 B 组 C2 的时长统一替换成 3 秒，其余字段不动，模型分数逐条完全相同。训练所取 8,192 行及早期正常校准 1,826 行中没有 UDP/443。此前的端点历史及回包历史模型也未检出 B 组 C2。

查看已打开的 TQH 后，按“UDP 任一端为 443，已结束连接持续至少 30 秒”核对，B 组 296/324 条 C2 满足，2,394 条同服务正常流无一满足。与 raw 告警取并集，原 28 条误报全部保留、没有新增。10 秒与 60 秒分别命中 311 和 261 条 C2。这是同试验台上的事后结果。

48 个单元的正常数、误报、C2 检出及漏检、八字段冲突和规则新增都保存在[逐单元表](tqh-raw-48-units.csv)。在仓库根目录运行下列命令可从原始 TQH、早期 IoT-23 日志和 R23 结果包重建表格。原始日志默认位于 `data/raw/response-evidence-20261112`，可用 `--source-dir` 指向其他目录。

```powershell
$env:PYTHONPATH = 'src'
python docs/raw-workpoint/audit_tqh_raw.py --result-zip <R23结果包路径> --out local/tqh-raw-diagnosis
```

## CESNET 的完整首日

从作者发布的 CESNET-QUICEXT-25 选取最早的完整日，即 2024-06-01，核验首月 ZIP 目录、日文件 CRC-32 和 SHA-256，对这一天的 14,750 条双向 QUIC 记录全量计数。作者对一个 ISP 网络作 1:100 均匀采样，仅公布目的端口。已知 UDP 目的端口为 443 的有 14,746 条，**其中 4,452 条（30.19%）持续至少 30 秒**。这些记录覆盖 276 个非空 SNI，包括 instagram.com 后缀 792 条、facebook.com 777 条、icloud.com 362 条和 fbcdn.net 290 条。统计以作者提供的流持续时间为准。作者未提供 IDS 正常/恶意标签，30.19% 只计条件触发比例。[作者字段与采样说明](https://zenodo.org/records/17249078) · [已校验的成员摘要及分服务计数](cesnet-quic-20240601.json)

| UDP 目的 443 的持续时间门槛 | TQH B 同服务正常 / C2 | CESNET 首日触发 / 同服务记录 |
| --- | ---: | ---: |
| 10 秒 | 0 / 311 | 6,171/14,746 |
| 30 秒 | 0 / 296 | 4,452/14,746 |
| 60 秒 | 0 / 261 | 3,072/14,746 |

CESNET 证明长时 UDP/443 在有明确应用线索的网络流量中很常见。实验策略 `add_quic30` 用来检查简单条件跨来源会触发多少告警。主要效果按独立检测数据中的作者真值和每单元 1% 预算判断。

用项目 Python 环境复核该日计数时，取月包的末尾目录及 2,236,724 字节压缩的日成员，内存解压，无需保存月包。

```powershell
$env:PYTHONPATH = 'src'
python docs/raw-workpoint/audit_cesnet_quic.py --out local/cesnet-quic-day-replay.json
```
