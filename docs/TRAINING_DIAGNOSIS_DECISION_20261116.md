# 训练诊断推进与路线决定

2026-11-16。本轮已完成原训练输入恢复、15条既有训练轨迹分析、精确输入冲突定位及B/D缓存分数复算。没有新拟合或真实模型前向。8份冻结权重的训练支持诊断已实现，实际评分留在实验室。

## 已查明的设计矛盾

同一种端口置零处理，在target向D迁移中有益，却使旧source的部分正常与攻击记录变成完全相同的输入。直接将两种监督任务按固定权重混合，没有保持相同的学习难度和信息条件。

### 训练损失不能代替迁移诊断

15个新MLP均保留80轮记录。下表BCE是优化过程中各批次损失的行数加权平均，不是最终权重重算的全训练损失。D列包含误报超标单元，不是达标成绩。

| 支持与输入 | 三种子末轮BCE均值 | D控制检出：17 / 29 / 43 |
|---|---:|---|
| target/raw8 | 0.00011062 | 43 / 0 / 0 |
| target/端口置零 | 0.00010935 | 1495 / 1773 / 1554 |
| mixed/raw8 | 0.01712708 | 2 / 2 / 2 |
| mixed/端口置零 | 0.08578063 | 45 / 46 / 45 |

target的两个视图有近似训练损失，却有很不同的迁移结果。统一延长训练没有积极依据。target到mixed还同时改变损失权重、标准化和更新次数：目标控制的目标函数权重份额从50%降到25%，更新次数从1680增至2960。权重份额不等于实际梯度份额。

### 端口置零制造了源训练输入冲突

按R26冻结身份恢复S的8192行、T的10682行。两份gzip按解压原文SHA核对，TQH按压缩包SHA和六个成员核对；压缩容器变化单列。恢复数据没有用抽样记录伪造原累计导出时钟。

| 训练支持与视图 | 异标签输入组 | 涉及记录 | 原权重下BCE经验下界 |
|---|---:|---:|---:|
| source/raw8 | 0 | 0 | 0 |
| source/端口置零 | 63 | 3657 | 0.13891601 |
| target/raw8、端口置零 | 0 | 0 | 0 |
| mixed/raw8 | 0 | 0 | 0 |
| mixed/端口置零 | 63 | 3657 | 0.06945800 |

63组全部已有source采集内部异标签，没有target记录，因此不是S/T直接交叉标签矛盾。涉及355正常、3262扫描、40控制。最大组是TCP、时长缺失（编码-1）、发送1包、接收0包、发送60字节、接收0字节：261正常、2638扫描、40控制，共2939条。旧训练56条控制中的40条集中于此。

下界按相同输入组的加权正负标签熵计算，是任意确定性评分函数在这些有限训练行上的下确界，不是当前网络的最优值。mixed给source一半权重，所以其下界是source的一半。不能将下界与末轮路径损失的比值解释成失败原因的贡献率。

实际MLP标准化FP32输入与公共数值输入有相同的63组异标签冲突，没有新增FP32异标签合并。按原计算顺序恢复的训练均值、标准差与六份冻结MLP逐元素一致。

来源：[冲突定位](training_diagnosis_20261116/conflict_localization.json)、[63组组成](training_diagnosis_20261116/conflict_localization.csv)、[实际输入核对](training_diagnosis_20261116/input_conflicts.json)、[恢复收据](training_diagnosis_20261116/recovered-training.json)。

### 冲突没有直接覆盖D攻击

B的72条攻击、D的1964条攻击均未精确匹配上述63组，D只有1条正常记录匹配。已确认的是source去端口后的训练障碍，不能直接宣布它造成D的大量漏检；参数共享造成的间接影响仍未被这一精确匹配检查排除。

## 立即生效的研究取舍

- B历史监督后的有效能力保留为现成基线；普通再训练与端口遮蔽不认领算法创新。
- 当前等权mixed MLP退出默认方案。端口置零保留为诊断，不作为对所有来源都正确的统一表示。
- D保留完整迁移结果，1%误报及逐类新增/丢失要求不改；已开结果用于诊断，不充当新独立确认。
- AIT保留为外部历史实现案例，字段、正常大响应及文件传输核验不作为理解R26训练问题的前置条件；本轮不扩AIT评分或训练。
- 不据非零BCE启动长训、扩容、KD或新损失函数。新增算法贡献仍未建立。

## 唯一新增模型计算

target/mixed × ports_zero8 × HGB/MLP17/29/43，共8份旧权重；每份在同一S∪T共18874条上评分一次，共150992模型评分行。target未见过的S明确标为非自身训练支持，不计入target原训练目标或下界。

新增拟合0，新增B/D前向0，新阈值登记0，新来源下载0。HGB作为同输入现成函数对照，不增加raw8、source-only模型或其他骨干。B/D只读取登记的15份回放。

输出最终权重的原加权BCE、各来源/攻击族损失贡献、各训练单元正常预算与严格上阈值排序、逐行训练分数。C&C的56条与Scanning的4040条分列；族检出使用同域正常参照。训练诊断阈值不投入部署。

| 最终观察 | 决定 |
|---|---|
| mixed已见S/T低误报排序保持，D退化 | 停止以训练支持未拟合为理由长训或扩容，研究已学映射的迁移条件 |
| mixed MLP在已见T上已经损失，target MLP和同输入HGB没有 | 定位mixed MLP的训练支持折衷；后续如立项，只检验这一具体缺口 |
| 错误集中在相同输入异标签组 | 承认表示限制；优化器不能让相同输入同时输出相反判定 |
| BCE偏高但低误报排序保持 | 不因概率损失高追加训练 |
| 平均BCE低但少数控制或个别单元漏检 | 不以总体平均宣布训练充分 |
| 种子结论不同 | 报告不稳定，本批结束，不追加种子寻找一致答案 |

训练错误不能唯一分离容量、优化和正则化；训练拟合好不能唯一分离过拟合与来源变化。本批结束于上述定位，不自动启动新矩阵。
