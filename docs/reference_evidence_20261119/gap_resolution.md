# 缺口绕过：严格结论、实物结构与最小修补

2026-11-19。对象是上一版 `stage_design/reference_model.py`：每个阶段与真实参考或可学习 null 比较，再做完整路径 min–max。本轮只读现有 8,514 条连接的阶段账本，做结构与恒等关系分析；没有真实模型前向、拟合、阈值选择或原包重扫。

**采用决定：撤下可学习 null-gap 作为完整解释的实现。** 一次真实匹配不足以保证后续阶段得到正常参照解释。最小的无删除对照可以实现为“相邻双向段无损成对＋完整瓶颈 DTW＋真实尾段比较”。它能从结构上消除原缺口出口，但属于普通序列匹配适配，不构成新的算法贡献。

## 1. 原缺口为什么不能靠已有条件消除

原分数为 `min_reference min_path max_edge cost`，所有阶段虽被路径消耗，但 query-gap 比较的是查询与 null。只要 null 的可学习成本低，后半条查询可以不与任何真实正常阶段比较。presence 使有限参数的 gap 成本数学上为正，却没有给出能支撑正常解释的下界。

把“至少一次匹配”改成更多次、规定匹配比例、固定 gap 常数或扫描温度，都引入了尚无业务依据的额外选择。它们不能作为本轮修复。

## 2. 两个看似直接的修复，实际会退化

### 2.1 原方向段上完全禁 gap，会变成等长对角匹配

现有阶段是最大连续同方向的唯一字节段，因此方向严格交替。若 q_i 与 r_j 同方向，q_(i+1) 必与 r_j 反方向，q_i 也必与 r_(j+1) 反方向。

所以在方向必须相同的普通 DTW 网格中，从合法位置作横步或竖步都会落入非法位置；只有同时前进的对角步合法。从两序列首端到末端的完整路径存在，当且仅当首方向相同且段数相同。

这项规则确实没有删除出口，但没有解决异长业务。不能把它描述成通用的可变长完整匹配。

### 2.2 用“最近真实阶段成本”替代 gap，会精确变成无序 Hausdorff

设同一完整参考下兼容阶段成本为 C_ij，定义查询 gap 为 `a_i=min_j C_ij`，参考 gap 为 `b_j=min_i C_ij`。假定每段至少有一个方向兼容的对应，则：

\[
H=\max\{\max_i a_i,\max_j b_j\}.
\]

任何完整编辑路径都消耗每个查询段和参考段。匹配成本不低于对应的 a_i、b_j；gap 恰等于它们，因此所有路径的瓶颈均不低于 H。

反过来，选择一条成本不超过 H 的真实匹配边，在它之前及之后把其他阶段全部放进 gap。该路径满足“至少一次匹配”，每条边成本均不超过 H。所以最优路径分数不高于 H。

两侧合起来得到 **最优编辑分数严格等于 H**，即对兼容阶段集合的双向 Hausdorff 成本。阶段顺序已不起作用。外层再取最佳正常参考，只是最近正常阶段集合的 Hausdorff 匹配。

若将最近阶段成本仅作为 gap 下界，而仍保留更大的可学习 gap，能保证每段承担至少一个真实参考比较成本，却不能保证顺序得到保护：学得 gap 接近下界时仍会退化。给最终分数加这个下界也只是引入同信息的集合匹配控制，不是新的完整解释机制。

## 3. 一个能实际消除删除出口的普通修补

按捕获首方向把相邻两个方向段成对。例如：

```
[(0,a1),(1,b1),(0,a2),(1,b2),(0,a3)]
→ 首方向0，完整对[(a1,b1),(a2,b2)]，真实尾段a3
```

首方向为 1 时同样从第一个已观察方向开始成对，不倒置源／目的定义。偶数段没有尾段。这个表示可以精确还原原有方向和每段字节量；没有把一对段解释成真实命令／响应，也没有压缩掉交互内容。

规则如下：

1. 查询与参考必须有相同首方向、尾段存在类型和完整对存在类型。只有单个尾段的查询不能对应一串完整对。类型不匹配返回未支持，不能转成攻击分数。
2. 完整对只与真实完整对比较；局部成本同时接收这两个真实方向的字节量。
3. 完整对采用从首到尾、覆盖全部行列的普通无 gap 瓶颈 DTW。横／竖步重复比较一个真实完整对，**不是与 null 比较或删除真实阶段**。
4. 若有尾段，尾段必须与参考的真实尾段比较；该成本也进入最终最大值。不存在尾段不补零，不以可学习空节点抵消。

完整对上的递推为：

\[
D_{i,j}=\max\{C_{i,j},\min(D_{i-1,j},D_{i,j-1},D_{i-1,j-1})\}.
\]

最终取完整对路径成本与真实尾段成本的最大值，再在类型兼容的完整正常参考间取最小值。

**没有删除出口的证明。** 路径从 (1,1) 到 (n,m)，每步坐标增加不超过 1，因而每个查询行和参考列至少被访问一次。每个行列元素是两个真实方向段，且尾段单独真实对真实比较。因此所有真实阶段都进入至少一个真实参照比较，不能只匹配第一对后把剩余数据转入低成本 null-gap。

这不保证学习权重合理。条件成本仍可能学得过小，但那是局部代价学习的失效，已经不能由删除边在结构上隐藏。二者需要区别。

**标准 DTW 的边界仍保留，而且真实材料中已经存在。** 在现有几何可用连接中，仅折叠连续相同完整对、保留首方向和真实尾段，可找到 31 组折叠后完全相同、原完整序列不同的连接：共 941 条、64 个不同原始序列，全部来自 Unraveled 的 F_expansion 正常业务。每组之间都存在只比较相同真实完整对的完整 DTW 路径；对恒等输入成本为零的局部函数，这条路径的瓶颈为零。这个结论由真实序列恒等关系和路径结构直接推出，没有调用真实流检测评分。

例如完整对 `(379,799)` 在同组真实连接中分别出现 1、2、4、5 次：

| 完整对次数 | 方向0／方向1唯一字节量 | 连接条数 | 一条真实连接的ID末段 |
|---|---|---:|---|
| 1 | 379／799 | 212 | `618bd24d81d9b225e3e9e1ac0958fff0` |
| 2 | 758／1598 | 26 | `64cc470611f79a6b3d0e00b2e27ab271` |
| 4 | 1516／3196 | 2 | `11e3bcdb896c92ec75bc6943d1237025` |
| 5 | 1895／3995 | 3 | `c7697cba57e6b8271660f82f8bc3a50f` |

完整 ID 的共同前缀是 `unraveled:20210621:net1013x:`。还有多阶段、带真实尾段的例子：完整对序列 `[(517,3833),(473,62),(31,5747),(39,39)]` 后接尾段 63，与在末尾再重复一次 `(39,39)` 的序列归为同组，分别有 1 条和 4 条真实正常连接。代表 ID 末段为 `64782a8e6ba5241af1a555c50235162e` 和 `613a2876749fb959f055a086ddbee7ee`。

因此无损输入表示与保留判别差异是两回事：输入仍能精确还原，DTW 分数会忽略连续重复次数。此次没有发现这类等价组内的攻击／正常混合，不能据此宣称漏报；这也可能是合理的正常重复不变性。若后续要把次数差异作为判别依据，须先找到真实业务证据，不能直接追加步长惩罚或次数项。

## 4. 真实材料中的结构可用性

F 中唯一结构不支持的是“首方向1、有尾段”的单例正常连接，排除自身后没有同类型参考。它必须保留为未支持，不能因为其余类型数量多而抹去。

上述“有参考”只表示存在合法完整比较路径。**它不表示字节量接近，不表示正常覆盖足够，更不表示该方法已经达到误报预算。** 数值相似和业务覆盖由主报告的真实参照分析单独回答。

既有几何不完整、未关联或没有原包的对象没有进入这个可达性分母；原始全体分母仍保留。fox 全部已知正常 TCP 为 431 条，其中 422 条满足本轮几何条件，另 9 条不能被当前可达性结果替代。

## 5. 与同信息简单方法及近期近邻的关系

成对没有创造新信息：起始方向、每段字节量、顺序和尾段都可以精确还原。固定局部距离版本就是完整正常模板上的标准瓶颈 DTW／离散 Fréchet 适配。学习局部权重也仍属于可学习模板匹配；修补删除漏洞本身不构成实质创新。

本轮重新核读 [EMS-uDTWAD 2026 原文](https://www.techscience.com/cmc/v89n1/68431/html)：其 §3 使用完整窗口与正常参考库匹配，并取最小标准化 uDTW 分数。它的任务和距离细节与本项目不同，但已足够排除“完整正常序列作参考”本身的新颖性。C2Detector 出版社全文入口本轮返回403，沿用上一轮已核到的片段／同名公开代码边界，不将此次访问写成完整复现。

因此该修补的用途是一个正确、可复用的简单对照。若它与同信息阶段统计／独立参照已经解释结果，就没有理由保留更复杂的完整解释学习模型。当前没有新增训练注册，也没有用结构可达率为算法收益背书。

## 6. 已交付实现

- `scripts/reference_evidence/paired_no_gap.py`：无损成对／还原、完整无gap瓶颈匹配、真实尾段成本；没有训练或真实流评分入口。
- `scripts/reference_evidence/gap_structure.py`：真实无损还原、F 参照类型和排自身结构可达统计；仅使用既有阶段表。
- `gap_structure_evidence.json`：逐来源／标签的分母、未支持连接 ID、真实输入 SHA、31 组真实重复等价关系的全量连接 ID，以及数学检查结果。

验证包含所有行列数各为 1—3 的二值成本矩阵，共 682 个；每个矩阵枚举全部合法完整路径，核对递推最优值及返回路径覆盖全部查询行和参考列。另对行列数各为 1—4 的 16 个固定种子整数成本矩阵做同样的路径穷举核对。

旧缺口反例在新结构中无可行出口：第一对成本 0、第二对成本 5、参考只有一对时，完整路径必须访问第二行，最终成本为 5。真实尾段成本 8 必须进入最终最大值；省略尾段成本或让带尾段查询对无尾段参考均被拒绝。重复相同对仍可零成本伸缩，既由算子检查保留，也由上述 31 组真实材料证明其实际存在。


## 7. 同学习参数的可微普通对照

`scripts/reference_evidence/paired_reference_control.py` 复用原 `RelativeCost`、`log_scale` 与 `intercept`。每个成对单元分别计算两个真实方向的局部成本后取 max，使用完整无 gap 的 Torch 递推；真实尾段单独参与 max。得分保留 autograd，只在输出诊断路径索引时 detach。旧 `WholeReferenceModel` 未改，该模块是独立普通对照。

`check_paired_reference_control.py` 完成 14 个首方向／长度自配检查、682 个二值小矩阵比较以及后段／尾段有限差分。后段解析梯度 −0.0407755982109，对应有限差分 −0.0407755982096；尾段为 −0.0173004612803 与 −0.0173004612858。检查结果保存在 `paired_reference_control_checks.json`。输入全部为合成构造，没有真实模型前向或优化器更新。合成配置的参数量只核对两实现相同，不作为实际部署模型大小。
