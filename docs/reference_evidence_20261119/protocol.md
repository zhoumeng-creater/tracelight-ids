# 正常参照真实验证口径

使用已发布的 `connection_geometry.jsonl.gz`，不重新提取包，不读取 C、harrison、Meterpreter，不运行候选模型或分类器，不拟合、评分或选择告警阈值。

1. 参考只取 F 内整连接正常且现有几何可用的 TCP 连接。F 查询排自身及 stable_flow_id 别名；同采集、跨采集／run、严格过去前缀分列。fox 是已开放开发材料，不改称盲测。
2. 统计完整方向／唯一字节序列的精确支持、段词表支持、同位置支持、单参考顺序支持。阶段特征相同不表示载荷或语义相同。正常事件保留多候选和未知标签。
3. 在相同段数与方向序列的结构域内，描述每个查询至少需要多大的逐段字节变化才能与正常参照一致。固定使用 `max_i |log(q_i/r_i)|`，指数后为所需倍率；不从标签选择可接受倍率。再用每方向总字节归一化描述阶段组成，单独识别总体积的影响。两项都是输入几何描述，不产生攻击判决或模型排名。
4. 完整参照与逐位置独立参照使用同一结构域和正常库；分别记录最小可达差异。精确身份、结构覆盖、连续接近和检测性能是四种不同结论。
5. 缺口问题先从可允许路径修正，不扫描 gap 价格或比例。若修正等价于标准 DTW／其他匹配，作为简单控制，不命名为新算法。所有阶段必须有真实对应，不以补零或缺口删除隐藏难解释部分。

精确支持的初步计数已先取得；本文件固定的是随后连续几何及缺口修复的口径，不冒称全部分析均在看见数据前登记。没有新实验批次。
