# 完整正常解释约束：真实连接的必要性与创新依据

2026-11-19。数据来自既有冻结几何和证据表；本子分析未运行真实模型、计算连续距离、选择阈值或打开保留来源；另外的固定几何分析见总报告。

## 结论

真实材料中，**410 条正常连接的各阶段，都能在同段数、同位置找到其他正常连接支持，但没有任何一条完整精确正常参照**；放宽到任意位置逐段匹配，这类正常连接有 **1,352 条**。其中 12 条连接与某个正常参照的完整阶段多重集相同，仅顺序不同。

相反，520 条几何可用的控制连接和 2 条可信下载连接，没有一条满足“每个阶段都在正常库出现”。因此，当前离散材料没有提供“攻击把不同正常片段拼起来，必须由整参考约束识别”的实例。它提供了正常组合变化的真实实例。完整约束确实区别于独立阶段匹配，但这个差别目前首先作用于正常业务，尚不能作为检测优势或创新成立的证据。

这里的精确阶段是 `(方向, 首次观测的唯一 TCP 载荷字节数)`。精确相同不表示应用语义相同；精确不同也不表示连续表示下不可比。本结果不能推出连续度量、监督学习或全部序列方法无效。

## 数据与比较口径

- 查询：既有 `connection_geometry.jsonl.gz` 中几何可用连接；源文件共 8,514 行。
- 参照：F 中几何可用、整连接正常的 6,840 行，合并为 2,797 个完整阶段轮廓。V 不进入参照库。
- 每条查询排除自身以及所有相同 `stable_flow_id` 的参照；其他物理测量恰有相同轮廓时仍保留。
- normal、control、download、unknown 分别报告；unknown 不加入正常参照。正常行数不是独立业务事件数。
- 阶段按方向连续段组织，使用首次观测唯一载荷字节；沿用已有几何资格，不重新解析原包。
- 源文件 SHA256：`7c4058d28b879ba05b2e45892d405474232acb8982e7f92a14aa1ae2d18ef050`。

脚本：`scripts/reference_evidence/necessity.py`。`necessity_queries.jsonl.gz` 为每条可用连接保留各关系的布尔值，可精确取出全部 410 条或 1,352 条连接；`necessity.json` 保存分组计数、正常标签依据、业务关联和逐段参照。

## 关系须分别判断

| 关系 | 要求 | 是否允许换正常参照 |
|---|---|---|
| 任意位置独立阶段支持 | 查询每个 token 出现在某条正常参照的某个位置 | 允许；也不要求同段数 |
| 同位置、同段数独立支持 | 第 i 段出现在某条同段数正常参照的第 i 段 | 允许 |
| 单一参照包含 token 集合 | 一条参照含全部不同 token | 不允许；忽略重复次数和顺序 |
| 单一参照包含 token 多重集 | 一条参照含足够的各 token 次数 | 不允许；忽略顺序 |
| 单一参照包含有序子序列 | 同一参照按顺序含查询全部 token | 不允许；可跳过参照额外段 |
| 完整多重集相同 | 全部 token 及重复次数相同 | 不允许；忽略顺序 |
| 完整轮廓相同 | 全部 token、数量、顺序相同 | 不允许 |

有序子序列仅用于分清“重复次数”和“顺序”造成的差异。它没有被用作模型，不认可免费跳过查询阶段，也不把免费跳过参照额外段当成有效缺口设计。

全部正常中，5,888 条有任意位置独立支持，4,946 条有同位置独立支持，4,761 条由单一参照覆盖 token 集合，4,745 条由单一参照覆盖多重集，4,728 条由单一参照覆盖有序子序列。17 条正常连接的 token 多重集可被一个正常参照包含，但没有任何参照按序包含它。

## 对机制必要性的修正

1. **必须撤下“正常拼接本身需要被排除”的任务假设。** 真实正常业务就会产生这种组合，严格一致性不是天然正确的正常定义。
2. **首段正常共享支持保留局部标签的不确定性，不推出整参考必要性。** 正连接标签不能复制到所有阶段；如果后段含正常库未见的特征，独立阶段方法也能利用它。520 条控制在精确 token 下均落入后一种情况，尚未形成需靠完整组合才能识别的攻击。
3. **V 正常的精确零覆盖不能直接当作误报预测。** 连续成本可能泛化到近似正常序列；反过来，F 内精确重复也不能证明独立业务覆盖。模型目标应保留这些区别。
4. **取消低成本缺口可修复候选定义，但不会补出攻击必要性。** 即使每个查询阶段都获得足够成本，仍需解释为什么“一条参照解释全部”比同信息独立阶段或完整序列分类器更有用。

## 与已核直接近邻的区别

| 设计成分 | 已有依据 | 本项目尚缺的实质差别 |
|---|---|---|
| 各局部阶段选正常原型，结合结构成本 | PRADOT 2025 使用特征／空间成本和 OT 学习原型；固定作者代码推理 `distM` 分支逐 patch `argmin` | 完整参考耦合确实不同于这个推理分支，但当前真实差异主要由正常组合产生，未证实攻击收益 |
| 整个窗口与一个正常参照比对，选择最近参照 | EMS-uDTWAD 2026 的粗尺度分支采用正常参考库和 uDTW | 不能把“从局部原型换成正常完整序列”单独称新机制 |
| 非负学习成本、零自距离、带插入／删除的动态规划 | 可学习度量、加权编辑距离和瓶颈对齐已有这些基本结构 | 若只是学习编辑成本，不能重新命名为新对齐算法；精确正常自匹配为零只保护已存轮廓 |
| 用连接标签学习局部证据、避免所有段继承正标签 | 流量 MIL 和 burst 编码已有直接先例；本项目可研究连接内阶段，但改变层级不足以确立原创 | 需给出受正常共享前段约束的可学习条件，并证明收益超出同信息简单聚合／序列方法 |

PRADOT 原文：[Learning local and global prototypes with optimal transport for unsupervised anomaly detection and localization](https://arxiv.org/html/2508.12927v1)。固定作者源码 `873b383c6bada49b70064d6379d92a9f5046a0ee` 第 186—223 行是 OT 原型计算，第 268—287 行是独立 patch 分配；已静态读取本地冻结副本并核对应[源码](https://github.com/robintrmbtt/pradot/blob/873b383c6bada49b70064d6379d92a9f5046a0ee/pradot/models/pradot_img.py#L268)。其图像任务不能代替流量效果证据。

EMS-uDTWAD 原文：[A Multi-Scale Time-Series Anomaly Detection Approach for Modeling the Time-Lagged Effects of Exogenous Variables](https://www.techscience.com/cmc/v89n1/68431/html)，2026，DOI `10.32604/cmc.2026.084688`。已核方法使用滞后增强窗口、正常参考库和 uDTW；本报告未声称复现其性能。

流量 MIL 前例为 ICCS 2025 的 [Encrypted Malicious Traffic Detection Using Multi-Instance Learning](https://www.iccs-meeting.org/archive/iccs2025/papers/159040260.pdf)，其 bag 是同端点的多条 flow，burst 编码后汇总；层级与本候选不同。此项沿用既有 `stage_neighbors.md` 的全文核查，本轮未追加复现。

这些来源支持“成分已有、耦合偏置可区分”，并不支持“现有方法已等同本项目所有可能学习器”。当前应保留连接级弱标签下的局部正常／攻击证据问题，本轮撤下完整参考一致性的创新主线定位，保留普通对照；不能围绕它安排新的训练矩阵，也不能把修复缺口后的得分变化当作创新证据。

同段数、同位置的独立支持与完整精确轮廓之比较隔离了参考一致性；任意位置关系还同时放松了位置与顺序，只能作为额外描述，不能称单因素对照。新成对 DTW 允许重复真实对应，因此“没有完整精确轮廓”也不等于“没有零成本完整 DTW 路径”。
