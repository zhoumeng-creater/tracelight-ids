# 正常子群高分尾部：模型与训练完整修改方案

2026-11-18。状态：唯一候选已选定，设计规格冻结；训练实现与实验室注册待完成。本文件取代11月17日“未选定具体干预”的后续安排，R30的原设计、源码标签和结果不改。

**采用原TabM+PLE，从R30三个协议屏蔽模型分别微调。唯一新增干预是F正常子群的固定单侧分位数目标：下调组内相对偏高的正常分数，同时约束其余正常分数和已有正例。部署仍为一个TabM与一次原C程序校准，不增加分组头、后处理分组阈值或模型拼接。**

本轮交付完整目标函数、数据和分组合同、训练及选轮规则、代码修改位置、验证与退出条件。未运行新拟合、模型加载、网络前向、新评分或阈值搜索。该方案具有可检验的机制，不表示已经取得新效果。

## 1. 要修正的对象与预期变化

R30协议屏蔽三个种子均已检出B的72条、D的1964条攻击；误报合规却仅8/15、5/15、4/15单元。当前目标是保住这些攻击身份，并使全部15单元满足原误报预算，不能再要求D检出超过100%。

[冻结输入与分数审查](R30_NORMAL_TAIL_DESIGN_REVIEW_20261117.md)确认：全部D TCP误报均在F的PLE全局范围内，F预处理未发现异标签碰撞，多数D TCP误报已有同计数、近时长F正常支持。seed43一个正常形态在C中23/23原误报，在D中84/84原误报；一个D单元中该组14条已超过单元预算8条。它不是靠增加PLE bin或重复相同正常记录就能解释的支持缺口。

完整F已严格正负分离，标准正负logistic pair在原分数上多数接近饱和。因此新增目标直接作用于**正常与正常之间的组别分数差异**，保留原成员BCE负责攻击判别。已开的C/D用于提出问题和最终开发回归，不参与分组、目标、梯度或选轮。

条件分布完全相同时，正常混合比例变化不会改变共同阈值下的总体误报率：

$$
P(S>t\mid Y=0)=\sum_g w_g P(S>t\mid Y=0,G=g).
$$

本方案只向这一机制推进：给偏高子群一个固定、只向下的分布目标。有限F/V拟合、稀疏组和组内漂移都使它不能推出各D单元必然达标；这些情形在验收中直接检验。

## 3. 数据、分组和参照的冻结

仅使用R30已固定F=19904、V=21450及其原身份与标签。F正常14691、正例5213；A0/A1/B0/B1分别8843/5123/5848/90。每seed从其原blind最佳工件开始，两臂使用完全相同的权重、预处理和PLE。三份起点SHA及F/V/C/E文件哈希见机器规格的输入绑定。

正常分组由F原始输入定义：A/B各建一棵平衡二叉分箱树，依次轮转优先考虑双向包数、双向IP字节数，最多4层，分裂两侧各至少256条，同值不拆；选择最接近半数的合法切点，同距取较小值，无合法切点就保留父叶。只使用四计数和训练来源元信息，不使用时长、协议、source_id、分数或D错误。精确规则见[分组合同](normal_subgroup_design_20261118/subgroup_training_spec.md)。

本次只读F统计得到32组：A的16组各430—701条，B的16组各349—385条。将固定树映射到V后，32组均有支持，A各523—1193条，B各217—375条；V的18645条正常全部覆盖。256只约束F分箱，不用它删除V较小的组。F/V四计数缺失均0；缺失处理、超范围落边叶和未知profile拒绝规则仍已固定。这个分组采用足够支持的完整经验分布，不对几十条记录声称可靠估计组内1%尾部。

分组只用于训练目标与V审计，不进入模型输入或部署路径。D没有A/B训练来源标签，不强行分入某一来源树，也不参与V的H指标；D按原全部单元和攻击身份完整回归。不得把已经观察到的D五种错误形态写成特殊组；不得根据V/C/D支持或错误重分组。

每seed在未来实现预检中，用同一确定性CPU评分路径对原工件生成F/V基准分数并冻结。这里只运行原模型的参照评分，不优化它。已有GPU F缓存用于历史证据，不能直接与新CPU数值混用作逐行硬约束。原工件在同路径冷重放不一致，则停止该阶段并修实现。

F正常分组映射、逐行原分数、逐行目标、尺度、输入身份顺序及V选择端点全部保存哈希。目标生成模块只能接收F；验证模块接收冻结组规则及V；C/E仅在全部候选工件冻结后进入评价。

## 4. 唯一目标函数

记第k成员logit为$z_{ik}$，部署分数为概率平均后的稳定log odds：

$$
s_i=\log\frac{\frac1{32}\sum_k\sigma(z_{ik})}{1-\frac1{32}\sum_k\sigma(z_{ik})}.
$$

沿用稳定logsumexp实现，辅助项通过该分数反传；不能改成平均logit。BCE仍对32个成员分别计算，辅助项会在训练目标层面耦合成员，这是本项目明确新增的部分。

设$s_i^0$为原模型F分数，正常组为$g$、大小$n_g$。按分数升序给组内并列记录相同midrank，排名从1开始：

$$
u_i=\frac{\operatorname{midrank}_{g}(s_i^0)-1/2}{n_g},\quad
Q_0(u)=s^0_{(\lceil N_0u\rceil)},\quad
t_i=\min\{s_i^0,Q_0(u_i)\},
$$

其中$Q_0$使用完整F正常的升序经验逆CDF，$N_0=14691$。$u_i\in(0,1)$，下标限制在1至$N_0$，不用线性外推或可调平滑。同组并列原分数必须得到相同初始目标。该映射不把原本较低的正常分数抬高。

上式先生成初始目标。A/B来源不是网络输入，若相同网络输入落在不同来源组，初始目标可能不一致。本次只读F检查发现1种五原始数值完全相同、跨A/B的正常输入；尚未生成目标，不能断言它已经发生目标冲突。最终将冻结FP32数值、缺失标记及UNKNOWN槽完全相同的正常记录统一为该等价类初始目标的最小值，并在后文将此最终值记为$t_i$。这保证相同网络输入目标一致、仍不抬高正常；它可能改变组内最终目标次序，不能再称精确逐组分位运输。目标构造前检查异标签同输入冲突为0，构造后检查目标非恒定，保存修正记录。

固定尺度为$\Delta=\max\{Q_0(.75)-Q_0(.25),1\}$；常数1表示原生log-odds单位，用于阻止零/极小IQR除法，不随训练更新。

$$
L_N=\frac1G\sum_g\frac1{n_g}\sum_{i\in g}
\left(\frac{s_i-t_i}{\Delta}\right)^2,
\qquad
L_P=\frac12\sum_{p\in\{A,B\}}\frac1{N_{p1}}
\sum_{i\in F_{p1}}\left[\frac{s_i^0-s_i}{\Delta}\right]_+^2.
$$

$$
L=L_{\mathrm{member\ BCE}}+L_N+L_P.
$$

两个系数固定为1，没有候选权重网格。正常损失是**对单侧生成的固定目标做双侧MSE**：超过目标要降，低于目标也会被拉回；未下调正常也保留原分数约束。不能把它实现成只罚超过目标的hinge，否则整体下移会轻易降低该项。正例项只罚分数下降，并对A1/B1各给一半权重，不能让5123条A正例稀释90条B正例。

这是一次性、原模型排名产生的运输目标回归，不是每步重新求当前分布的Wasserstein最优运输，也不是保证满足的硬约束。固定目标与正例锚减少无意义的共同平移/缩放；V选择另外使用严格单调变换不变的排名指标，排除仅损失变小、排序不变的“改善”。

**唯一控制臂**把正常目标改为$t_i=s_i^0$，其他损失、分组权重、正例保护和选择规则完全相同。因此两臂比较估计“固定单侧运输目标相对于原分数保持目标”的作用；控制臂不是纯BCE续训。

## 5. 采样、反传与固定训练预算

保留每步A0/A1/B0/B1各64条、总256的独立循环洗牌队列。BCE不叠加类别或组权重。正常辅助项单独做组等权采样校正：批内正常行$i$来自profile $p$、正常组$g$，它的MSE乘

$$
\frac{N_{p0}}{64\,G\,n_g}.
$$

对128条正常加总即估计组等权$L_N$。固定参数、按均匀行抽样取期望时该校正对应全量目标；循环无放回且参数不断更新时，不声称每步梯度对完整历史条件无偏。正例批中A1/B1各64，$L_P$为两个组内64条单侧误差均值的平均。不得把辅助权重乘到BCE，也不得再增加“困难正常”采样器。

同一批做两条前向路径：BCE使用`train()`启用原dropout，先backward；$L_N,L_P$使用`eval()`关闭dropout但保留autograd，再backward累积梯度，使目标约束部署分数。辅助前向不消费dropout随机流。两项梯度累积后只执行一次全局norm=1裁剪和一次optimizer step。不能用`inference_mode/no_grad`包裹辅助前向，也不能在两次backward之间清空梯度。TabM没有本方案新引入的状态归一化层。

| 项目 | 固定值 |
|---|---|
| 起点 | R30 blind seed17/29/43各自最佳权重；两臂配对相同 |
| 优化器 | 新建AdamW，lr=0.0002，weight_decay=0.0003，betas=(0.9,0.999)，eps=1e-8；所有原参数 |
| 学习率依据 | 原0.002的十分之一，作为保留已收敛模型的固定微调步长；不是作者验证的最佳值 |
| 精度 | 原FP32网络，无AMP；稳定ensemble分数与辅助标量使用FP64数学，梯度回到FP32参数 |
| 调度 | 固定lr；不继承原Adam动量；不加scheduler、warmup或warm restart |
| 更新预算 | 每轨迹2224=139×16步，完成16个验证事件；无性能早停 |
| 轨迹总数 | 运输/保持两臂×3seed=6；最多13344 optimizer steps；0次P重训 |
| 随机流 | 配对共享队列、batch顺序和BCE dropout流；辅助eval前向不改流 |
| 异常 | 非有限loss/梯度/权重或合同失败立即停；不自动重试不完整fit |

2224步取原R30的16个验证等待窗口，不由D结果选择。两臂固定完成预算后选轮，消除一个臂更早停止造成的更新预算混杂；选中步数仍可不同，报告的是同预算自适应选轮流程效果，不能称同一步权重的纯结构效果。

## 6. 保护、选轮与机制验收

完整数学与并列处理见[评价合同](normal_subgroup_design_20261118/evaluation_and_redteam.md)。step0保存原工件及其基准指标，始终可回退，但回退不能标为候选通过。

每139步用同一路径评价。候选checkpoint须同时满足：

1. 完整F每条正例分数不低于其原分数；不能只比较平均值。
2. 完整V每条正例被正常分数大于或等于它的数量不增加；保留原A_TCP/B_UDP面板严格分离，并不降低原面板及pooled pAUC。
3. V正常的最大并列块及并列对比例不高于step0，防止靠数值塌缩制造表面均衡。
4. 冻结组在V的10%、5%、1%三个尾部富集最大值$H_q$分别不高于step0，且$H=\max_qH_q$严格低于step0。较宽尾部的改善不能掩盖1%尾部退化。

在通过保护的checkpoint中最小化$H$，相同$H$选最早步，不看NLL或C/E。$H$在V全体正常的最高10%、5%、1%排名质量上计算：边界并列分数等比例分配尾部质量，比较各可评价冻结组尾部占比超过总体名义比例的最大正差。分组缺席和低支持的处理固定在评价合同中，不按候选表现丢组。全局严格单调分数变换不改变$H$。

训练损失下降不是机制通过。三个seed的运输臂均须相对step0和配对控制臂严格改善$H$，三个$H_q$分别不差于控制臂，同时通过上述保护，才记为机制端点通过。若控制臂同样完成开发采用条件而运输没有预设优势，不宣称需要新增运输干预。

## 7. 最终开发采用标准

全部六份选中工件、分组/目标哈希与配对收据冻结后，才允许进入原C和E_B/E_D。每模型只用C的5511条正常按原rank5457、严格`score > threshold`规则校准一次；保持alpha=0.01。保留的是校准程序，不是把R30旧数值阈值用于新尺度。

每个运输seed必须同时满足：

- B TP=72、D TP=1964，全部原R30 true-positive身份保留，逐cell与逐类新增/丢失表完整；不挑seed或平均掩盖退化。
- 原15个cell分别满足`FP <= floor(normal_n/100)`，不按总误报相互抵消。
- 单元正超额之和$X=\sum_c\max(FP_c-\lfloor n_c/100\rfloor,0)$严格小于配对控制臂；若两臂均$X=0$，本候选不满足“必须采用运输”的比较理由。只有保持目标臂也满足B72/D1964、TP身份零丢失、全部15单元预算与工件检查时，才可将它保留为有效开发结果；否则回退R30。不能改为比较另一个事后指标。
- 所有真实代码/冻结/回放检查通过；部署包仍只需原预处理、TabM权重和一个阈值。逐流成本按原CPU单线程batch1/batch128口径重测，不宣称轻量化收益。

这是已开开发材料上的修复验收。对新采集的泛化确认须在模型固定后另行确定事件到flow映射、完整正常分母、时间/设备单位与标签证据；本次不把新采集或另一训练矩阵作为默认后续。

本次新增分布约束来源及作者逐行对照见[目标设计与作者代码](normal_subgroup_design_20261118/alignment_proposal.md)。借鉴2025作者实现中按类别/组约束分布和排序分位计算，改为本任务的正常类、单侧固定目标、保留原分数的控制臂、正例保护与TabM概率平均分数；这些改造没有作者对本IDS任务的实证保证。

[AAAI 2025条件公平与最优运输论文](https://ojs.aaai.org/index.php/AAAI/article/view/33847)支持关注完整条件分布而非仅均值的原则；未确认作者代码，不称已复现。[FG-CCDB，ICLR 2026作者代码对照](normal_subgroup_design_20261118/fg_ccdb_comparison.md)说明频率重加权与输出分布约束的区别，未采用其偏置模型和多阶段流程。STACO/tapAUC不加入本轮，原因保留在前轮[作者审查](r31_design_review_20261117/author_methods.md)。

## 10. 退出条件与后续顺序

| 触发 | 处置 |
|---|---|
| 分组/目标读到V/C/D、起点重放失败、公式/梯度检查失败 | 停实现验收，修合同；不启动真实fit |
| 非有限数值或执行收据/冻结错误 | 标执行失败并打包；不当作算法负结果，不自动重试 |
| 任一seed没有安全且H改善的checkpoint | 原seed回退step0，候选机制失败；不延长2224步、不改保护容差 |
| 运输对控制没有预设排名与超额优势 | 不采用新增运输干预；不得改用另一个事后优势指标 |
| 任一B/D旧TP丢失、任一15cell超预算 | 开发采用失败；保存逐身份损失，不调阈值补救、不拼回旧模型 |
| H改善却开发误报不改善 | 记录该机制不能迁移到当前C/E；不追加group细分/权重/seed |
| 全部通过 | 候选可作为开发修复结果，完成同口径部署回放与成本说明；新数据确认单独登记 |

下一步是按第8节实现目标、损失与选择器，并完成合成数组、微型网络和工件合同核验；之后冻结独立运行注册及实验室说明。本轮只完成设计与静态材料核验，不开真实训练。
