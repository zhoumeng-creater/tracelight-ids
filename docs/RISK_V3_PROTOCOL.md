# v3 可执行开发协议与贡献边界

2026-11-03。入口：`ids.risk_research`；实验室包装：`scripts/run_risk_lab.py`；配置：`risk-v3-pilot.yaml`、`risk-v3.yaml`。本轮把已有研究审查落实为算法与对照代码，尚无本轮实验室真实结果，不宣称新方法成功。

## 问题、依据与可推翻解释

旧轮出现低FPR校准后test误报超预算、部分攻击族退化、固定KD增益不足。新假设是：冻结工作点并显式记录误报/旧攻击检出损失，比单纯平均KD更容易审计升级代价；这不是总体误报保证。训练约束若不可行、KD不优于同预算标签控制或PCT/MPT式FD/EKD，则撤回相应有效性解释。

已逐式检查 [PCT原文](https://arxiv.org/html/2011.09161v3)、[MPT原文](https://arxiv.org/html/2511.08322v2)、[EKD原文](https://arxiv.org/html/2206.02325)与作者代码，具体commit及差异写入 `risk_research.PROVENANCE` 和每次输出的 `provenance.json`；本轮再次访问原文核对。2021/2022方法是必要基础近邻，2026 MPT身份及更广2025/2026模型调查见[当前成果审查](research_alignment_20261103/README.md)与[全景记录](landscape_20261103/README.md)，不以旧基础替代近期调查。

正常项的repair-credit表达与锚点条件的capped hinge代数等价，不作为独立新损失发明。旧FP正margin区域上capped项梯度为0；本轮加入普通uncapped hinge对照检验此失效机制。后者对旧FP有梯度，但锚点slack可能更大，不能预称更优。

## 数据与教师

- 只核验并读 train/validation。pilot在角色分配前整组限量，full保留全部开发行；CIC优先联合group_id。种子固定，不重试角色/OOF，不按家族补样本或拆巨组。
- F负责预处理、锚点与三折分组教师；R仅冻结正常样本工作点/阈值网格；C提供硬监督及完整训练约束；V用于同一协议内开发选择。所有条件均获得相同F+C硬标签与正类权重。
- 每个OOF折独立拟合预处理及教师，只预测未拟合F组；每折在R冻结自己的阈值。所有折的类别/隔离先检查后才开始教师拟合。完整F教师只做V诊断，不提供F内soft target。树概率统一clip到[1e-6,1-1e-6]再转raw logit。
- 家族约束仅保护C支持≥预先固定30行的攻击族，支持不足或只在R出现的族明确记为未保护。二元类支持不等于每族支持，也不等于独立统计单位足够。

## 九条件与优化

| 条件 | 额外目标 | 用途 |
|---|---|---|
| hard | 无 | 共享标签与锚点的简单控制 |
| boundary_kd | 工作点中心化BCE蒸馏 | 不加风险约束的KD控制 |
| risk_hard | C代理约束 | 不含教师知识的约束控制 |
| risk_matched | C代理＋同系数真标签soft目标 | 排除重复标签/目标尺度解释 |
| risk_kd | C代理＋OOF边界KD | 待验证候选 |
| normal_hinge_kd | 普通正常hinge＋攻击保护＋KD | 击穿旧FP零梯度机制解释 |
| pct | 原文语义逐样本old-correct加权KL | PCT二元适配，修正作者源码广播问题 |
| dual_source_fd | 锚点/新教师独立correct mask的双源FD | MPT式二元适配，不复现类别增量bias |
| ekd | 固定R网格上的逐样本rank-count MSE | EKD适配，无人脸配对/挖掘/动量阈值 |

各条件共享锚点权重、学生[32,16]、F+C完整hard BCE、AdamW与宏步数；不把C标签只给新方法。hard按总F+C样本数归一，soft只在F上按完整F均值，EKD按全F两类各自均值；fold/chunk不改变数学分母。KD/PCT/FD统一外层β=.3，FD两源各β/2；KL的T²显式保留，EKD无T²。不同目标数值尺度仍不同，固定单一超参不是等调参预算的最优方法排行。

C代理每步用完整C图和全局分母，不能以batch分位数代替总体约束；正常FPR与攻击lost-TP mass分开，所有攻击作为分母、救回的旧漏检不抵消旧TP损失。正常代理默认capped，hinge控制独立记录。对偶先用当前λ做学生步，再用步后完整C违规量做投影更新，不做逐chunk更新。梯度裁剪只在完整目标累积后做一次。

forward分块只限制单次batch，C反向图仍覆盖完整C，**不宣称常数显存算法**。教师拟合/查询、锚点/学生训练耗时与部署包大小分别保存；正式三轮CPU延迟尚未接入本轮，不用合成耗时替代。

## 选择、拒绝与工件

所有条件先要求C实际预算和冻结R阈值下V FPR≤1%；risk条件额外要求C代理预算满足。合格检查点按V TPR最大、FPR最小、最早步数选取。额外代理可行条件是risk方法自己的求解要求，报告需同时列实际/代理可行率，不能只比较筛选后赢家。V阈值曲线另存为描述项，不用于重新调冻结阈值。没有合格检查点保留末步诊断模型，明确不合格，不能删除失败种子或家族。

导出CPU后再复核原始logit下C实际/代理预算和V误报。CPU/GPU决策差异、概率阈值转换差异显式记录；部署契约为原始logit，使用专用重放入口。若CPU复核失败，降为诊断结果，不回填阈值或换检查点追求通过。

数据/源码/配置/角色/固定阈值与所有输出均有身份绑定，source随包封存，训练中源码变更拒完成。恢复只接受完整工件，核当前身份；半程不可续训但保留逐步history。完成标记不证明实证优势。

## 仍需完成的研究

本轮九条件是首个可执行近邻矩阵，**不是“市面方法已全部比较”**。成熟pAUC/CVaR低FPR目标、经过独立调参的强表格基线/教师、正式CPU重复资源测量和真正未见数据上的确认尚未完成。LibAUC原版有每正例持久u状态，不能用batch top-k冒充；本轮不以未经验证的替代版填表。此前TabM适配与v2结果必须保持各自预算/版本边界，不能拼成v3胜出结论。当前创新性仍待真实结果和机制分析支撑，不以更多条件或代码行数冒充。
