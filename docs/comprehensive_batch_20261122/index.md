## 六种目标分别回答什么

沿用两个完整 F 正常来源参照、九个既有正常业务组以及相同攻击池。令参照边界为 $q_j$，业务边界为 $e_u$，$a=\min s(\text{attack})-1$。边界仍是 1% 整数预算的实际顺位，严格大于才告警。

$$
D=[e_{\max}-q_{\min}]_+,\quad H=[q_{\max}-a]_+,\quad G=[e_{\max}-a]_+,
\quad R=D+H,\quad S=D+G.
$$

现有业务完整划分保证 $e_{\max}\ge q_{\max}\ge q_{\min}$。六臂均保留相同的类别均衡 BCE，D 单独出现时也没有移除攻击监督。

| 臂 | 附加目标 | 必要问题 |
|---|---|---|
| A_BCE | 无 | 普通模型是否已足够 |
| H_reference_attack | H | 只按正常参照边界保持攻击间隔是否有用 |
| D_reference_alignment | D | 正常参照对齐本身是否有用 |
| G_group_tail | G | 简单业务尾部分离是否已足够 |
| R_reference_envelope | D＋H | 原参照约束配方的整体作用 |
| S_alignment_group | D＋G | 保持 G 的攻击项不变，只加入同一个 D |

A/H/D/R 给出两个组成项的完整消融；S−G 与 R−H 检验加入 D 的作用；R−S 检验攻击边界的切换。R−G 继续报告，但不再把它单独解释成 D 的贡献。详细关系、反例与结果解释见[机制说明](mechanism.md)。

## 固定矩阵与计算量

| 目标 | 学习率 | 完整辅助项权重 | 种子 | 从头训练轨迹数 |
|---|---|---|---|---:|
| A、H、D | 0.002、0.0005 | 1；A 不使用辅助项 | 17、29、43 | 18 |
| G、R、S | 0.002、0.0005 | 0.25、1、4 | 17、29、43 | 54 |
| 原覆盖×端口 HGB 四臂 | 沿用原注册 | 沿用原注册 | 原固定种子 | 最多 4 |

共 72 条 TabM 轨迹，每条最多 31,200 次更新。三个主要辅助目标使用相同的权重、学习率组合，覆盖两者交互；没有把候选的最佳配置与只跑一次的简单基线比较。A 不为无效的辅助权重重复训练。H/D 用于成分消融，不扫描它们的权重。

每条轨迹在 **3,900／7,800／15,600／31,200** 步保存检查点，同一轨迹连续运行，只训练一次。共 288 个 TabM 评价工件，加四个 HGB 为最多 292 个。初始状态另作诊断保存，不参与 C 校准或开发比较。原 HGB 四臂若已有绑定正确的完整模型，可直接复用；否则纳入本次训练，不单独再安排一轮。

主比较固定为学习率 **0.002**、权重 **1**、**15,600** 步的六臂三种子。其余全部属于已登记的配方／预算敏感性，不以开发结果重定主比较，也不挑最好的种子或检查点。

本项目选择较低学习率、几何间隔权重和四个预算点，用于检查已知训练问题；这些具体数值不是作者保证有效的配方。仍沿用 TabM＋PLE 的结构、AdamW、batch 256、类别各 128、weight decay 0.0003、梯度裁剪 1、固定常数学习率和相同预处理，不再同时搜索网络宽度、层数、dropout、优化器和多种骨干。

训练共 **2,246,400 次参数更新**，BCE 抽样 **575,078,400 行**。66 条辅助目标轨迹的完整 F 发现评分共 **27,288,518,400 行**，是原九次包的 **22 倍**，另计活跃块反传和固定诊断。实际墙钟时间由实验室运行记录提供；一次启动不代表低计算成本。

机器可读的全部任务与比较见 [plan.json](plan.json)。预算档不再额外从头拟合，完成的任务续跑时校验后跳过。

## 一次保留足够解释结果的材料

训练每 100 步记录成员 BCE、辅助目标、梯度范数与裁剪比例、采样进度及累计时间。在初始状态和四个预算点保存：

- 模型、全部 F 部署分数及身份、逐样本曝光次数，按来源和控制／下载分别汇总；重复抽样不算新增独立攻击。
- 六种目标的诊断、18 个参照—业务配对的实际整数 FP、并列边界、攻击间隔和边界身份。
- 集成部署分数的 BCE，与训练成员 BCE 分列；BCE、D、H、G 的参数梯度范数及方向，观察辅助项是否压过或抵消分类梯度。
- 本轮检查点更新幅度、正常分数同分情况及每个来源／目标的损失。

训练过程不读取 C、fox／OpTC，也不据它们提前停止。所有任务完成或记录为确定失败后，先冻结可用工件，再统一计算 C 阈值，所有阈值冻结后才评价开发材料。

保存每个工件的完整分数数组，共享同一份身份、事件和业务成员表；成对报告保存全部变化身份，不为数百组比较重复存储相同元数据。原始分数与阈值足以恢复每个连接的判决。

## 中断与失败怎样处理

每 100 步及预算点在参数更新完成后保存原子恢复点，包括模型、AdamW、CPU／CUDA 随机状态、采样器队列与游标、步数和统计。恢复只重放 CPU 抽样以恢复校验流，再继续同一训练轨迹；不自动换种子、batch、学习率或重新初始化已训练模型。

资源不足、进程中断等保留现场，解决后以同一命令加 `-Resume` 继续。某条轨迹出现数值失败时保留已有检查点与错误，继续其他独立任务，不让一个失败使全部批次失去结果；缺失种子和检查点必须在最终表中显示。读取 C 后，训练永久关闭，只能恢复评分、报告和打包。

## 评价、成本与固定出口

逐个预定义正常单元报告 1% 整数预算、FP 与超额，分别报告控制／下载的连接检出、事件候选上下界及全部新增／丢失。三个种子逐个展示；不把大量重复连接、重叠正常单元或参数组合当作独立证据，不用最好的结果代替主比较。

所有工件都报告模型大小及实际训练／评分成本。v1.1 并发训练的任务耗时包含资源竞争，不能据此比较各目标的独占训练速度；发现／回放行数及更新数仍按原口径记录。默认学习率、单位权重、主预算的六臂三种子，加四个 HGB，共最多 22 个模型在独立进程中测 CPU 4 线程的单条与 batch 256／1024：预热后分三轮保留原始计时，给出 p50、p95、吞吐与工作集内存。范围从已提取特征到分数，包含预处理，不冒称包含抓包、特征提取和告警送达的端到端延迟。

| 结果 | 本批即可作出的判断 |
|---|---|
| D 相对 A 有收益，R/S 没有额外收益 | D 有增量，攻击辅助项未显示必要性；保留简化候选及完整取舍 |
| S−G、R−H 支持，而 R≈S | 参照项有依据，R 特有的攻击边界没有额外依据 |
| 只有 R−G 改善，干净的加入项对照不支持 | 不能独立归因于 D；按边界选择与训练路径交互解释 |
| 仅长预算、较低学习率或特定权重有效 | 明确依赖该配方，主配方结论不改写；所需比较已经同批完成 |
| 训练后期退化 | 用已有四档模型和判决定位变化，不为恢复中期模型重训 |
| 损失或 gap 下降，实际判决不改善 | 没有目标检测收益，不调整分数尺度或阈值补救 |
| 误报下降伴随控制／下载丢失 | 列明每个得失，不用总 TP 掩盖下载损失，不事后补成功门槛 |
| 全部已登记配方均无实际增量 | 关闭这套目标与优化范围内的候选，不追加临时网格 |

三种子均有实际正常业务改善且无控制／下载或事件界退步，可标记清楚的优选候选，但不是永久逐 TP 零损失要求。没有用户给定的数值采用门槛时，不按结果倒定最低检出率。
