# 有向交互记忆：同信息近邻、读取损失与创新边界

2026-11-19。本文负责代数、作者实现与可归因差异，不给真实检测成绩。实际流序列结果由本轮统一读取另行汇总。没有训练、模型评分或阈值计算。

**当前候选的实质差异已收紧为“逐交互对归一化，再按查询汇聚”，而不是新的历史信息或新的记忆更新。** 与同信息有序二阶统计相比，它改变不同交互对的权重，同时在查询读取中丢失部分信息。这个偏置可能帮助稀少但有效的关系，也可能放大弱证据。仅凭公式不同、真实特征值不同或胜过均值，均不足以成立算法创新。

## 1. 精确同信息、同状态预算的近邻

设每批已经到达的非负编码和为 U，衰减因子为 rho。持久状态只存一阶 P 和非对角有序二阶 B：

```
P_minus = rho * P
B_minus = rho**2 * B
B = offdiag(B_minus + P_minus outer U)
P = P_minus + U
```

同刻查询先读取旧状态，再用整批 U 更新。严格排除同批内部先后。

令 `A = B-B.T`、`S = offdiag(B+B.T)`，则逐元素与原候选递推相同。反向由 `B_ab=(S_ab+A_ab)/2` 恢复每个非对角坐标。两者都存 `r+r(r-1)=r²` 个数；r=13 都是 169 个数，紧凑 FP32 加一个 FP64 时钟都是 684 字节。两者每批更新及查询都为 O(r²)，没有随历史长度增长的存储。代码中使用 float64 做代数核验，684 字节是 FP32 理论载荷，不是本 Python 实例实测内存。

因此，可以在每个真实查询上用 B 精确重构原候选的三个读取分支，而无需训练任何模型。这种等价计算不是一个应重复拟合的实验臂。它只检验实现是否正确、是否存在额外信息或隐藏状态。

可运行模块：[ordered_pair_neighbor.py](../../scripts/order_evidence/ordered_pair_neighbor.py)。40 批独立 A/S 递推与 B 递推的最大读取绝对差为 `2.220446049250313e-16`；同信息逆变换也一致。结果见[代数检查 JSON](ordered_pair_neighbor_checks.json)。这些人工数组只验证函数，真实序列检查应逐查询重复同样的恒等式。

## 2. 一个更严格的同预算读取对照

使用同一状态 P/B、同一查询权重 g、同一输入映射、同一支撑分支及同一分类头，仅改变归一化和汇聚的顺序。

原候选：

\[
d_a=\sum_{b:S_{ab}>0}g_b\frac{A_{ab}}{S_{ab}}.
\]

先汇聚再归一的近邻：

\[
G_a=\sum_{b:S_{ab}>0}g_b,
\qquad
\tilde d_a=G_a\frac{\sum_bA_{ab}g_b}{\sum_bS_{ab}g_b},
\]

分母为零时取零。G 匹配原候选的有效查询权重总量；否则差异会混入对角／无支持坐标造成的总权重变化。两者最终都输出：

`[direction, log1p(S @ g), log1p(P)]`，共 3r 个数。

此时差异可以精确写成：原候选以 g 加权每个方向比；近邻以 `S_ab*g_b` 加权方向比，再乘相同 G。**原候选相对提高了低共现量交互对的权重。** 原候选没有增加模型参数或持久状态，也没有选择更长历史。这使同一个分类头可以严格保持输入维数和参数量，无须用“大 MLP 读全矩阵”的不同头预算解释结果。

上述对照是对当前候选的代数分解，不声称某篇作者论文已经实现这个精确版本，也不是新增实验安排。归一化顺序的区别属于固定权重／表示偏置；它本身仍不能直接充当原创贡献。

模块 `read(query)` 返回 `candidate` 和 `pool_then_normalize_matched`，均为 3r 维；同时保留方向、支撑和 G，供真实查询比较。它不把任何方向值当作攻击分数。

## 3. 查询读取确实会丢信息

固定非零查询 g，反对称矩阵到向量的映射 `R -> Rg` 的秩为 r−1，因为 `g.T @ R @ g = 0`。r=13 时，78 个反对称自由度最多读出 12 个独立组合，剩余核维度为 66。查询变化可以读取其他组合，但某次查询不拥有这些其他查询结果。

存在可实现的历史碰撞，而不只是任意构造矩阵：用三个 one-hot 交互类型，比较序列 `012012` 和 `100221`。它们的 P 都为 `(2,2,2)`，S 的每个非对角项都为 4。A 的三个上三角项分别为 `(2,2,2)` 和 `(0,4,0)`。对同一 `g=(1/3,1/3,1/3)`：

- 两者方向都为 `(1/3,0,-1/3)`；
- 两者 `log1p(Sg)` 与 `log1p(P)` 相同；
- 原有序二阶状态 B 不同。

所以“按当前查询读取”可能丢掉该查询下本来可用的次序信息。反过来，这种压缩也可能在有限标签下减少无关变化；只有真实可比业务能判断哪一种后果占主导。不能用这一碰撞证明候选必然无效，也不能把读取输出更短等同于检测更好。

## 5. 标准几何签名为什么不是自动同信息

普通分段线性几何路径二阶还含自身项 `Q=sum_i w_i² u_i u_i.T`。严格同批不配对时，Q 应用每个 batch sum 而非每条记录计算。此时 `S=offdiag(P P.T-Q)`。

所以仅给 P/A 的二阶 log-signature 对照比候选少了 Q 所携带的事件划分信息。公平状态是 P 加非对角 B，或 P/A 加非对角 Q。二阶机制是否足够、归一化是否有价值，需要分开判断。

候选用每条完成流的非负编码作为累计路径增量；直接把一条条 raw8 当作路径位置再计算签名会产生另一种表示，不能混称同一输入。这里的精确 B 近邻避免了该适配歧义。

## 6. 真实材料应该怎样解释

同一攻击与正常的方向数值不同，只证明表示随输入不同；未控制当前流形态、主机、服务、前缀长度和业务时段时，也可能只是环境指纹。按已知攻击标签把某一方向挑成判别规则，又会变成未登记的评分器。

本轮真实分析应分清三个问题：

1. **物理先后证据**：查询前是否真的已观察到不同形态的关系，且对应可靠正常业务也有可比较历史；晚到控制不能补入。
2. **可比业务的关系差异**：在已定输入、主机／服务和真实时间条件下，这种关系是否仍有一致的攻击—正常差异。多条同 campaign 不能当独立环境，无法匹配的事件必须直接列出。
3. **原候选相对近邻的差异**：逐对归一和质量匹配的先汇聚后归一是否实际改变这些样本的表示，改变发生于什么稀少交互对。如果本来没有差异，连固定归纳偏置这一可检验对象也不存在；如果有差异，仍不能跳到检测收益或原创成立。

纯特征分析可以否定依据不足的设计，不能替代同预算分类器的真实检测比较。本轮没有为弥补这一边界安排拟合、阈值或新来源。

## 7. 创新结论与出口

当前可支持的描述是：**一个采用成熟有序二阶状态、偏向低共现量交互对的固定查询表示。** 更新、信息量和状态成本没有超越精确 B 近邻；查询压缩还有可构造的信息损失。逐对归一化是确定性权重选择，尚不足以承担项目所要求的实质算法创新。

只有在真实可比业务中先确认稀少关系具有判别依据，且其价值不能由当前流、一阶支撑或同信息的直接读取解释，才值得进一步讨论这个偏置。不因当前候选未成立而自动追加层数、学习门控或新损失。若真实差异主要来自业务时段、服务身份、事件划分或缺失模式，就结束该候选，不把它包装成控制／下载的先后机制。
