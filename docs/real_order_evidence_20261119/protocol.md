# 真实先后关系的固定分析口径

2026-11-19，在计算候选的真实表示之前写定。目的是判断现有证据能否支持机制；不拟合分类器，不产生告警，不选阈值。

使用已打开的 santos、fox、OpTC 声明轮转与 Unraveled 完整捕获。russell 校准和 harrison／Meterpreter 保留来源不参与本分析。历史按原来源组、监控主机独立积累，使用原有可用时刻；AIT／Unraveled 为离线导出网络时钟，OpTC 为原声明的流结束重放。每批查询先读，再整批更新，未知记录保留为未知。

输入采用上轮候选的 13 维：五个数值 log1p、五个缺失标记、TCP／UDP／其他协议。五个数值分别除以 F_expanded 中该列严格正 log1p 的中位数；求尺度不读取类别标签，不使用 C/V/外部开发。缺失数值填 0，缺失标记为 1；真实零与缺失分开。协议和端口用于业务匹配时，匹配结果只服务解释，不成为新增模型输入；两端口不进入表示。

本次取 lambda=0，检查完整前缀的顺序信息，不选择一个没有业务依据的半衰期，也不做衰减网格。结论限定于这个固定、无衰减的真实表示；状态等价性的代数结论对共同指数衰减仍成立。

计算两个状态：候选的 P/A/S，以及独立递推的 P/非对角 B。逐查询核实后者是否重建完全相同的候选读取。两者数值状态均为 13²，FP32 加 FP64 时钟均为 684 字节。这是数值载荷，不是资源实测。

同一 P/B 状态另外比较两种 39 维读取：

- 逐关系归一化再汇总：d_pair = (A/S)g。
- 先汇总再归一化，并匹配有效查询权重：d_pool_i = G_i (Ag)_i/(Sg)_i，其中 G_i = sum_j g_j 1[S_ij>0]；零分母取 0。

二者共同保留 log1p(Sg) 和 log1p(P)。不把没有匹配 G 的整体缩放差异归因于稀少关系。

真实比较分层使用同主机／来源组／协议／目标端口；Unraveled 另列攻击发生时段的正常 TCP/443。AIT 不把正常云盘和攻击内网服务冒充同服务。OpTC 正常轮转与攻击轮转分列，不把不同起始边界拼成一段历史。

对攻击连接，分别找到上述同层正常中时间最近者、当前输入最接近者，两个结果都报告，不挑更有利的一种。拆解 R_A g_A - R_N g_N = (R_A-R_N)g_A + R_N(g_A-g_N)，区分历史状态变化与当前查询形态的作用。距离只是描述量，不解释为攻击得分或判决性能。

另外做一个明确的事后归因读取：从前缀中删除已有可信正标签连接，再保持当前查询不变重新计算。它只检验已标注攻击历史对该表示的影响；不是可部署输入，不证明因果，不把未标注历史当正常。全体查询和事件候选保留，歧义事件不选最有利父连接。

不以连续表示几乎没有完全重值宣称可分，不由某一坐标的差异选分类规则。报告真实正常反例、混杂、同信息重建误差与读取差异；如果仍无法辨明攻击特有顺序或相对近邻的价值，就结束该候选的本次推进，不安排训练或追加窗口。
