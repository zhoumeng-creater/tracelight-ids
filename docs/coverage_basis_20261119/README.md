# 覆盖落实与固定单流对照

本轮完成统一数据、撤下固定历史摘要，并将必要实验收束为监督来源与端口输入的四次固定 HGB 对照。尚无本批次的真实训练结果，也没有新算法优势或创新已经成立的结论。

统一表包含 **47,285 个事件／对象、209,722 个唯一网络观察、102,409 条关联**。事件／对象、网络连接、作者流注释和独立攻击链分别保留单位，不能把它们的数量互相替代。

| 产物 | 已完成内容 |
|---|---|
| [正常来源 v2](normal_calibration/v2/README.md) | 整个 russell 的 3,475 条正常连接；33 次核实下载，188 条文件请求候选连接；标签与连接状态、活动完整性分列 |
| [完整 Unraveled](attack_coverage/full_capture/README.md) | 47,032 条全捕获观察；目标主机正常 12,308、C2 473、其他攻击 11、未知 32；全部目标作者流都有原包对应 |

原 C25 曾在本轮 v1 中被额外的 SF 和完整活动门槛排除 9 条。逐条核实表明其正常依据没有被推翻，v2 已纠正并保留全部 25 条。v1 表保留为历史，不作为当前校准数据。整个 russell 只用于 C，fox 和 OpTC 承担开发评价，不再用同一次业务的早晚片段充当独立角色。

新来源只扩充了 C2 监督，没有增加已核实恶意下载监督。四臂使用同一 C、相同评价单位和固定工作点，控制与下载分别报告。预先指定 `mixed_ports_zero` 为主参照，其他三臂解释监督覆盖和端口的作用。普通 HGB、扩充监督和端口置零不是原创算法；本批次用于取得能够决定研究路线的真实基线结果。

代码位于 `research/coverage-basis-20261119` 分支。实际实验角色与输入由独立注册确定，事实表中的 `new_batch_registered=false` 表示事实装配本身不授权训练；实验室使用新四臂注册，不使用原 HGB8/HGB27 配方。完整原件保留在本地，版本库包提供训练输入、事件关系、原件来源与哈希、提取和装配脚本。

版本库保留完整的 `unified/flow_rows.jsonl.gz`、事件表和关系表；重复的 `observations.jsonl.gz` 详细视图、逐包账本、第三方论文／源码原件及部分原始提取日志只留在原工作目录。文件名单见 `delivery_receipt.json`；实验室运行所需输入全部随包提供，无需重新下载抓包或运行 Zeek。原件的来源、版本、哈希与获取脚本保留。
