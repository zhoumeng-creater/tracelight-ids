# 整个 russellmitchell 来源的正常校准候选 v2

**若将整个 russellmitchell run 只分配给正常校准，现有材料可提供 3,475 条正常证据充分、raw8 与上下文均可用的连接。** 原 v1 的 270 条角色未定记录可以全部进入这个候选集合：它们本已满足 v1 更严的行级依据，只因关联组件未结束而未获早／晚角色。整来源分配取消了这项内部时间角色障碍，没有把未知标签改成正常。

v1 另误加了“TCP 状态必须为 SF”和“用户活动必须明确结束”两项正常身份门槛。修正后恢复 2,222 条有充分作者正常请求／用户依据的连接：其中 1,394 条为非 SF，另外 828 条本已为 SF、只被活动门槛挡住。部分非 SF 记录同时触发过活动门槛，不能将原因计数相加。原 v1 数据保留不覆盖。

## 三层分别记录

`label_evidence_qualified` 与 `label` 只表示正常证据是否充分：整观察区间在作者有效期内，存在原始服务请求，所有可能请求均无作者攻击标签且属于已知正常内部用户；ownCloud 还要求正确代理端点和前后端请求身份集合闭合。没有未知 actor 或攻击请求才给 `label=0`。活动没有明确结束、请求发生在活动间歇，不自动推翻已知用户与作者正常请求的事实。作者对正常日志的规则及原行号配对见[数据集说明](https://zenodo.org/records/19483937)。

`input_quality` 单列 `conn_state`、raw8 缺失、EOF、上下文与捕获截断事实。RSTO、RSTR、S3 不因没有优雅关闭而失去正常标签；`model_input_ready` 只核对固定 raw8、已有上下文和有限导出时间是否可供当前输入使用。当前 3,475 条正常记录均满足这项输入条件。

`role/source_role=C_candidate_whole_run` 表示完整 russellmitchell 来源的候选分配；`calibration_candidate` 另要求正常证据与输入均具备。未知行仍保留 `label=null`，不能因来源归 C 就成为正常样本。fox 和 OpTC 的正常验证按其独立来源登记处理，本脚本不改那些表。

## 旧 C25 的明确修正

v1 的 16 条未定分为：9 条被附加行级门槛排除，7 条正常身份已知但组件角色未定；其余 9 条曾分到后期验证。

9 条行级排除中，6 条仅不满足 SF 条件：S3 三条、RSTO 三条；另外 3 条均属于已知 `internal_employee_3`，请求落在没有明确结束、随后又开始活动的 ownCloud 片段内。**未知客户端、无活动候选、作者攻击请求均为零。** 这不是旧 C25 正常标签被新证据推翻；是 v1 把额外输入／活动要求混入了标签判断。v2 的 25 条原输入均保持相等，全部保留正常证据和校准候选资格。逐条状态、原因和修正见 `historical_C25_disposition.json`。

## 工件与覆盖

- `connection_candidates.jsonl.gz`：全部 16,374 条目标服务观察，含分开的标签、输入和角色字段；原 v1 字段封存在 `historical_v1`。
- `qualified_connections.jsonl.gz`、`C_candidates.jsonl.gz`：3,475 条正常证据充分、当前输入可用的候选；复用原 flow_id、stable_flow_id、raw8 与完整背景上下文。
- `business_episodes.jsonl.gz`：255 个原活动，保留旧角色，仅增加整来源候选角色；`episode_flow_links.jsonl.gz` 保留所有实际活动候选关联。
- `file_business_evidence.json`：33 次下载动作、33 个请求与 188 条连接候选的去重对应。
- `summary.json`、`policy.json`、`source_receipt.json`、`output_receipt.json`：计数、修正规则与输入输出哈希。

四天实际连接数分别为 721、277、1,030、1,447，覆盖三个内部用户。正常连接关联了 170 个活动候选；499 条连接没有解析到具体活动边界，但其全部请求仍有已知用户和作者正常标签依据。这些数量不是独立样本数：同一模拟、用户和服务之间存在相关性，不能据连接数超过 299 宣称总体误报率不超过 1%、置信度 95%。[NP 原文的样本独立同分布要求](https://jsb-lab.org/wp-content/uploads/2018/02/ScienceAdvances_eaao1659.full_.pdf)

本次仅重新装配标签证据与候选角色，没有训练、评分、阈值计算或重跑原始提取。
