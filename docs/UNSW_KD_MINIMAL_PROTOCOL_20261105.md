## 1. 决定与要回答的问题

下一步有依据安排 **UNSW、一个现成教师、一个现成 small 起点、四个训练臂、每臂固定 40 次全 F 更新**。新增教师拟合 0 次，warmup 拟合 0 次，学生续训 4 次。结果出来后先按本协议作停止／继续判断，不自动展开温度、权重、架构或多 seed 搜索。

检验的问题是：在相同硬标签、输入、学生起点和梯度预算下，**真实教师概率与输入的对应关系，能否带来超过硬标签续训、随机对应控制和类别平均软化的低误报检出收益？**

这是一项普通 KD 的机制与应用筛选，不提出新蒸馏算法。它测试已有 warmup 后的 KD 续训，不替代从头训练 KD 的结论。

依据分三路并行审查：[论文与固定作者实现](research_alignment_20261105/unsw_kd_sources.md)、[本项目工件与目标检查](research_alignment_20261105/unsw_kd_artifacts/artifact_review.md)、[独立设计审查](research_alignment_20261105/unsw_kd_design_review.md)。本轮实时核查 11 项相关成果；直接近邻展开公式和源码，其他条目标明阅读深度。没有运行或复现外部项目。

## 4. 四臂与同尺度目标

令 $N_c$ 为 F 中硬标签类别 $c$ 的行数，$w_i=1/(2N_{y_i})$，因此每类总权重均为 $1/2$。四臂仅改变目标 $r_i$，统一计算

$$
L_a=\sum_{i\in F}w_i\,\operatorname{BCEWithLogits}(z_i,r_i^{(a)}).
$$

| 臂 | 目标 | 控制的问题 |
|---|---|---|
| H：硬标签续训 | $r_i=y_i$ | 同一起点继续优化本身是否足够 |
| K：真实普通 KD | $r_i=(y_i+0.3q_i)/1.3$ | 原始教师实例对应信息是否有用 |
| S：固定模式置乱 KD | $r_i=(y_i+0.3q_{\pi(g(i))})/1.3$ | 保留类别概率边际和重复结构，破坏允许层内的实例对应 |
| M：类别条件均值软化 | $r_i=(y_i+0.3\bar q_{y_i})/1.3$ | 保留每类平均软化，去掉类内置信度差异 |

固定 $\lambda=0.3$，来自已有配置，归一化 soft 比例是 $3/13$，不是 0.3。T 固定为 1，不搜索这两个参数。普通 KD 的恒等式为

$$
\frac{\operatorname{BCE}(y,p)+0.3\operatorname{KL}(\operatorname{Bern}(q)\Vert\operatorname{Bern}(p))}{1.3}
=\operatorname{BCE}\!\left(\frac{y+0.3q}{1.3},p\right)-\frac{0.3}{1.3}H(q).
$$

右侧末项与学生参数无关。使用一个混合目标即可在一次前向中得到相同梯度。旧 raw_kd 是未归一化的 hard+0.3KL，并做两次全 F 前向；不能直接调用它作为公平实现，也不能复用历史 hard 成绩省掉 H。

网络前向和参数保持 float32；四臂统一将 logits 转 float64 计算 BCE，目标及类别权重使用 float64，梯度返回原 float32 参数；不开 AMP。每个 chunk 使用全 F 的 $N_c$，不能用 chunk 内类别比例或逐块均值重新归一化。先完成全部 chunk 梯度累加，再一次裁剪、一次 AdamW 更新。教师目标分支固定且无梯度。

合成 CPU 检查验证了混合 BCE 与项目原生 KL 对独立 float64 logit 向量的梯度关系，最大绝对差 $1.39\times10^{-17}$；在该向量上分块求和与整批求和的梯度差为 0。这验证了目标代数与全局分母，真实 float32 网络的逐块参数梯度累加仍需在训练入口落实后检查。记录见 [objective_verification.json](research_alignment_20261105/unsw_kd_objective_verification.json)。

### 4.1 S：保持重复结构的唯一固定置换

完整特征模式由 F 的 feature_hash 定义。已核 49,507 个模式内原始 q 逐值恒定。每个模式记录 $(n_0,n_1)$，只在相同计数向量的模式之间交换 q，不使用 attack_cat。

固定算法：

1. feature_hash 字典序定义模式编号；$(n_0,n_1)$ 字典序遍历各层。
2. NumPy default_rng(SeedSequence([17,353])) 只初始化一次。
3. 对含至少两个模式的层，order=rng.permutation(indices)，donor[order]=np.roll(order,1)；单模式层不动。
4. 每行使用其模式 donor 的 q；一次生成，40 步全程复用。

这样精确保留两类的行级 q 多重集合，也保持同输入同教师概率；非单模式层没有模式自映射。它仍保留 q 与模式大小、标签组成的关系，不能称为消除了全部输入信息。

F-only 检查结果：132 层，49,461 模式／82,940 行可交换，占 F 行数 96.5362%，覆盖原 $|q-y|$ 质量 98.3163%；最终 82,045 行的 q 实际改变，占 95.4944%。46 个单模式层的 2,976 行保持不动，另有 895 行因 donor 的 q 相同而数值不变。

类别边际逐值一致、模式内 q 唯一两项均已通过。正常／攻击的可交换行覆盖分别为 98.8047%／95.4716%，软化质量覆盖为 97.9533%／98.4866%。训练前要求两类的这两项覆盖均至少 90%，并且实际目标改变量大于 0；若不符，判为输入或构造偏离，不重抽 seed。

固定 donor int64 SHA 为 55a0a11e05da3eeecd300f0ed38de76a15f52fdb77fa593c457621a00c6640c6，行级 q_perm float64 SHA 为 d8e453b4baa77d8a01eef0c9b51b46bb88c336479356ea48aa17f2504ae1ede0，均按小端连续字节计算。正式入口应重新构造并逐字节核对。

原逐行标签内置乱会在 4,770 个模式、41,175 行中制造同输入异 q 的额外冲突，因此不采用。上述构造只确定一次，未根据续训结果选择映射。一次固定 S 不构成置换显著性检验。

### 4.2 M：平均软化匹配

F 上 $\bar q_0=0.04288529271315426$，$\bar q_1=0.9571102499731591$。混合后两类目标为 0.009896606010727905 和 0.9901023653784212；从绑定的原数组重算，不使用文中截断值生成目标。

M 利用 F 的硬标签作类别条件平滑，不是仅依赖输入的教师 $q(x)$。混合标签的重复模式可能获得不同 M 目标，这是有监督规则的定义。uniform q=0.5 会造成每行 0.1153846 的目标移动，是实际 KD 平均移动的约 11.66 倍，故不占用一个实验臂。

## 5. 精确训练预算与固定终点

四臂均从共同 anchor 深拷贝网络状态，分别新建 AdamW，不复用 warmup 优化器。参数为 learning_rate=0.001、weight_decay=0.0001、betas=(0.9,0.999)、eps=1e-8、amsgrad=false；相同设备明确使用 foreach=false、fused=false。固定 seed17、threads=4；固定 F 原行序，chunk_size=2048，gradient_clip=10，学习率恒定，无调度、dropout、随机数据增强或采样损失。

|---|---:|---:|
| 新教师／warmup 拟合 | 0／0 | 0／0 |
| 学生续训 | 1 | 4 |
| 全 F macro-step／optimizer update | 40 | 160 |
| 每步 chunk 前后向 | 42 | — |
| 带梯度的样本前向量 | 3,436,640 | 13,746,560 |
| backward 调用数 | 1,680 | 6,720 |
| 主终点 R+C 评分行数 | 36,821 | 147,284 |

共享 step0 只评分一次，额外 36,821 行；step0 加四个终点共 184,105 行，无需每步在 R/C 上评估。F 逐步损失来自训练前向；记录 hard/soft 分解、更新前梯度范数、裁剪是否触发和累计行数，无额外 F 模型查询。计时调用和工件回放另计，不混入梯度预算。

**step40 是唯一主终点；step0 仅核验共同起点。** 不按 C 早停，不保存或改选“最佳 step”，不在 step25／step40 中择优。保存每臂最终权重与全部 40 步 F 训练日志；四臂全部完成才统一解释结果。非有限损失等技术故障应保留失败工件，不换超参继续同一轮。

网络无 dropout、按固定 F 顺序累积全梯度；冻结 anchor 后只改 continuation seed 不形成新的训练重复。此轮单一起点不估计 seed 方差。后续若值得复核，需另训不同初始化的 warmup 并另冻结其预算，不能把同一起点重跑称为多 seed 验证。

本机仅进行已保存工件分析及合成检查。真实四臂和正式 CPU 测量均在实验室完成；新增训练墙钟与 GPU 峰值显存实际记录，不预估为已测成本。既有教师／warmup 成本单列为历史投入，不记为算法零成本。

## 6. 工作点与主比较

每个 step40 模型独立使用相同函数登记 $\tau_a=\max(\tau_{a,R0},\tau_{a,C0})$。沿用 transfer_diagnostics.training_threshold：normal 升序数组索引 $N_0-\lfloor0.01N_0\rfloor-1$ 的值向正无穷取 nextafter，分数及阈值都用 float64，报警规则为 score≥threshold。

R 的正常预算为 39 条，C 为 78 条；相同分数并列可能使实际 FP 更低。tau 仅由这两个正常池产生，不为挽救漏报手动移动。R/C 的 1% 是该开发池上的工作点，不是独立部署保证。

同时报告 max_fpr=0.01 的 McClish 标准化 pAUC及 raw pAUC，采用现有 binary_rank_metrics。主要比较是 **K−H、K−S、K−M**，H/S/M 的相互差异只帮助解释，不用于改选本轮候选。

## 7. 训练前冻结的验收与退出

以下数值是本次四臂开发推进规则，在新训练前冻结。0.002 是选择的最低实际 TPR 增量，不由外部论文保证，也不是沿用旧 teacher qualification 就自动成立。对 C 的 16,707 条攻击，整数门槛统一为 $\lceil0.002\times16707\rceil=34$ 条净 TP。三个比较都采用相同门槛，避免单条事件触发下一轮。

| 检查 | 通过条件 |
|---|---|
| 工件与控制有效 | 身份、教师、起点、目标哈希及 S 不变量全部通过；四臂完整；预算、精度、终点一致 |
| K 的 C 实际收益 | 对 H、S、M 分别净增加至少 34 TP；三项标准化 pAUC 差均≥0 |
| R 方向 | K 相对 H 的 R 净 TP≥0，标准化 pAUC 不降 |
| 正常代价 | 四臂 R FP≤39、C FP≤78；K 在 R、C 分别相对 H 净 FP≤0 |
| 攻击族代价 | R 与 C 分别检查所有有支持的 attack_cat，K 相对 H 的族内净 TP均≥0；小族同样检查，不用总收益抵消 |
| 收益集中 | 在 C 的 K−H 配对下，以 UNSW 既有 feature_hash 精确重复组汇总净 TP；删掉正贡献最大的一个组后总净 TP仍>0；保持原终点阈值，不重新校准；不把模式数当独立采集事件数 |
| 部署结构 | 42 原字段、189 编码维、6,625 参数和原预处理完全一致；包只包含学生所需工件，K包字节≤H包的1.05倍 |
| 正式相对成本 | 实验室 K 对本轮 H 的 CPU 管线 p95 比值在 batch1、batch256 各3块均≤1.25；原始时长完整 |

集中度判据精确定义为 $\sum_g\Delta TP_g-\max_g\Delta TP_g>0$，其中 $\Delta TP_g=TP_{K,g}-TP_{H,g}$，使用原终点已登记的阈值。

pAUC 的比较只允许 $10^{-12}$ 数值误差，不设置事后实质容忍带。计数条件按精确整数判断。成本采用已用过的混合输入配对测量方式：共同 C 样本、seed20261105、每块25次、3块、每模型每批5次预热、随机交错 H/K 顺序，线程4。p95 使用 NumPy percentile(values,95,method="linear")。范围为内存 DataFrame→预处理→原始分数；测量只比较 H/K，S/M做相同结构及包内容检查，不扩成四模型资源矩阵。

本轮允许同一攻击族内“救回 FN／新增 FN”同时发生，但族内净 TP不得下降；同理，正常净 FP不增加也可能包含新的受影响样本。必须逐行列出四类事件以及所属族、模式和组，不能只报净数。这是**后续开发研究的推进规则**，与第九轮冻结裁剪的“零新增 FN”规则不同；本协议不重判或放宽第九轮结果，也不将新错误交换解释为已通过部署验收。

判定顺序：

1. 技术或控制不合格：记为未完成有效对照，修正具体执行问题后另存记录；不把故障算成 KD 的负结果。
2. K 未达到相对 H 的收益门槛：停止该冻结候选；不当场扩 T、lambda、训练步数或换教师。
3. K 达到 H 门槛但未达到 M：相对均值控制的增量未达到预定质量门槛，尚不支持实例信息贡献结论。
4. K 达到 H/M 但未达到 S：未达到超过该固定随机控制的预定门槛。
5. 三项收益成立但代价／集中度／成本任一失败：记录收益与失败项，本候选不进入下一轮训练。
6. 所有项通过：只支持另立小规模配对稳定性复核的依据；不自动启动更多拟合。独立泛化还需要未参与开发的新来源。

统计报告保留完整计数、逐族支持、事件表和组集中度，不对高度重复的行套独立二项显著性检验，也不把一个置换或一个初始化当作总体因果证明。

## 9. 执行接口和回传内容
