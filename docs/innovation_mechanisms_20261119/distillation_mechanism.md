# 同信息蒸馏：把低误报区间信息与学生可达性分开研究

2026-11-19。本轮读取原文和作者代码，真实模型训练、前向、评分均为 0；未改旧实验。

## 判断与具体候选

最有依据的候选是：**教师只给出相对正常分数尾部分位的区间归属，学生无需复现教师概率大小。** 有限分位网格是比完整次序更粗的信息，同一区间内可以任意换序而不改变目标。要检验的机制是“全局概率匹配浪费了学生容量，而低误报区的教师区间信息仍可传递”。它对应一个明确问题：同一小学生、同一输入和更新预算下，这种监督是否比普通 KD、纯标签 partial-AUC 优化更能保留教师的低误报检测优势？

不能把这个方向直接命名为原创：CVPR 2022 的 EKD 已将 FPR/TPR 所对应的阈值关系用于蒸馏；2026 年的 O³PD 已明确区分次序与概率大小。EKD 只用于确认历史先例和排除原创主张，不满足本轮 2025—2026 新采用方法的时间要求，不列入新运行对照。本轮另深入核验了“投影到学生可达空间”这一看似新的部件，发现一个严格等价情形，见下文。因此建议保留**低 FPR 区间监督这一可否定的机制候选**，撤下“加一次可达性投影就是新算法”的主张。后续真正需要的证据是教师区间归属的独有作用，不是再证明加权或选难例能够改变结果。

## 候选的数学对象：正常尾部的区间，而非全局概率

以下是针对二分类流检测的候选定义，不是声称原论文已经实现本项目。

记同信息教师分数为 \(t_i\)，学生 logit 为 \(s_\theta(x_i)\)。从 F 的正常样本取固定参考库 \(N_F\)，不取 C、V 或已打开评估集的样本。参考库和训练样本仍按完整来源／业务组件登记；同一参考库只能供 F 优化，不能又算独立验证。

在 F 内选择事先写定的低误报分位网格，例如 \(\mathcal B=\{0.0025,0.005,0.01\}\)。这是一个供辨识的固定示例，不是已批准参数；若 F 的完整正常单位不足以分辨这些尾部，不通过反复改网格凑信号。

严格按 \(s>u\) 判正。对 \(n\) 个升序正常分数及预算 \(b=\lfloor\beta n\rfloor\)，使用

\[
u_\beta=z_{(n-b)}\quad\text{（这里为 1 基序号）}.
\]

并列值保留原状，不能添加随机抖动制造次序。教师只提供区间位：

\[
b^T_{i\beta}=\mathbf1[t_i>u^T_\beta].
\]

学生的 \(u^S_\beta\) 从同一 F 正常参考库在当前学生下的分数产生。一次更新内将参考阈值视作固定量；是否、何时重算写成固定调度。一个明确可实现的区间损失为

\[
L_{\rm ord}(\theta)=\frac1{|F||\mathcal B|}
\sum_{i,\beta}\operatorname{softplus}\!\left(
-\frac{(2b^T_{i\beta}-1)(s_\theta(x_i)-\operatorname{sg}(u^S_\beta))}{\tau}
\right),
\qquad L=L_{\rm hard}+\lambda L_{\rm ord}.
\]

\(\operatorname{sg}\) 表示该步不通过分位排序求导。这定义的是冻结阈值的分步更新，不是每次重新计算分位数的完整复合目标之梯度。\(\tau\) 仍控制学生的 surrogate 形状；不能因教师侧不需要温度就声称“无超参数”。对教师分数和教师正常参考分数施加同一个严格单调变换，所有区间位不变；学生 loss 并不对任意单调变换不变。

具体地，单个分位、正常阈值由唯一第 \(k\) 条分数给出时，令 \(g_i=\partial L/\partial s_i\vert_{u\text{固定}}\)。当参考样本和当前样本在同一分数向量中，完整分位目标的导数为

\[
\nabla_s L_{\rm full}=g-e_k\sum_i g_i,
\qquad \nabla_s L_{\rm stop}=g.
\]

参考库若是另一个分数向量，也仍有通过参考库参数路径的对应项，不能忽略后声称与完整目标等价。正常分位处存在 ties 时，选定 order statistic 的复合目标还可能不可微；固定阈值分支的导数仍可计算，但它不是唯一的真实分位导数。重新计算阈值时共同平移所有学生分数保持 loss 不变；冻结阈值后则一般不变性消失。合成检查直接展示了这两种导数的差异。

这会放弃教师在区间内部的精确概率和精确次序，教师传递的信息只剩相对正常分位的区间归属。所用 logistic surrogate 仍偏好一定的学生 margin，并非一旦落入区间就成为零损失。教师误报及漏报同样会进入区间目标，因此 hard 项仍有作用，也必须保留错误交换。把这些错误目标全部用标签过滤，会把机制改成另一种方法，不能事后悄悄替换。

### 与已有方法到底差在哪里

1. **相对全局 KL，确实改变了目标。** 教师概率 0.2、0.8 的距离不再是监督对象；正常参考分布决定这两点是否跨越目标工作区。全局 KL 的 logit 梯度为 \(p_S-p_T\)，这里则由工作区侧别产生，二者一般不相等。
2. **相对 EKD，是邻近适配，不构成原创。** 原 EKD 对关系分数匹配多个平滑阈值的总 rank-count；这里把每条流当作检测评分对象、保留分位侧别向量，并用 ordinal logistic surrogate。改变向量／求和或 MSE／logistic 不足以证明新方法。
3. **相对 pAUC，新增信息只有教师的实例区间归属。** pAUC 由真标签直接要求攻击排在正常之前；教师还区分同为攻击的易难实例、同为正常的尾部实例。如果收益只来自强调难正常项，纯标签 pAUC 就足以解释，不应归功于蒸馏。
4. **相对 O³PD，排序轴不同，基本思想已有。** 它对同一上下文的多个 token 排序；二分类 \([p,1-p]\) 的顺序几乎只剩一个类别判定。要研究当前问题，必须跨不同流／正常参考位置，不能给两个类别加 rank loss 后宣称传递了正常尾部几何。

## 深入否定“学生可达投影”这个附加机制

设学生输出向量在起点 \(\theta_0\) 的 Jacobian 为 \(J\in\mathbb R^{n\times p}\)，目标残差为 \(r=t-s_{\theta_0}\)。最直接的“只教可达知识”构造是

\[
P_J=JJ^+,\qquad \tilde t=s_{\theta_0}+P_Jr,
\qquad L_{\rm projected}=\tfrac12\|s_\theta-\tilde t\|^2.
\]

在构造目标的同一点、目标 stop-gradient 时：

\[
\nabla L_{\rm projected}(\theta_0)=-J^TP_Jr=-J^Tr
=\nabla\tfrac12\|s_\theta-t\|^2\big|_{\theta_0}.
\]

**因此正交投影并没有产生新的首步更新。** 若学生为线性模型、固定 J，投影残差与被丢弃残差正交，两种平方目标只差常数，整个优化路径在相同优化器状态下都相同。带权平方损失使用相应加权投影，也有对应结论。

这不是对一切学生适配的否定：非线性模型在离开起点后 J 会变；固定目标、重算目标、通过投影算子反传，已是不同算法。但这些差异需单独证明，不能把首步恒等写成“移除了不可达梯度”。采用 ridge 投影

\[
P_\rho=J(J^TJ+\rho I)^{-1}J^T
\]

会改变梯度，作用是按学生 Jacobian 的谱重标定方向；它本身仍未引入低 FPR 风险信息。对应的预条件 hard／pAUC 对照不能省略，否则收益可能只是优化器改变。

若进一步把目标改成“在有限步长内尽量满足教师次序约束”，对固定线性学生可写为

\[
\min_{\Delta,\xi\ge0}\ \tfrac12\|\Delta\|^2+C\sum_e\xi_e,
\qquad a_e^T\Delta\ge m-d_e-\xi_e.
\]

消去 \(\xi\) 就得到带二次正则的 pairwise hinge ranking。若所有 e 都是教师判对的正负对，排序方向已由标签决定，教师只提供样本对选择；如果还包含同类内部次序，才有标签没有给出的实例关系，但它是否有利于低 FPR 尚待验证。把这一式重新命名为“可达蒸馏”不能消除它与已有 rank loss／难例选择的等价性。

这两项代数检查直接否决了两个很容易再次投入无用功的变体：**正交投影平方目标；把教师正确正负对筛选当作新知识形式。**

## 为什么不是重做旧 boundary／EKD 失败

旧 risk-v3 曾将裁剪后的 teacher logit 减去工作点，再 sigmoid，导致 CIC 正常 OOF 目标约 99.63% 变为 0.5；其单行二元 EKD 适配也出现多数正常 rank-count 约 1.5 的退化。见[原结果 §2](../RISK_V3_RESULTS_20261104.md)。

当前候选不对 teacher logit 做 clip 后中心化，不把“恰等于分位阈值”的样本赋成 0.5；按照原始精度、严格比较和 ties 直接产生区间位。若教师大量同分，区间位会如实合并，不能把分辨不了的次序变出来。训练参照只来自 F；部署阈值仍另由固定 C 规则确定。这里改变的是监督对象及其构造，旧 R10—12 没有检验过这一对象；同时，旧 v3 已说明不能跳过目标分布和真实梯度的核验。

旧失败还没有排除“同一小学生在相同输入上根本不能达到教师工作区排序”的可能。区间监督必须实际缩小尾部关系差距，才能支持它缓解了目标错位；只看总 loss 下降不够。

## 最小强控制与一次能结束的判断

如果当前同信息强教师没有低误报优势，结束这个蒸馏候选；旧 UNSW 优势不能代替新任务证据。如果强教师在当前任务有优势，固定一个教师、一个学生结构、共同起点、F 和更新预算，仅比较以下目标。这里是机制研究设计，不是已启动实验。

| 臂 | 目的 |
|---|---|
| H：hard | 测学生本身能达到什么。 |
| K：hard＋原始 KL | 复用普通 KD 作为概率匹配参照。 |
| P：hard＋纯标签 pAUC surrogate | 排除“仅仅把优化目标改成尾部”就足以解释的收益。LibAUC 只用于核验目标含义；表中是所需消融条件，不是已选择其旧方法作为新运行。具体优化器和预算须与拟采用实现一起确定。 |
| O：hard＋上述教师区间目标 | 检验教师实例区间是否比 H/K/P 多提供了有效信息。 |
| O-perm：与 O 同构，F 内按标签／完整来源层置换教师区间位，保留各层区间频数 | 排除目标边际、类内软化及选难预算效应。固定一次置换规则，不为让控制变差反复取种子。若层内没有可置换变化，报告控制失去辨识力。 |

已有教师是比较对象，不另列成一次新训练。O-perm 是必要的知识控制，不能只用 O>K 就声称“传递了教师知识”。上述是 **5 个学生目标、一个固定机制问题**；不再叠温度／宽度／教师 checkpoint 网格。λ、τ、分位网格和训练长度必须在查看评价输出前固定，且不给候选更多选模预算。

训练内必须区分三个量：全局 KL、F 尾部区间／排序违反数、实际参数梯度。评价则只按原注册的来源单位、同 C 操作点规则报告 FPR、控制／下载事件上下界、召回和成本；完整报告新救回／新漏报，不把逐条零损失重新设成所有新方法的永久硬门。已用于 F 的来源不能作为独立迁移证据，C 不能用于修改监督或反复换网格。pAUC 改善也不自动等于每个正常单位在 1% 工作点改善。

| 一次固定比较的结果 | 继续／停止的具体含义 |
|---|---|
| O、P 同幅优于 K，O 无稳定额外增益；或 O 与 O-perm 相当 | 低误报目标可能有用，但教师实例知识没有被支持。停止该蒸馏机制，采用更简单的有效目标；不再加可达性门控挽救。 |
| O 优于 K/P，且 O-perm 失去该增量；尾部违反数下降与外部工作点收益一致 | 支持教师区间信息可传递。下一步仅确认这一个差异在预留来源上能否保留，并测真实成本；这仍是相近方法的实证机制结果，不能把 EKD 的核心重新宣布为原创。 |
| O 在 F 不能学会目标，且与 K 一样未缩小尾部差距 | 本固定学生／预算下机制失败。停止这个学生配方，不从结果倒推普遍容量定理，也不续调 λ、温度或训练轮数。 |
| F 的尾部关系明显改善，V／外部开发没有改善 | 训练可达性不再是充分解释；停止把目标传递当作该泛化问题的解法，不用改 C 阈值补救。 |
| O 增加部分检测同时增加误报或漏掉另一些事件 | 记录完整取舍，不以事后阈值或“保住所有旧 TP”隐藏它。若未形成相对 HGB／P 的可接受成本—检测位置，停止轻量蒸馏主线。 |

本轮最具体的研究产出是：把“低 FPR 下教师区间归属能否被传递”留下，把可代数消去的“可达性投影创新”删去。真正有资格成为后续新机制的部分，必须解释并超过 O、P 和 O-perm 的差异；当前不能用组合命名替代这个证据。
