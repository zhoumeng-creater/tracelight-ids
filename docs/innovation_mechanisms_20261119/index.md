# 创新机制探索与原型

2026-11-19。此次工作是机制设计、现有 F 输入分析和合成推导；没有真实模型训练、评分或阈值搜索。

本轮保留的具体候选是：**让当前连接读取历史交互的相对先后关系，同时单独保留这些关系的支撑量。** 它有可执行的记忆更新与读取原型，也有能否定其解释的近邻对照。保留的是一个值得辨识的表示假设，尚未确定为论文的原创贡献或下一批训练方案。

## 本轮作出的取舍

| 路线 | 实际推进到什么程度 | 决定 |
|---|---|---|
| 有向交互记忆 | 给出递推、读取、状态预算；检查同均值／同末槽的可分性，以及顺序相消、过时证据、事件切分等反例 | 保留机制探索；必须超过同信息的二阶近邻，不能只打赢均值 |
| 正常参照的表示投影 | 推导正常 secant 子空间；核查 F 内配对支持并给出曲率反例 | 不采用硬投影。精确条件参照本身可能形成标签捷径，且组内不变性不解决组中心高分 |
| 低误报区间蒸馏 | 推导区间监督，核查直接近邻，数值验证 Jacobian 投影等价性 | 保留作知识机制对照，暂不作为创新主线；区间监督已有近邻，可达投影的简单版本无新更新 |
| 多候选事件联合监督 | 检查真实训练候选集合，写出联合概率 | 不立项。现有四个恶意歧义集合不交，联合目标退化为普通 MIL |

## 保留候选到底学什么

旧的末槽和历史均值容易混淆两种历史：相同形态的连接都出现过，但先后关系不同。AIT／OpTC 的既有材料说明部分早期控制连接在后续查询时已经可用，也说明真正触发 wget 的完成流常常尚不可用。因此这里只使用严格早于查询到达的完整连接，不声称恢复未完成的触发流或建立命令因果链。

当前候选先固定输入映射：五个非负数值的 `log1p` 与 F 内尺度、五个缺失标记、三个协议标记，形成 13 维 `u = phi(x)`；当前查询按同一映射归一化为 `g(q)`。分类头综合当前连接、历史方向和支撑量，仅由 F 的可信连接标签学习。未知历史可以贡献已观察特征，未知连接不产生正常监督。URL、命令、动作标签与攻击链身份不作为输入。学习编码器会引入额外差异，本轮没有把它叠进候选。

记 `P` 为衰减的一阶和，`A` 为反对称的有序交互，`S` 为对称的交叉共现量。无同刻新观察时，时间前进 Δt，先作：

```
rho = exp(-lambda * Δt)
P = rho * P
A = rho² * A
S = rho² * S
```

当前批查询全部读取旧状态。之后把同一可用时刻的编码求和为 `U`，更新：

```
A = A + P Uᵀ - U Pᵀ
S = S + P Uᵀ + U Pᵀ
P = P + U
```

同刻记录之间不编造先后，当前连接也不提前进入自己的历史。对非对角元素定义 `R_ab = A_ab / S_ab`；`S_ab = 0` 时取 0，并保留支撑缺失信息。原型读取：

```
direction = R g(q)
support   = log1p(S g(q))
activity  = log1p(P)
```

分类器接收当前连接和这三组量。它学习什么交互关系对当前查询有帮助；方向不预先指定为攻击。上式 S 只保留非对角交叉共现，对角置零。`qᵀ R q` 恒为零，不能拿这个标量当读取结果，原型保留整个 `R g(q)` 向量。

非负编码使 `|A_ab| <= S_ab`，方向值有界。r 维状态共 r² 个数；当前 13 维规格按 FP32 加一个 FP64 时钟计算为每实体 684 字节。这是数值状态的理论载荷，不是 Python 对象大小、完整检测器内存或实测吞吐。实体索引、特征提取、分类头与工作缓冲仍另计。

## 这个候选与现成方法的关系

有序二阶和、反对称面积、指数衰减都不是新发现。2025 年的 [Exponentially Fading Memory Signature](https://arxiv.org/abs/2507.03700) 已研究衰减路径签名，2025—2026 的流量路径签名方法也已有直接应用；具体原文位置与作者代码记录见时序机制文档。相对均值增加顺序信息，只能支持采用有序表示，不能证明本项目创新。

本候选实际要检验的是：**在有限状态和有限训练数据下，把交互方向比与支撑量显式分开，再按当前查询读取，能否比直接学习相同二阶信息更有效。** 这是归纳偏置假设，不是“增加了别人没有的信息”的主张。

尤其不能省掉同信息对照。令 `B = sum(i<j) w_ij u_i u_jᵀ`，有 `A=B-Bᵀ`、`S=offdiag(B+Bᵀ)`。候选读取是 P 与非对角 B 的确定性变换；拥有相同信息的足够强 MLP 可以学习相应比值。P 加非对角 B 与本候选正好具有相同数值状态量。标准几何路径签名还涉及每个增量内部的二阶项；只拿较小的一阶／二阶几何签名比较，可能把额外事件切分信息算作我们的优势。

## 原型已经回答的事

- 存在当前查询、均值和末七条记录全部相同的两段历史，原型能够区分其较早先后关系；也构造了均值和指数一阶和相同而本表示不同的例子。
- 递推结果与直接枚举严格早于关系的二阶和一致。同刻批处理不会因为文件行序制造先后。
- 所有编码共同乘正数时，方向分支保持不变；支撑分支和完整分类器没有这个保证。复制事件、改变采样率也不具备普遍不变性。
- 单一形态不断重复的控制流可能得到零方向；正常浏览后下载可以与恶意业务有完全相同的表示；多段先后关系还可能相消。
- 静默时 A、S 同比衰减，R 不变。只读 R 会保留过时方向，所以读取中显式保留支撑量；这并不保证尚未训练的分类器会正确忽略它。
- 将一个多通道事件拆成两个事件，可能改变分母与结果，即使几何路径相同。必须固定流提取与事件粒度，不能把这种变化称为检测到新攻击信息。

这些是可分性与边界的检验。原型目前接收人工非负向量，尚未接入真实流映射或分类器，也未检验真实攻击检出。三个脚本与重跑方法见[原型目录](prototypes/README.md)。

## 必要的机制辨识及结果出口

以下定义以后比较时需要回答的问题，不新增实验室运行批次。固定四臂仍只收尾覆盖／端口问题；其成功或失败都不自动证明这条时序机制。

| 必要比较 | 它回答什么 | 不支持时的决定 |
|---|---|---|
| 当前单流强基线 vs 同监督的历史模型 | 历史是否有单流模型不能解释的真实收益 | 没有收益则不进入记忆压缩／复杂机制研究 |
| 同编码器的一阶记忆 vs 有序二阶记忆 | 先后关系是否提供分布／重复计数之外的收益 | 只需一阶就采用简单方案，不把二阶写成贡献 |
| 同信息、同状态预算的 P＋非对角 B 读取 vs 显式方向／支撑分离 | 固定归一化是否比直接学相同信息更合适 | 相当或更差就放弃该归一化主张，不续加门控 |
| 查询无关读取 vs 查询条件读取 | 收益是否真的依赖“当前在判断什么” | 相当就删掉查询机制，不能继续宣称条件化贡献 |

研究不以 AIT 某一个下载得分上升为成功。控制、下载和各预定正常业务单位仍完整报告，给出新增和丢失身份、1% 经验预算以及真实成本。若只有 F 内可学而外部无收益，结束这套固定配方；若只有额外信息或状态增加解释了收益，就撤销相应机制主张。不会由这些结果自动派生新来源、阈值、窗口或模型网格。

本轮交付的是一个具有公式、原型、近邻与反例的候选，以及三条不应继续盲试的分支。下一项设计工作应围绕上述同信息差异，而不再把“加历史”“换损失”“做正常校准”本身当成创新。
