# 表示层机制推演：正常参照差分与条件切空间

2026-11-19。本文给出一个具体候选、可计算的反例和当前训练材料的支持情况。真实模型调用、拟合、评分、阈值计算均为 0；未改四臂注册。

**本轮最值得推演的候选是“按流量成分条件构造正常参照，再保留 PLE 表示中偏离正常变化方向的部分”。它确实增加了标准 PLE 没有的归纳偏置，但当前推演不支持把硬投影版送入真实训练。** 两个原因直接关系到现有问题：R30 的正常高分成分在训练正常近邻中已经同样高，抹平组内变化不能自动降低成分中心；当前 F 中，攻击恰好全部没有精确同条件正常参照，参照是否存在会成为新的标签捷径。

因此，本轮保留这份结构与反例作为算法设计的实物，撤下“正常切空间投影即可修复 R30”的主张。没有用新的分组损失、阈值或试跑来掩盖这个结果。

## 1. R29、R30 实际支持哪一种表示问题

R29 同种子对照中，PLE 分别新增 1,607、1,560、1,657 条 D 检出，对应无 PLE 模型的已有检出丢失为 0。有 PLE 的 D 检出为 1,652、1,560、1,657 / 1,964；无 PLE 为 45、0、0。这支持保留数值的非线性表示，不能再把持续时间和体量一律压成粗类别，也不能声称 PLE 已解决低误报问题。[R29 实验分析，第 24—77 行](<E:/OneDrive - Coventry University/中传/毕业论文/实验归档/20261117_第二十九轮模型训练/实验分析.md:24>)

R30 三个 blind 模型均检出 B 72/72、D 1,964/1,964；D 误报分别为 99、110、137，15 个单元中预算合格数分别为 8、5、4。R30 同时改变了监督、批次、选轮和交付方式，不能把相对 R29 的全部增益归给某个表示设计。[R30 结果，第 23—32、55—82 行](../MODEL_TRAINING_REDESIGN_RESULTS_20261117.md)

本次设计最需要回应的是以下事实：

- 三个种子的 D TCP 误报中，88/96、93/106、114/131 条在 F_B 正常中已有相同双向包数、双向 IP 字节数；其中 73、69、97 条持续时间也在相应正常组的范围内。多数近邻原分数相近，而非进入未知区间后才突然升高。
- seed43 的 `(11,8,1285,4725)` 正常成分，在 C 中 23/23 告警，在 D 中 84/84 告警。成分占比从 0.417% 升至 0.878%；F_B、C、D 的分数中位数分别为 −11.836、−11.832、−11.810。组内几乎不变，整个成分的位置却偏高。
- 六模型 D TCP 误报均未越出 F 的五数值 PLE 全局端点。F 的原始、预处理和无参数 PLE 表示没有异标签同值冲突。

这些证据使“统一拉平 duration”“增加 bins”“只对同组邻居保持平滑”都缺少针对性。它们没有直接处理**不同正常成分之间的相对位置**。[R30 正常尾部分析，第 11—60 行](../R30_NORMAL_TAIL_DESIGN_REVIEW_20261117.md)

## 3. 具体候选：条件正常差分投影

### 3.1 输入与参照

记去端口输入为

\[
x=(c,u),\qquad
c=(p,n_o,n_r,b_o,b_r),\quad u=\log(1+\mathrm{duration}).
\]

`p` 为协议；其余四项是上下行包数和 IP 字节数。协议若在指定基线中盲化，条件键也必须同时盲化，不能从参照查询偷渡回模型。现有四臂的去端口输入仍保留协议，所以本轮 F-only 计数使用上述键。

只用拟合角色中有可靠正常标签的样本，构造同条件正常集合 \(N_c\)。训练查询自身不能充当自己的独立正常参照，否则单例正常会因记忆自身而得到零残差。记固定、未学习的 duration PLE 基为 \(\phi(u)\)，正常中心为 \(\mu_c\)，将正常样本之间的差分放进列矩阵：

\[
D_c=[\phi(u_i)-\phi(u_j)]_{i,j\in N_c},\quad
P_c=I-D_cD_c^+.
\]

其中 \(D_c^+\) 是 Moore–Penrose 伪逆。候选表示为

\[
r_c(u)=P_c(\phi(u)-\mu_c),\qquad
z_A(x)=[e(c),r_c(u)].
\]

后端使用与基线相同的 TabM 和普通二分类损失，不增加 worst-group 目标、域判别器或阈值。模型拟合前冻结参照与投影，避免模型随意转动嵌入坐标绕过投影。这里提出的是表示结构，不是按错误清单降低某组分数的规则。

实质偏置很明确：当 \(\phi(u)-\phi(v)\in\operatorname{col}(D_c)\) 时，同条件两个输入的残差严格相等；该变化方向后续再大的分类器也无法恢复。标准 PLE 加 MLP 没有这一硬等价约束。若保留原始 duration 旁路，则约束失效，候选只能算增加一组派生特征。

### 3.2 为什么这仍解决不了 R30 的已证问题

在 \(z_A\) 中，条件嵌入 \(e(c)\) 原样保留。分类器仍可给正常成分一个高偏置 \(b(c)\)。即使该成分所有 duration 都被压成同一个残差 0，也只得到 \(s(x)=b(c)\)，没有任何结构保证不同正常成分的 \(b(c)\) 接近。

这正好对应 R30 那个在 F/C/D 中分数均接近 −11.8 的正常成分。组内平滑或投影可以完全成立，整组仍然在 −12.252 的旧工作点之上。**候选 A 的作用对象与主要已证失败模式不一致。**

可以进一步删掉 \(e(c)\)，令

\[
z_B(x)=r_c(u).
\]

这样不同条件下落在正常仿射空间内的样本都变成 0，确实消除了成分中心偏置。然而它把任务改成“相对于正常条件参照的异常程度”，同时删除了条件本身的判别信息。它比普通 PLE 更强，也更容易误删真实攻击证据。它与正常流形残差、局部 PCA、条件重建异常检测处于同一方法族；不能仅凭加入 PLE 就宣称原创。

## 4. 六项合成检查及其设计后果

检查脚本只做固定数组的线性代数，不拟合统计模型。取两段 PLE：

\[
\phi(0)=(0,0),\quad \phi(1)=(1,0),\quad \phi(2)=(1,1).
\]

| 检查 | 实际计算 | 结论 |
|---|---|---|
| 两个正常端点 0、2 | 正常 secant 是 `(1,1)`；投影确实将该方向清零 | 候选不是恒等变换，硬不变性真实存在 |
| 中点 1 未被观测 | 中点残差 `(0.5,-0.5)`，平方范数 0.5 | 能保留普通线性 duration 投影会丢掉的曲率；这是一个真实的结构差异 |
| 中点实际也是正常 | 相同残差仍为 0.5 | 只有正常端点不能证明中间是攻击；该机制会把正常内点曲率当成异常 |
| 将正常中点也加入 | 两个差分张成二维空间，整个投影变成 0 | 正常覆盖增加后，攻击所需的 PLE 方向也可能全部被消掉；更多正常并不单调改善此表示 |
| 保留条件中心 | 设两个正常成分偏置为 −10、−5；组内投影不会改变偏置差 | 不能借此解决 R30 的正常成分整体偏高 |
| 扩展到联合表示时的弯曲流形、以及坐标缩放 | 圆上四点的仿射差分张成二维，圆外攻击也被投影成 0；将第一个 PLE 坐标放大两倍，中点残差平方从 0.5 变为 0.8 | 圆的例子针对联合表示扩展，不是单一 duration 曲线；仿射 span 不等于局部流形，欧氏投影还依赖人为表示尺度 |

“正常端点之间可以有攻击中点”和“正常端点之间全部正常”在当前两个端点证据下都成立。这是不可识别性反例，不是换一个 seed 能解决的优化问题。条件分区改小、只取最近邻能够改变反例出现的位置，却会引入邻域选择假设；不能当成已完成的修复。

加上攻击保护也不会自动带来新机制。若用正常差分散度 \(S_N\) 和攻击—正常差分散度 \(S_A\)，选择方向使

\[
\max_w\frac{w^\top S_Aw}{w^\top(S_N+\epsilon I)w},
\]

这就是广义 Rayleigh 商的判别子空间形式。把它包装成“攻击保护的正常压缩”并没有越过经典判别分析/度量学习；若只对难正常加大此约束，也不能绕开已经关闭的分组风险路线。

可复算文件：[检查脚本](prototypes/representation_mechanism_checks.py)、[实际结果](prototypes/representation_mechanism_checks.json)。脚本记录 6 项检查通过，含上述复合反例；“通过”表示反例按推导出现，不表示算法有效。

## 5. 当前 F 能否支持这种监督

只读取冻结批次 `rows.jsonl.gz` 中 `F_base/F_expansion` 且 `target_label∈{0,1}` 的记录，不读取 V/C/外部开发标签来选择条件。输入 SHA256 为 `8822c9ff41b5172d4024a15c84a0d96ebfa9d61fe6dbb3845b1888851ee6561c`。本次仅做身份与原始字段计数。

| 固定精确条件统计 | F_base：santos | F_expanded：再加完整 Unraveled |
|---|---:|---:|
| 正常 / 攻击观察 | 439 / 32 | 12,747 / 505 |
| 攻击类型：control / download | 31 / 1 | 504 / 1 |
| 正常条件组 | 275 | 3,960 |
| 仅一个正常样本的条件组 | 236 | 3,163 |
| 至少两个已观测 duration 的正常条件组 | 39 | 792 |
| 这些组内的正常观察 | 203 | 9,512 |
| 跨完整来源组、同条件且 duration 不同的正常配对组 | 0 | 0 |
| 有精确同条件正常支持的攻击观察 | 0 | 0 |

这说明有足够记录计算一些**来源内部正常差分**，不是完全没有正常数据；但当前精确配对不能学习跨来源的正常环境变化。505 个攻击条件均无正常参照，若给未支持条件输出一个特殊向量或保留原值，“参照是否存在”就与训练标签形成强关联。排除正常查询自身后，仍有许多正常单例没有参照，因此不能称这个标记能完美分类；它足以使训练收益混入支持域捷径，不能单独验证所提机制。

缺口是具体的：候选需要在同一可观测条件邻域内，既有正常变化的可靠覆盖，又有需要保留的攻击差异；现有精确匹配并不提供这种对照。放宽距离后，近邻的传输类型、方向成分与体量可能一起变化，不能再说只识别了 duration 的无关变化。正常标签只证明各条观察正常，不能证明两条之间全部插值也正常，更不能证明差分来自可去掉的环境因素。

现有 F 仍可用于普通有监督流检测：事实表有明确正负标签。这里被否定的是**它已足以支持该候选所要求的不变关系**，不是训练资格。攻击 download 仅有 1 条监督观察，也不能据此单独估计一个可泛化的“下载正常差异子空间”。

## 6. 与几种容易改名的设计逐项区分

| 改法 | 是否构成本文需要的新增机制 |
|---|---|
| 加包均字节、双向比值、速率，然后普通 MLP | 是派生特征工程。若同时保留原量，主要改变优化；不能据此声称获得环境不变性 |
| 对包数与字节数共同缩放不变 | 会主动丢掉传输体量；正常小对象与恶意大对象可具有相同比例。没有证据允许全局删掉该信息 |
| 对 duration 伸缩不变 | 可能删掉等待、节律与控制连接时间证据；R29 的 PLE 收益不支持先把它消掉 |
| 上下行互换不变 | 网络角色方向有语义，下载与上传可被混同；不能把数值对称直接当业务对称 |
| 条件正常分位/CDF 再接足够灵活的网络 | 单调可逆时只是重参数化；不可逆时必须解释丢失信息。不能凭预处理名字声称新判别信息 |
| 新 PLE knots 或线性加 PLE 残差 | 作者实现已有；监督 tree bins 应是直接基线 |
| 正常差分投影 | 真正限制可表达函数，但本轮反例已否定其自动有效性；一般子空间残差也有成熟近邻 |
| 正常对相似性惩罚 | 落入图平滑、对比学习或度量学习；不同配对语义可能值得研究，惩罚形式本身不是创新 |
| 对抗来源分类器 | 对齐的是来源可预测信息，未必是无关信息；源与攻击实现耦合时会删掉有效信号 |
| 对高分正常成分另加权 BCE 或 worst-group 风险 | 仍是已讨论的优化/风险路线，不能作为表示创新重新启动 |

## 7. 最小同输入对照与最终优先级

假如后续有新的配对证据支持该结构，最低限度需要固定同一拟合角色和输入，比较：作者 TabM+PLE、同一固定 PLE 空间的条件局部 PCA/正常参照残差、候选结构。三者共同使用原损失、训练预算和既定工作点。局部 PCA 是必须面对的机制对照；只赢无 PLE MLP 无法说明差分设计的贡献。DRL 可用于核验“正常子空间残差”这一大类思路，但其训练与评分合同不同，不应冒充只换一个层的等价消融。

这不是本轮实验安排。本轮硬投影版已经在数学与 F 支持上失败，故不启动上述训练。

最终优先级：

1. **撤下正常 secant 硬投影、全局量纲不变、无条件域对齐作为下一真实训练候选。** 它们分别存在作用对象错位、不可识别/塌缩和信息误删问题。
2. **保留一个精确的表示研究问题：能否利用可靠的正常配对，约束不同正常成分的相对位置，同时保留位于这些正常成分之间或附近的攻击差异。** 它必须显式处理“正常中心偏置”和“局部攻击差异”两件事，不能只压组内方差。当前已推导出的线性方案属于判别子空间/度量学习，尚无可主张原创的新增结构。
3. **当前可实现的成熟参照仍是固定 PLE 与正常参照/局部 PCA，而非一个已证有效的新模型。** 本次未找到足以越过这些直接近邻、又由现有精确配对支持的表示机制。R29 的正向证据保留；R30 的现象被转成了一个有反例、有明确数据需求的设计问题，没有被解释成“换一个新 loss 总会有效”。
