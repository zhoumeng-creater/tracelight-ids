# 可用时刻下的有限历史：机制探索、公式与反例

2026-11-19。本轮完成一手近邻核对、纯 Python 表示原型及 15 项合成核验；真实模型调用、真实拟合、留出材料读取均为 0。

**保留一个可具体检验的表示假设：在当前完整流输出时，既有已到达流的有向交互比例与支撑强度，是否比最后若干条记录或一阶均值更有判别价值。** 原型已证明它可以区分部分一阶摘要不能区分的次序，也证明它会丢失、混淆哪些信息。二阶路径签名、指数衰减、条件化读出都已有成熟近邻；这里尚未成立原创算法或真实检测收益。最接近可推进的差异是“有向量与交叉共现量分开表示”，不是新记忆网络或学习选择器。

## 1. 现有证据给出的研究对象

原 19 维摘要失败，不等于所有历史都没有意义。AIT 的真实 `wget` 完整控制流晚于或同批于下载查询，所以不能作为该查询的历史输入；已经完成并到达的更早动作仍然存在，只是可能被最近槽覆盖。OpTC 后 23 个控制查询能读取上一控制，是重复通信的实际正证据。正常 ownCloud 同样存在大量重复端点，不能把重复直接当恶意。[项目历史实证](<E:/OneDrive - Coventry University/中传/毕业论文/工作/覆盖与历史依据落实_20261119/history_mechanism/README.md>)

本候选仍在完整流输出时预测当前连接，不以恢复真实触发命令为目标。分类头监督使用已有可信当前连接标签；多候选集合继续保留事件上下界，不在本候选内另加 MIL 损失，不需要“哪条前驱导致哪条下载”的因果标签。未知背景也进入历史，未知不能变正常。其可研究的问题是**已观察到的行为组合是否有稳定的先后差异**；当前材料尚未证明这种差异能区分控制／下载与同服务正常。

## 3. 先排除改名后的成熟方法

对已到达记录 $u_i$，若状态为 $M=\sum_i w_i k_i v_i^T$、$z=\sum_iw_i k_i$，读出

\[
c(q)=\frac{q^TM}{q^Tz},
\]

这就是核化／线性 attention 的充分统计。均值是常数 key 的特例；指数 $w_i$ 是 EMA／衰减记忆。修改状态名、增加一个查询投影，都不能单独构成创新。

last-k 的优势是保留最近原记录，缺点是较早事件会被背景挤出。大小 k 的均匀 reservoir 对 n 条历史中的一个固定前驱，保留概率是 k/n；固定两条都保留的概率是 k(k−1)/[n(n−1)]。它保存原记录的分布代表性，不保证保留当前查询所需关系。按查询做 attention 可以在**仍被保存**的记录中选择，不能取回已经删除或尚未到达的记录。带位置的完整 attention 可以表示次序，本报告没有证明所有 attention 都缺信息。

同一物理流的前缀更新应替换旧状态而非重复累加；减旧加新属于数据结构正确性，不作为本候选的算法创新。

## 4. 唯一保留的具体候选

### 4.1 输入与时钟

每台监控主机、每个冻结来源组独立保存状态。已完成记录 i 的可用时刻是 $a_i$，只读取 $a_i<t$ 的历史。同可用时刻先对全部查询读取，再整批更新；不凭 UID 排序捏造同批先后。

令 $u_i=\phi(x_i)\in\mathbb R_+^r$。为避免先训练复杂编码器，首个可验证规格可用五项非负数值的 `log1p` 与 F 内固定尺度、五项缺失标记、TCP／UDP／其他协议 one-hot，共 r=13；两端口置零、端点 ID 不进入编码。所有参照共享这份输入。它是尚未执行的数据映射规格，不是已拟合预处理。若采用别的编码，必须重新说明维度、可用性和成本。

当前 query 的 $g(q)=\phi(x_q)/\|\phi(x_q)\|_1$，全零时 g=0。该映射不使用真实标签、PID、命令或未来流。

### 4.2 状态、更新与展开式

保持一阶向量 P、反对称矩阵 A 和对称非负矩阵 S 的非对角上三角；对角设零。时间从 t 移到 t+Δ 时，

\[
\rho=e^{-\lambda\Delta},\quad
P^-\leftarrow\rho P,\quad A^-\leftarrow\rho^2 A,\quad S^-\leftarrow\rho^2 S.
\]

若这一时刻到达一批记录，$U=\sum_{i:a_i=t}u_i$，所有查询完成以后更新：

\[
A\leftarrow A^-+P^-U^T-U(P^-)^T,\qquad
S\leftarrow\operatorname{offdiag}\{S^-+P^-U^T+U(P^-)^T\},\qquad
P\leftarrow P^-+U.
\]

实际代码显式使用逐坐标乘积。S 始终只取非对角坐标，对角为零；同批内部不配成有序对。

于是，对不同到达时刻的历史对，

\[
w_{ij}(t)=e^{-\lambda(2t-a_i-a_j)},\quad
A(t)=\sum_{a_i<a_j<t} w_{ij}(u_i u_j^T-u_j u_i^T),
\]
\[
S(t)=\operatorname{offdiag}\!\left[\sum_{a_i<a_j<t} w_{ij}(u_i u_j^T+u_j u_i^T)\right].
\]

**S 是交叉共现量，不是每对楔积的绝对值之和。** 后者不能用一次聚合后的绝对值代替；聚合会先发生相消。

### 4.3 压缩与读出

\[
R_{ab}=\begin{cases}A_{ab}/S_{ab},&S_{ab}>0,\\0,&S_{ab}=0,\end{cases}
\qquad
c(q)=[Rg(q),\ \log(1+Sg(q)),\ \log(1+P)].
\]

三个部分分别保留方向不对称、对应交叉共现的支撑、一阶历史支撑。最终可由同一简单分类头读取 $[x_q,c(q)]$，只用当前标签训练；本轮没有拟合这个头。

保留 Rg **向量**，不用 $g^TRg$，后者对反对称 R 恒为零。也不再用 $g\odot Rg$ 限制读出：该做法会使 one-hot 查询完全失明。查询相关读出是标准交互，不能独立作为创新点。

非负 u 保证 $|A_{ab}|\le S_{ab}$，所以每项 R 在 [−1,1]。所有历史编码同时乘正标量 c，A、S 同乘 c²，**只有 R 分支不变**；支撑分支和最终分类器不因此不变。真实事件复制、流切分和采样率变化均没有这种不变性。

静默时 A、S 同比衰减，R 严格不变。因此方向比本身不会遗忘旧方向；支撑通道必须保留，且不能声称分类器必然学会正确遗忘。这里没有增加阈值门控来补救。

压缩状态共 $r+2\binom r2=r^2$ 个数及一个时钟，更新 O(r²)，不随历史长度增长。r=13 的紧凑 FP32 数值加 Float64 时钟为 684 B／主机；r=8 示例为 264 B。Python 对象、主机索引、提取器和查询临时数组不在这个数字中，正式成本须另计；主机数量也必须受总预算约束。

### 4.4 真正差异与等价性

设有序二阶统计 $B=\sum_{i<j}w_{ij}u_i u_j^T$，则 $A=B-B^T$、$S=\operatorname{offdiag}(B+B^T)$。因此本候选**没有比 B 更高阶的信息**，只有非线性归一化与查询读出的归纳偏置。非对角 B 加 P 与当前状态恰好同信息、同数值存储量。

普通分段线性路径的二阶 signature 还包含半个自身项 $Q=\sum_i w_i^2u_i u_i^T$。按严格同批不配对的约定，应把 Q 换为每个 batch sum 的外积和。此时 $S=\operatorname{offdiag}(PP^T-Q)$。只有 P、A 的几何 log-signature 不能恢复 S；公平的同信息参照必须读取 P 与非对角 B，或 P、A 与非对角 Q，不能只比较 P、A 后把信息差异归功于归一化。

当编码是 one-hot 行为类别时，R 是两类先后次序的加权优势比例，与 rank-biserial 效应量相联系。它不是新统计量；连续多通道时，S 又受到事件切分影响。可主张的假设只能是：**将有向关系相对于共现量表达，同时保留支撑，是否比直接交给小模型学习这种比例更适合有限监督。** 是否有效、是否超过成熟方法，尚无真实结果。

## 6. 最小强参照及可归因差异

只有确认实际可用历史存在不同于单流的信息之后，才值得比较检测器。现在可以先用已开材料检查表示，不打开 harrison／Meterpreter、不换数据集。比较时至少保留：

1. **当前流＋一阶状态**：EMA／必要的同端点重复与时间间隔，所有允许输入一致。不要只把原先已被否定的 19 维当弱参照。
2. **相同总字节的 last-k 与 reservoir，加同一个查询读出**：算上每条记录的时间戳；例如 r=13、684 B 的数值预算下，11 条 `(13×FP32＋Float64 时间)` 连同总时钟为 668 B。历史检索不能拥有另一个未计费的全量存储。
3. **P 与非对角 B，或 P、A 与非对角 Q，加相同线性／小 MLP 头**：这是同信息、同状态预算下判断归一化是否真正有帮助的决定性近邻。若小 MLP 能直接学到同样效果，本候选没有独立方法价值。
4. **本候选 Rg＋支撑**：先固定 φ、λ、内存预算、分类头和训练标签。另比较查询固定／实际查询，才能判断当前 query 条件化是否有用。

普通二阶 signature／LogSig-SSM 用于确认数学和表示近邻，若与本候选比较，必须匹配事件定义与自身项信息，不能因它使用不同完整序列／窗口而直接解释成算法优劣。没有安排新的模型矩阵；上述是区分机制时不可省略的比较关系。

真实监督的单位仍是整 run／campaign／活动组。AIT 两个 run 共用实施家族；Unraveled 的 473 条 C2 属于一个 campaign；OpTC 的重复控制也不增加独立实施次数。不能把每条历史或每个前缀当独立训练证据，学到某一条链的先后顺序就称跨实现泛化。正常比较必须保留浏览、文件传输、更新和运维的实际已证类别；当前缺失的正常“控制触发下载”不能补造。

## 7. 进行中流路线如何处理

FastFlow 说明用已到达包／时间槽作早期表示有成熟实践。若改为该输入，瞬时状态至少应按真实包到达更新：包数、已见字节、首包年龄、最后包间隔、方向变化及截断标记。真实流终止时间和最终总字节不可提前读取。长期存活并非恶意，TLS keepalive、SSH、更新连接都是必要正常反例。

这条路线与本候选分开：前者增加新的、可能及时可用的信息；后者压缩已有完成流历史。两者同时改变，就无法把收益归因于二阶记忆。版本替换、同一流去重和有界活动表是实现要求，不是算法创新。本轮不根据晚到 wget 自动改成包级模型，也没有宣称进行中状态已包含可识别的命令信息。

## 8. 本轮决定

**保留“有向交互比例＋支撑强度”的具体表示假设，推进到已有开发材料上的信息核验；不恢复 19 维，不推进学习选择器，不立真实训练入口。** 它有严格时钟、有限状态、明确读出、同信息近邻和能否定它的反例，已经超过只有方向名的方案。

尚不能把它定为项目原创主线：其数学来自成熟二阶统计，额外 S 引入事件切分敏感性；目前真实正证据主要是重复 C2，而纯重复恰是方向分支的盲点。只有已到达的多形态先后信息在正常对照中仍有差异，且归一化在同预算、同信息 B／MLP 参照之外有稳定价值，才产生值得进一步讨论的方法贡献。若实际可用历史主要同形重复，或者区分完全来自切流规则，就应结束这个候选；不能再通过追加记忆层、门控或损失挽救。
