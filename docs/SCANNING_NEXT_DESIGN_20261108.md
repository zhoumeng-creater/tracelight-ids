# 第十五轮之后：先检验标签粒度，再决定是否补跨流观测

状态：2026-11-08，**同输入、同支持行的标签粒度三臂对照**已接入正式多类适配器、预检、运行、冷预测、复算与归档入口。执行使用 `scanning-label-lab-v1` 标签和[实验室指南](SCANNING_LABEL_LAB_V1.md)。本机只完成工件分析与合成核查，真实比较留在实验室。

## 当前方向需要修正什么

当前完整 KV 对 Scanning 仍近乎失效，压缩不是这一问题的起点。第十五轮基准、源端口重编号、源端口遮蔽分别检出 3、4、4 / 1078 条 Scanning，均没有恢复旧 54 条，也没有恢复其中 15 条完整输入匹配 P 扫描支持的记录。继续搜索编号、温度或全局阈值，缺少收益依据。

根本问题需要拆成两个可检验的设计前提：**把所有攻击合成一个支持标签，是否让模型丢失了有用的子类结构；逐流输入，是否缺少区分扫描活动与正常通信所需的历史观测。** 先检验前者，因为它可以保持全部输入、支持样本和推理预算基本不变。历史输入作为有条件的下一分支，不与标签对照并行开矩阵。

新的[尾部与支持审计](research_alignment_20261108/scanning_next/tail_findings.md)给出以下依据：

| 发现 | 对设计的含义 |
|---|---|
| P 有 512 条 Scanning；主47模式有89条扫描、11条正常支持；旧54失检中15条具有完整48字段相同的P扫描记录 | “没有扫描支持”不能解释这些行。仍须检验这些支持通过什么监督语义进入模型。 |
| B1中4623条E查询源端口未变，其中4620条分数超容差变化；P中6493/8192行源端口改变 | 第十五轮同时改变了P和查询。目标行分数变化不能全部归因于查询端口，支持上下文也在起作用。 |
| B0主47模式217扫描/33正常的组内AUC仅0.5424；目标服务237扫描/72正常为0.7402 | 不只是不同服务争夺同一个阈值，目标组内部排序也不足。 |
| 只下调B0全局阈值，要检出至少270条扫描，必同时纳入C正常99/5000、E正常298/11830 | 25%扫描检出对应1.98%/2.519%的已观测正常误报代价；严格单调全局校准不能消除这个排序代价。这些边界用于诊断，不登记为新阈值。 |
| 当前C的49条误报来自49个通信组，E的118条误报来自117个组 | 不能把当前高阈值主要归因于C中的一个大重复组。 |
| P原始完整48字段的4096条攻击形成4068组，其中4040个攻击单例组、28个双行组；Scanning/其他攻击混合组为0 | 可以设计不额外制造同输入矛盾的伪标签对照。原有Scanning/Benign冲突为1组，照实保留。实验室仍须在最终FP32输入上复核分组。 |

完整48字段尚不能被判定为信息论上不可分。遮蔽源端口后的47字段冲突，只证明删除信息后的限制；几次模型失败也不能代替完整输入的信息上限证明。

## 唯一优先对照：T0 / TF / TP

沿用第十四轮P8192、正常C5000、E20000的身份、顺序、原48字段最终FP32输入和冻结预处理；沿用第十五轮模型权重、单视图、完整KV、CPU FP32单线程评分、查询批128与模型seed20261107。原始输入与权重绑定沿用[前轮设计清单](research_alignment_20261108/scanning_mechanism/design_manifest.json)。不同时改变源端口、支持行、N、输入维度、骨干或预处理。

| 臂 | 仅在P上使用的标签 | 计数 | 检验作用 |
|---|---|---|---|
| T0 | Normal=0，Attack=1 | 4096 / 4096 | 重放第十五轮B0，要求分数容差一致、逐行判决一致。 |
| TF | Normal=0，Scanning=1，OtherAttack=2 | 4096 / 512 / 3584 | 检验真实扫描族信息经支持标签进入模型的作用。 |
| TP | Normal=0，AttackA=1，AttackB=2 | 4096 / 512 / 3584 | 控制增加类数、类计数和输出归并，区别是否利用真实扫描族划分。 |

TF使用现有P的族标签，增加了监督信息的细度，没有增加样本；不能写成“监督信息完全相同”。C/E只提供48字段供模型查询，族标签仅用于结果分组。三臂均重新构建列级与ICL完整KV，不进行优化器更新。

TP的构造先固定，再由实验室执行：

1. 仅对P攻击行按完整48字段最终FP32值分组。哈希字节采用little-endian float32，将正负零统一为正零；不修改传给模型的原始矩阵。相同攻击输入必须留在同一伪类，避免将28个已知重复攻击对人为拆成矛盾标签。
2. 组键为 `SHA256(prefix || input_bytes)`，其中 `prefix` 为紧凑ASCII JSON `["scanning-label-group-sham-v1",20261108]` 后接一个零字节。按摘要、再按输入字节排序。逐组选择大小不超过剩余512配额的整组，达到512即停止，其余攻击为AttackB。
3. 若不能精确填满，停止并报告，不换种子、不拆组、不补选E表现好的样本。攻击单例组不少于512是本构造成功的充分条件；真实FP32组计数须先核查。
4. 保存P逐行标签、输入组摘要、TF/TP交叉表和冲突审计。TP不强制Scanning在伪类中的比例，不把按组抽样称为逐行均匀抽样。它是一种固定的无族语义划分，不代表所有可能的有意义子类划分。

### 保持最终检测任务相同

所有臂仍判断全攻击与正常。直接使用未加温度的模型logits：

$$s_{T0}=z_1-z_0,\qquad s_{TF,TP}=\operatorname{logsumexp}(z_1,z_2)-z_0.$$

这等价于攻击联合概率相对正常概率的log-odds。不得改用Scanning单类分数、三类argmax、两种分数择优或E上选择权重。二分类路径保留原减法运算；三类采用稳定log-sum-exp，不先截断概率。

每臂只用本臂同一正常C登记既定1%阈值，序位4951、严格 `>`。T0先对第十五轮B0检查C/E逐项分数、阈值与判决：沿用 `3e-5 + 3e-5*abs(reference)` 容差，逐行判决必须一致；失败时不进入TF/TP，也不放宽容差。

## 判读规则与停止条件

本轮E已打开，只作机制诊断。先登记判断，再评分；不按结果更换伪类种子、拆分类别或挑选支持。

| 观察 | 判断与下一步 |
|---|---|
| TF优于T0，却不优于TP | 类数、任意拆分或输出归并仍是解释；不能将改善归因于Scanning族信息。 |
| TF的Scanning检出同时高于T0与TP，整体TP不低于T0、E正常FP不高于T0；同时固定低误报区间的Scanning归一化pAUC高于T0与TP | 进入独立确认的候选门槛。继续报告提升量、阈值余量和其他族得失；小幅跨阈值变化不等于扫描问题已解决。 |
| TF提升Scanning却增加正常FP或损失总体TP | 存在代价，未通过上述候选门槛；不以调阈值或放宽目标事后改判。 |
| TF/TP均无改善，或主47组内仍无法拉开扫描与正常 | 下调此次标签细化解释。复查历史观测可行性后，再决定是否实施下一分支。 |

T0通过逐行判决复现后，整体TP下限为6711、E正常FP上限为118。118/11830是当前E的实测计数门槛，不是总体误报率保证。TF胜出支持“此P族标签细化有用”，不能证明合并标签是唯一根因；TP是随机伪划分，也没有控制所有有意义的攻击子类结构。

主要排序指标固定为：E的1078条Scanning对同一批11830条正常，FPR区间 `[0,0.01]` 的ROC面积除以0.01。相同分数整组处理，区间边界线性插值，沿用第十五轮算法；它是该区间的平均TPR，不是1%端点TPR，也不据此选部署阈值。TF/TP的实际Scanning检出和FP仍须并列：若TF的FP高于TP，即使pAUC更好，也只能称低误报区间平均排序改善，不能称当前工作点以相同误报代价胜过TP。

必须保留：全部C/E逐行logits、联合分数、阈值、本臂 `score-threshold` 余量、成对修复/新增TP和FP；各族结果；全体Scanning对正常、目标服务和主47模式的排序；旧54与其中15条；同输入数值波动与并列情况。不同臂分数尺度不同，原始余量不能跨臂直接比较；另报各自C的分位区间，保留并列范围。保存逐行身份和通信组；P/C/E不含IP与绝对时间，本轮入口明确记录主机/时间块汇总不可用，不从行号或组哈希猜测，后续有逐行元数据时再补分析。不将相关流当独立重复实验。缓存形状、构建/评分时间、部署字节量分别记录，不能由“类数仍不超过10”推断实测资源完全相同。

## 历史观测分支与原创新主线的位置

若标签对照不能提供语义特异改善，下一候选是保留48字段，增加同源IP/协议过去60秒已完成流的数量、不同目的IP数、不同目的端口数、无返回包比例。比较同52维的中心零历史槽与真实历史，并以现有48维B0作为锚；不能仅因真实历史胜过被填零后变差的模型就宣布改善。该分支须由实验室从完整原始流重放，不能用33192条抽样行估计真实扇出。

结束时间只代表最后包时间。该离线分支采用“流结束即可取得完整记录”的可用性假设，严格只读结束时间小于当前时刻的流，同毫秒先读后写；现实部署需使用导出/到达时间。当前随机通信组划分的P含未来时刻样本，所以构造因果历史并不会使整个P/C/E评价自动成为在线因果实验。详见[历史分支约束](research_alignment_20261108/scanning_next/network_context_research.md)。

独立确认必须另冻向前时间P′、C′、E′，先检查标签/样本可评价性，再锁定边界；不通过反复挪边界挑出扫描效果。若该来源的攻击日程无法提供所需支持与未来评价，应登记不可评价，再选择新的确认来源。

此前“校准裕量敏感的KV压缩”降为待验证研究分支。先建立能在低误报工作点利用有效证据的完整KV，再比较其压缩损失与真实状态成本。标签拆分、历史计数和原生多类推理本身不作为创新点；潜在贡献必须体现为：在相同监督、观测信息和成本对照下，更好保留会改变攻击—正常边界的证据。当前不恢复CRT、梯度加权压缩或新的模型矩阵。
