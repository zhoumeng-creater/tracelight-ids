# 第六轮：低误报预算下的压缩与困难攻击保护

日期：2026-11-03。研究版本：**TraceLight research v2**。状态：下一轮开发协议；文中目标均可失败，完成实现、通过 smoke 或写出协议均不表示方法有效。完整研究动机、文献边界和确认数据路线见 [STAGE6_RESEARCH_DESIGN.md](STAGE6_RESEARCH_DESIGN.md)。

第五轮已经打开 UNSW 和修正版 CIC 的 test。本轮设计受既有结果启发，**现有 train/validation 只能产生 v2 开发证据**；旧 calibration/test 不用于新增模型选择、损失参数选择、阈值选择、早停或新模型排名。旧 test 结果保留为 research v1 的已完成结论。把旧数据重新随机划分、换 seed、改文件名或删掉不利样本，都不能重新获得独立确认集。

## 1. 问题、比较单位与可否定假设

主问题：在小网络和受限字段输入下，针对低正常误报区域的训练目标，能否比配平的硬标签与普通蒸馏对照保留更多攻击，且不把总体收益建立在困难攻击家族的明显退化上？

比较单位是同一数据、输入字段、学生结构、seed 和训练预算下的一对模型；不是跨数据集的两个最高分。固定五个训练 seeds：**17、29、43、71、97**。主开发误报预算为 **1%**；0.1% 仅在正常支持数足够时作次要探索，不取代未达到的主指标。

| 假设 | 有意义的反证 | 必须对照 |
|---|---|---|
| H1：普通 KD 的收益超出硬标签类权重变化 | KD 对严格 matched-hard 无稳定收益，或只改善易检家族 | hard、matched-hard、KD |
| H2：拒绝不可靠 OOF 教师能减少负迁移 | gated-KD 对 KD／gated-matched-hard 无改善，或 gate 排除了多数困难攻击仍造成召回损失 | KD、gated-KD、三个gate控制及分层诊断 |
| H3：困难正常流与低分攻击的排序项改善低 FPR 区域 | rank 改善总 AUC 却不改善 1% 工作点，或损害困难家族 | 每种 base 目标的 rank=0／0.1 配对 |
| H4：训练收益在压缩条件下保留 | 收益仅存在于较大网络／全字段，压缩后消失或 CPU 无实际节省 | 本轮同预算大／小网络，以及后续全字段／缩减字段控制 |

H1—H3 先以八条件核心矩阵及三个gate机制控制检验；H4由本轮大／小容量参照和后续字段对照检验，不能由同结构学生自动推出。候选的正面或负面结论必须写明支持到哪项假设。组合有效也不能证明每个组件都有效，更不能仅因组合未见过就声称发明新算法。

## 2. 可执行范围与晋级次序

本轮先验证研究工具和机制，再决定是否值得扩大。当前开发 runner 的范围与完整研究目标分开验收。

| 层级 | 数据与预算 | 可以据此判断什么 |
|---|---|---|
| synthetic smoke | train 上限 400、validation 上限 150；seed 17；最多 2 epochs | 接口、损失、工件和隔离检查；不评价研究效果 |
| 真实 pilot | 现有合法 train 上限 12,000、validation 上限 6,000；seed 17；最多 20 epochs | 可运行性、成本量级、错误与数值异常；n=1 不判定有效 |
| 五种子机制开发 | 完整现有train/validation，不设行数cap；五个固定seeds；最多120epochs | 完整既有开发任务中的方向与训练随机性，不是最终泛化确认 |
| 压缩与机制扩展 | 仅对过闸门的 base 目标增加容量／字段和特定机制对照 | 回答 H4 和进一步归因，单列新增预算 |
| 新来源确认 | 通过准入审计的新数据；确认协议另冻结 | 提供真正新的确认；现阶段尚无此结果 |

cohort_policy明确区分complete_development与bounded_pilot：前者必须max_train_rows=null、max_validation_rows=null，使用完整现有开发分区；后者才允许固定、可恢复的预算子样本。所有配对条件使用相同行和分组，采样不读取旧test，也不因seed结果改样本。pilot保存完整分区与子样本的家族支持、缺失家族、大组排除和身份清单；组不能为凑到精确行数而拆开。

实际配置入口为[research-v2-smoke.yaml](../configs/research-v2-smoke.yaml)、[research-v2-pilot.yaml](../configs/research-v2-pilot.yaml)、[research-v2.yaml](../configs/research-v2.yaml)，训练模块为src/ids/research.py，损失为src/ids/research_kd.py。此入口负责开发训练、逐项损失、OOF与预测归档；本协议另列的CPU三轮、完整机制分析、新来源确认和最终应用验收需各自工件，不能由RESEARCH_COMPLETE.json替代。

本机先用可核验的 UNSW 跑 pilot。第二数据环境只有在本机 prepared 身份与 schema 完整后，才按原准备流程复用；不能临时拿相近 CSV 替代。CIC 与 UNSW 分别拟合，比较的是机制是否可重复，不声称 A 训练后可直接检测 B。

## 3. 八条件核心、机制控制与预算配平

核心学生固定为两层隐藏层[32,16]、ReLU、单输出logit；首个机制矩阵使用本数据环境全部合法字段（UNSW42／CIC82），不同时改字段。容量参照另用[64,32]。初始共同训练预算：AdamW，learning_rate=0.001，weight_decay=0.0001，batch_size=1024，epochs 上限 120，patience=12，min_delta=0.00001。pilot把epochs改为20、patience改为8、教师max_iter改为100；smoke有更小的合成预算。其他实际覆盖值以各自锁定配置为准，完整记录差异，不与正式方案当成同预算比较。

| 编号 | base mode | ranking 权重 | 问题 |
|---|---|---:|---|
| A | hard | 0 | 原有硬标签监督 |
| B | matched_hard | 0 | 控制普通 KD 混合带来的有效类权重变化 |
| C | kd | 0 | 教师软目标是否带来额外信息 |
| D | gated_kd | 0 | 完整正确性／置信门控策略的效果 |
| E | hard | 0.1 | ranking 单独效果 |
| F | matched_hard | 0.1 | ranking 与类权重控制 |
| G | kd | 0.1 | ranking 与普通 KD 的交互 |
| H | gated_kd | 0.1 | ranking 与完整门控策略的交互 |

八条件之外，正式设计增加三个不带ranking的gate控制，以及一个[64,32]large-hard容量参照：

| 编号 | 条件 | 改变什么 |
|---|---|---|
| I | gated_matched_hard | 保留原teacher决定的同一g，soft目标改为y，控制门控逐行权重 |
| J | gated_correct_only | teacher方向正确且置信过门槛时g=1，区分连续置信权重的作用 |
| K | gated_confidence_only | 置信过门槛即使用其连续权重，不滤除错误teacher，区分正确性过滤 |
| L | large-hard [64,32] | 全字段、相同hard与共同优化预算的容量参照 |

12个MLP条件×五seeds=**60次MLP拟合**。加TabM为13个条件、**65次主拟合**。同一结构的配对共享初始化；large-hard与TabM结构不同，不宣称权重逐项相同。同一seed的同结构MLP学生重置相同RNG、相同初始权重和DataLoader顺序；OOF 生成消耗的随机状态不能改变初始化。优化上限、早停指标、数据行、预处理和 CPU 测量相同。不同早停轮数如实报告，不能声称优化步数完全相同。

TabM是独立近期模型对照，固定五seeds时占上述5次主拟合；它不是相同参数量的 MLP 消融，不用于归因 KD。仅在其 adapter、依赖和 schema 检查通过时进入矩阵；否则记录失败原因，不用普通 MLP 替代它。

现阶段先固定上述参数，不根据 pilot 的一条曲线开始搜索。若确需调整，先写入版本化 amendment：每个目标使用相同公共学习率候选集合 {0.0005,0.001,0.002}、相同数据和候选数上限；alpha、gate、rank 若另搜索，单列搜索账本及相应控制，不隐藏在公共预算内。失败、OOM、重启和弃用配置同样记账。单个方法多试几倍参数后胜出，不能直接解释为方法收益。

本轮[64,32]large-hard与[32,16]hard的同预算比较，是容量压缩证据；旧第三轮工件只作历史参照。字段扩展先固定“全字段／MI24”一对，不自动铺满多个字段数和所有机制的笛卡尔积。若普通 MI 在当前数据更合适，保留它，不为维持“稳定选择创新”强行使用已失败机制。

## 4. 训练内交叉拟合与教师身份

每个学生seed生成一套**3折OOF**教师目标，共15个辅助HGB拟合；另有每seed一个全train HGB reference，共5个参考拟合。两类合计20个教师拟合，与65次主拟合分开记账，即每个数据环境最多85次本轮计划拟合（不含pilot、失败和后续搜索／字段扩展）。全train reference不生成自身训练行的蒸馏目标，也不混入OOF。两套环境分别执行时为170次计划拟合，但这些数字是预算账本，不是研究贡献。若确定性 HGB 的不同 seeds 产出相同目标，公开相同性，不把重复拟合当成更多独立证据。经验证的同一套OOF可在同seed的C/D/G/H/I/J/K复用，复用不得抹掉原始生成成本。

固定 fold_seed=**20261103**。折划分只在本轮固定 train 样本内，用 StratifiedGroupKFold、3 folds、shuffle=True。优先使用已审计的关联会话组；仅有完整字段哈希时按该哈希组隔离并明确不能证明真实会话独立。每折的教师训练部分必须同时含正常与攻击；稀有家族不保证每折存在，保存实际支持数。

每折的填补、编码、缩放、特征选择及类别权重只在该折教师训练部分学习；不能先在全 train 拟合教师预处理。HGB 采用既有明确参数（200 迭代、31 叶、learning_rate=0.1、early_stopping=False）并记录有效参数。每条 train 记录恰由未见过其组的教师生成一次分数。

OOF 表至少绑定 sample_id、label、feature_hash、group、fold、teacher seed、教师训练／预测行身份、数据与代码哈希。逐项检查完整覆盖、无重复未知 ID、有限 [0,1] 分数、教师 fit/heldout 组交集为空；学生按身份而非盲信行序对齐。学生预处理器在完整本轮 train 学习是合法的，与折内教师相互独立。

q 是 class-balanced 教师的攻击得分，不是校准的真实攻击概率；OOF 只防止教师直接拟合该记录，不证明教师可靠或外部泛化。全 train 的教师参考分数不能冒充 OOF 质量。

## 5. 明确的损失定义与归因限制

本轮固定temperature=1，alpha=0.5，默认gate_policy=correct_confidence。p=n_normal/n_attack 只由本轮固定 train 计算。令 hard 行损失 h_i=BCEWithLogits(z_i,y_i,pos_weight=p)，soft 行损失 s_i=BCEWithLogits(z_i,q_i)，二者按全部 batch 样本数取均值，不按有效 gate 数重新归一化。

- hard：mean(h_i)。
- matched_hard：把普通 KD 的 q_i 严格替换成 y_i，其余混合完全相同；temperature=1 时有效攻击权重为 (1-alpha)p+alpha，正常权重为 1。
- kd：mean((1-alpha)h_i+alpha s_i)。
- gated_kd：mean((1-alpha g_i)h_i+alpha g_i s_i)。
- gated_matched_hard：g_i仍由真实OOF教师决定，但s_i改为BCEWithLogits(z_i,y_i)；其他系数完全相同。它不是先把teacher改成y再重新算gate。

gate 定义为 g_i=1{教师得分方向与 y_i 一致}×1{|2q_i-1|≥0.5}×|2q_i-1|。方向用 q_i>0.5／q_i<0.5 判定，q_i=0.5 时 gate=0。错误或低置信教师回退原 hard，不删除该行。这里的“正确”只是训练标签与教师 0.5 得分侧一致，**不是最终低 FPR 阈值上的正确性，也不是经过概率校准的置信**。

ranking 在当前合法 train batch 内，对 detach 的学生分数选最高分正常流（normal_fraction=0.1，至多32条）和最低分攻击（至多64条），至多2048对。对每个选中 normal n、attack a 使用 softplus((0.5+z_n-z_a)/1)。加权 0.1 后加至 base 损失。无合法正负对时记 0 并保存原因；离散选取不反向传播，选中 logits 的排序损失仍参与梯度。若提供合法 group_ids，双轴按选中组平衡；否则是选中样本均值，报告所用模式。

这只是有界的 batch hard-negative ranking surrogate，**不等于精确优化 population pAUC 或保证 FPR≤1%**。normal_fraction=10% 也不能解释成 10% 部署误报率。对数值字段、模型得分、标签的处理分别审计，不能混用。

三个正式gate控制分别保持其余条件不变：correct_only在方向正确且|2q-1|过门槛时g=1；confidence_only对两种方向都按过门槛的|2q-1|赋权；gated_matched_hard保留默认同一g但q=y。D-I用于排除逐行hard权重解释，D-J与D-K辅助区分连续置信与正确性过滤。它们仍是本轮指定策略的机制证据，不代表穷尽所有门控设计。ranking 若有效，也需用同数目的随机 normal／attack 配对排除纯额外正则和计算量效应；此控制不应偷偷替换主矩阵。

每 epoch 保存 hard、soft、各自加权贡献、ranking 原项／贡献、总损失、gate 激活率／均值、教师错误率、selected normals/attacks/pairs、有效组数和跳过 batch 数。所有MLP目标统一用validation的原hard weighted BCE早停；TabM遵循官方逐head的hard weighted BCE并独立记录，不能当作同结构损失消融。不能让新方法独享更有利的指标；额外报告低 FPR recall 随 epoch 的开发曲线，不能据曲线后验换 best_epoch。

## 6. 指标、开发阈值与继续研究门槛

每个模型在本轮固定 validation 正常样本上用同一经验阈值规则确定 FPR≤1% 的开发工作点，保存阈值、正常分母及 FP；边界并列使实际 FPR 更低时也报告。重复使用 validation 已产生选择偏差，不提供独立确认。

主要量是该工作点的攻击召回，并列实际 FPR；主比较为C-B（软信息）、D-C（完整门控）、D-I／D-J／D-K（门控机制）以及E-A／F-B／G-C／H-D（ranking）；小hard-A对large-hard-L另回答容量取舍。同时报告全部家族 TP/支持数，不仅报改善的家族。预定重点：UNSW Exploits、Fuzzers、Reconnaissance；CIC Botnet、Portscan、Infiltration - Portscan、DoS Slowloris、DoS GoldenEye。这是 v1 启发的 v2 开发重点，不假称事前未知。

次要量：每家族召回与宏平均、最差家族召回、precision、Macro-F1、average precision、ROC-AUC，以及预先声明定义的低 FPR pAUC。正常样本不足、某家族缺席或极少时直接给计数与宽区间；不把未定义当零，不用数百万相关行声称独立样本充足。0.1%档至少要求validation有20,000条正常流且仍须给不确定性；有足够总行数并不保证有足够正常流或独立组。

按同 seed 算差值，公开五个原值、均值、样本SD与范围。五 seeds 仅反映固定分区上的训练随机性；计时重复不增加训练 seeds，训练 seeds 不增加独立采集环境数。存在可用会话／场景组时补组配对 bootstrap；不具备时不冒称群体推断。多项主比较并存，未做预定多重比较处理前不以单个 p 值挑选成功故事。

以下是**继续投入的开发闸门，不是显著性或非劣效证明**：

1. 完整性／隔离／数值检查全部通过。
2. 相对对应简单控制，平均 1% 工作点召回提高至少0.5 pp，至少4/5 seeds 方向为正；重点家族平均下降均不超过1 pp，且单 seed 下降超过5 pp须显式失败分析。支持不足的家族不能据此判定受保护。
3. 若总召回未提高但困难家族宏平均提高至少2 pp、总召回下降不超过0.5 pp，可保留为明确的另一取舍候选，不能改称主假设成功。
4. 不通过时最多一次预先记账的机制诊断／公共预算复查；仍失败就停止该分支，保留 hard／matched-hard。不能不断调 alpha、gate、阈值或家族名单直到过线。

## 7. 资源目标和实际部署范围

部署时只加载学生与其预处理器，不加载 OOF 教师、gate 或训练 ranking。相同结构的 hard/KD/gated/rank 参数量相同，训练机制本身不能被写成进一步压缩模型。完整计入 OOF 和额外排序训练时间、峰值 CPU RSS／GPU显存；缓存后的训练秒数不能冒充完整方法成本。

压缩晋级目标：相对本轮配平大网络，学生学习参数至少减少50%；相对相同后端全字段模型，输入压缩至少减少50%原始字段。两者分别报告，UNSW42→24不满足后一个目标，不能换用编码维度冒充。实际存储／CPU目标为模型与预处理包缩小至少30%，或单线程预处理加推理p95降低至少20%，同时保留明确的检测取舍；未达到即如实报告。

同机 CPU、threads=1、无竞争任务，全部候选做三轮轮换次序测量，保存单条p50/p95和batch256吞吐、冷启动、包字节、RSS及原始观察。可复用此前计时方法，但新模型必须重测，不引用 v1 速度冒充 v2。增加另一台普通CPU复测后才能扩大硬件结论。

现有模型级计时不含原始包特征计算。应用验收另外计 CSV读取／校验、预处理、推理、结果导出、界面首次反馈；未实现PCAP一致提取前只承诺可信流特征CSV。字段数减少不直接证明特征提取成本下降。

## 8. 新确认数据与旧结果的保留

新来源准入与审计路线见研究设计第6节。数据准入不等于已获得可用新test。当前不新增“最终测试”命令：先完成开发和来源审查，再另写冻结计划，确定样本支持、切分、候选、seeds、置信区间、校准阈值算法、保护家族与停止条件，最后只开一次新确认批次。

旧 UNSW/CIC test 不作为新增方法的盲验证。若仅对其展示新模型分数，必须另标“已见数据的回顾性探索”，并且不能进入新的确认主表；当前轮次默认不运行这项探索。v1 第五轮的模型、阈值、错误案例、报告与原始归档保持不变。

## 9. 交互与视觉系统验收

视觉不是装饰性附加页。系统须让用户完成三项真实操作：

1. 同一CSV在两个已生成模型之间比较；输入行数、分区、run_id、字段／模型版本始终可见，可定位同一条分歧、误报或漏报；无标签时不显示准确率。
2. 点击实际测过的模型点，联动召回／实际FPR／p95／包大小及家族得失；不在离散模型间插值生成“连续性能”，不能把回放速度当推理速度。
3. 从一条事件追溯原始字段、分数、阈值、来源与哈希，导出同源证据。开发阈值探索与冻结确认分开，冻结视图不提供重新挑主阈值的操作。

文件错误可解释、长任务进度真实、可取消、不重复计数、结果可导出；默认离线运行，普通CPU可完成。检查390px窄屏、投影可读性、键盘路径、减少动画设置和浏览器控制台。成功、误报、漏报各保留实例；不伪造IP、时间、网络拓扑、攻击概率或实时流量。

## 10. 工件与阶段停止条件

每次执行绑定代码提交／dirty状态、源码指纹、依赖、配置、数据清单、固定子样本及OOF身份；保存所有seed、训练history、损失分量、逐条开发预测、阈值、家族计数、CPU原始测量与失败记录。新方法、旧协议及历史报告分目录，不覆盖第三至第五轮。

阶段完成分别表示：工程链通过；五种子开发覆盖；机制证据支持／否定；压缩和部署证据；新来源确认。完成标记不自动代表方法有效。测试隔离失败、关键元数据不可信、训练异常未解释、困难家族系统性退化、连续固定预算无稳定收益时暂停扩展并修正论证，而不是继续增加run数。

发布前须由实际 runner 的 help/dry-run、合成 smoke、真实小样本 pilot 及返回工件复核证明支持范围。本文中的后续机制控制、新来源确认和最终应用验收，只有对应实现与工件完成后才可标记完成。
