# 算法 v3 设计稿：带正常误报修复信用的风险预算蒸馏

版本：设计 v3.1，2026-11-03。状态：**目标、代理、优化步骤与反证对照已定稿到原型层；核心代码和合成检查已实现；真实数据效果、主张的新颖性和正式实验室入口尚未验收。** 本文将算法设计、实现与效果分开记录。真实训练仍在实验室 RTX 4090D，本机只做文献、代码、单测及合成检查。

**后续原文／代码审查更新：** [逐项成果对照](research_alignment_20261103/README.md)确认完整“修复信用”表达与锚条件 hinge／截断 hinge 等价，不能作为独立新机制；旧正确区域保护、双源指导及约束学习也有更直接近邻。当前 v3 按受约束蒸馏候选／机制研究原型定位，不把下述公式命名成原创学习原理。

## 1. 本次重新设计了什么

研究对象仍是已提取网络流特征的二元检测：在固定小 MLP 的部署预算下，从合格教师获得收益，同时控制低误报工作点的退化。v3 将训练核心从“教师在 0.5 处正确且置信高，再加 batch 难例排序”，改为**相对同容量 hard 基线的显式错误预算**。

三个具体变化：

1. 使用冻结 hard 基线作为决策锚，区分新增正常误报、修复原有误报、丢失原攻击检出和新增攻击检出。
2. 正常风险使用“新增误报上界−保守修复信用”；攻击保留单列约束，新增检出不能抵扣原检出的丢失。
3. 迁移教师相对其工作点的 margin，并依据完整约束训练总体更新对偶系数；不再把偏离 score=0.5 当成可靠性，也不将 batch top-10% 排序叫精确 1% FPR 目标。

部署仍只有小学生、预处理与最终阈值。基线、教师、家族标签、风险池与对偶状态不进入推理必要路径。需要实测才能确认训练开销和部署成本；本轮没有新的 IDS 性能。

## 3. 数据角色与教师／基线

| 角色 | 来源与用途 | 允许参与什么 |
|---|---|---|
| F：fit | 现有原 train 中的一组完整关联单元 | 教师训练／折内 OOF，基线 hard 训练，学生 hard／KD |
| R：reference | 原 train 中与 F、C 隔离的一组单元 | 冻结基线／各折教师的训练参考阈值及尺度；不作 hard 训练 |
| C：constraint | 原 train 中另一组完整单元 | 所有学生共同的 hard 监督，以及候选风险梯度、对偶更新、可行性检查 |
| V：validation | 现有开发 validation | 开发选型与选轮；不是新独立确认 |
| Z、H | 另行审核、未使用的新来源 | 将来独立校准与确认；本轮不读取、不调参 |

F、R、C 必须恰好覆盖所声明的原 train，不能隐性丢弃巨大组。分区先冻结样本身份，防止 exact-feature 与会话联合关联跨角色。CIC 优先使用 `group_id` 的联合传递闭包，不能只按 feature_hash 重做 OOF。每个角色报告缺失攻击族及最大组；不保证“每族每角色都有”，也不为达到这一外观拆散会话。

**C 已参与训练，不能再叫独立审计／风险证书。** 所有学生对照都获得同一 C 的 hard 标签、同样的可见特征和计算预算，排除额外监督量造成的假增益。教师和基线仍只在 F 拟合；R、C 不得先混入全 train 产生 OOF 再切回来。

教师先通过强参照／低误报资格检查，首个可执行研究可用固定 HGB；TabICLv2 等合格后再定向换教师，不同时改教师和机制。OOF 每折只拟合 F 的其余组，预处理、上下文、表示与缓存亦折内生成；该折在 R 的正常分数确定自己的训练工作点。FC 普通 KD 与 OOF 普通 KD另作定向协议比较，不把合法 FC 监督一概称泄漏。

基线 B 是与候选学生同架构、同预处理、预先冻结的 hard MLP；学生从 B 的权重初始化。继续训练的 hard 对照也从同一 B 开始、看到同一 F∪C，拥有相同更新预算。基线初始拟合成本及教师辅助拟合全部入账。

## 4. 分数、工作点与尺度

令 $z_B,z_S$ 为基线与学生的原始 logit。训练参考阈值 $t_B$ 在 R 正常样本上冻结，默认 $t_S=t_B$；学生权重可以更新，阈值不随 batch 重估。允许冻结尺度 $s_B>0$，初始原型取 $s_B=1$：

$$
a_i=\frac{z_B(x_i)-t_B}{s_B},\qquad
m_i=\frac{z_S(x_i)-t_B}{s_B},\qquad
B_i=\mathbf1\{a_i\ge0\},\quad S_i=\mathbf1\{m_i\ge0\}.
$$

教师的折内 score logit 记为 $z_T$，其 R 参考阈值和尺度为 $t_T,s_T$：

$$r_i^T=(z_T(x_i)-t_T)/s_T,\qquad q_i^T=\sigma(r_i^T/T).$$

$q_i^T$ 是软报警目标，不是校准攻击后验。类平衡 HGB 的原 score 也不是部署后验。教师 score=0/1、阈值超出可表示范围、概率裁剪和标准化必须由未来 adapter 显式处理并记录；不能把无穷 threshold 裁成有限值制造有效教师。R 的尺度标准化作为独立分支，不能让学生通过实时重算尺度悄悄改变预算。

原型提供 raw-logit 工作点的保守冻结：允许 $\lfloor\alpha n_0\rfloor$ 个参考误报，对下一个不允许的分数取 float64 nextafter，并统一先转 float64 再减阈值／比较，避免阈值被 float32 标量运算舍回并列边界。它没有完成 HGB／TFM 的正式 margin adapter。保存重载后的 CPU sigmoid 分数与 float64 阈值比较，可能与 raw-logit margin 受饱和影响，正式接入时仍须单独核验。

## 5. 核心：不对称风险预算

取固定 $\kappa>0$，定义锚间隔尺度

$$d_i=\max(|a_i|,\kappa).$$

### 5.1 正常误报：新增上界与修复信用

$$u_i^+=(1-B_i)[1+m_i/d_i]_+,\qquad
\ell_i^-=B_i\operatorname{clip}(-m_i/\kappa,0,1).$$

当学生新增报警时 $m_i\ge0$，$u_i^+\ge1$；$\ell_i^-$ 只在学生修复基线报警时才可为正，且不超过真实修复事件。因此对全部正常样本或一个事先声明的正常分层 $g$，

$$
\widehat{\mathrm{FPR}}_{S,g}\le U_{0,g}
=\frac1{n_{0,g}}\sum_{i:y_i=0,g_i=g}
\big[B_i-\ell_i^-+u_i^+\big].
$$

约束 $U_{0,g}\le\alpha_g$。分母为该分层**全部正常行**。实现按逐行非负包络求平均，避免将 baseline rate 与另一个均值相减引入数值抵消。关闭修复信用的必要消融为 $\ell_i^-=0$。

正常池默认只设 pooled FPR 约束；若要增加分层，必须预先定义真实环境或可解释粗分层，并有足够正常支持。重复 hash 只用于隔离与集中度诊断，不给每个相同特征组直接设 1% 约束。所有同特征确定性预测组的硬 FPR 只能取 0 或 1，这样做会把任务变成已见模式零误报。

### 5.2 攻击检出：丢失上界，不用新增 TP 抵扣

$$v_i^-=B_i[1-m_i/d_i]_+,\qquad
U_{1,f}=\frac1{n_{1,f}}\sum_{i:y_i=1,f_i=f}v_i^-.$$

约束 $U_{1,f}\le\epsilon_f$，其中分母是该族全部攻击，$\epsilon_f$ 是该族召回率绝对损失预算。于是

$$\widehat{\mathrm{TPR}}_{S,f}\ge
\widehat{\mathrm{TPR}}_{B,f}-U_{1,f}.$$

新增 TP 不进入信用项，避免用容易样本的挽救抵扣原有检出的丢失。pooled 攻击与有支持家族均可列约束，但家族不参与推理。若锚在某族全漏，则保护项恒为零：这是没有可保留检出，不能称保护成功；必须报告实际召回、基线 TP 个数和无保护标记。

### 5.3 边界与可行性

- 稳定锚样本 $|a_i|\ge\kappa$ 在学生初始化 $m_i=a_i$ 时相关新增／丢失代理为零；弱边界样本可能有正 slack，必须保留并报告。减掉初始 slack 会破坏硬事件上界。
- `fixed` 消融取 $d_i=\kappa$。两种代理在锚处 slack 相同，离开锚之后互不全局支配；不能预写 adaptive 更紧或更好。
- 正常修复信用使问题一般非凸；神经网络也非凸。标准原始—对偶更新不提供本方法全局收敛或必然可行的结论。
- $U$ 是经验代理上界，可大于 1，不把它画成预测概率。独立性不是点态界成立的条件，却是许多总体统计保证的条件；这里不作后者主张。
- 阈值、尺度、成员或分母改变后须重新计算。最终重新校准阈值会改变翻转事件，训练期约束不会自动延续。

一个必须承认的不可兼得例子：同一特征在 C 中同时有正常和攻击标签，锚对两者都报警。若要求正常零误报且不丢失这条攻击检出，任何只看该特征的确定性学生都无法同时满足。风险设计不能消除输入不可辨识性；实际训练未达约束时应检查这类冲突，而非默认扩大网络或提高预算。

## 6. 完整训练目标与求解

令 $N=N_F+N_C$，所有学生共享的 hard 项为

$$L_H=\frac1N\sum_{i\in F\cup C}
\operatorname{BCE}_{w_+}(z_S(x_i),y_i).$$

教师只为 F 提供样本外信号：

$$L_T=\frac{T^2}{N_F}\sum_{i\in F}
\operatorname{BCE}(m_i/T,\sigma(r_i^T/T)).$$

这里 BCE 的第一个参数指 logit，原型使用 `binary_cross_entropy_with_logits`。硬标签项系数保持固定，教师项以 $\beta$ 加入，避免门控同时悄悄缩小 hard 权重。

设计问题为

$$\min_\theta L_H+\beta L_T\quad\text{s.t.}\quad
U_{0,g}\le\alpha_g,\quad U_{1,f}\le\epsilon_f.$$

使用有界原始—对偶原型，记所有约束为 $c_j=U_j-b_j$：

$$\mathcal L=L_H+\beta L_T+\sum_j\lambda_j c_j,\qquad
\lambda_j\leftarrow\operatorname{clip}(\lambda_j+\eta_\lambda c_j,0,\lambda_{\max}).$$

计算学生梯度时 detach $\lambda$、教师、锚；更新对偶时 detach 完整 C 报告。使用原始 $\lambda c$，不截为 positive-only penalty。对偶达到上限且仍违规，需要标“本次未达约束／对偶饱和”，不提高预算直到通过。非凸启发式没有找到可行迭代，不能证明不存在可行解。

求解顺序：

1. 冻结数据角色、教师、基线、阈值、尺度、约束名称／分母／预算、初始化与 batch 计划。
2. 构建完整 C 的 risk reference，保存身份和内容签名，记录锚 slack、真实计数及初始可行性。
3. 初版每个 macro-step 对完整 F 与 C 累积一次目标梯度，再统一作一次 optimizer step。可分块计算，但块间不更新权重／对偶；每块分别除全局 $N$、$N_F$ 或相应约束分母，最后统一检查／裁剪梯度。该更新是 warm-start 后的全总体微调，不冒称沿用了旧 minibatch 训练算法。
4. 用当前同一组权重完整重算 C，各组不可因本 batch 缺席而被视为零风险。然后更新对偶，记录新 FP／修复 FP／丢失 TP／新增 TP、代理与实际值。
5. 预定正式选轮规则：所有条件先满足 C 的实际硬事件预算和 V 的实际 FPR 预算；v3 另需完整 C 的代理约束通过。对合格者按 V 攻击召回最大、V 误报最少、最早 step 的顺序选轮，全程使用各自已冻结的训练阈值，不在每轮 V 重调阈值。没有合格 checkpoint 就报告“本次未找到”，不能证明无可行解。原型检查脚本仅保存最后一步，明确是否曾可行，不执行此正式选轮。
6. 新来源确认阶段，固定模型后独立校准并封存阈值，再评价新 test 实际 FPR／召回；同时重算新阈值下的师生分歧。该阶段尚未实施。

组装目标时，F／C 的 hard 均值按人数加权，soft 单独乘 $\beta$，不能将整个 F 返回值一起乘 $N_F/N$：

```python
common_hard = (n_fit * fit_parts["hard"] + n_constraint * constraint_hard) / (n_fit + n_constraint)
total = common_hard + beta * fit_parts["soft"] + risk_lagrangian(full_report, dual.weights)
```

正式分块／随机约束求解器尚未接入。分块须与完整合成数据的 loss／梯度逐项对齐；若改为随机按类／组抽样，必须给已知采样概率与全局分母修正，另立算法版本和对照。当前 API 明确拒绝把任意短 batch 当完整 reference。梯度有限性必须单独检查，不能只验证 loss 有限。

## 7. 原型参数与必要控制

初始开发建议：同架构 `[32,16]`，$\beta=0.3,T=1,\kappa=0.05$（冻结 margin 单位），$\eta_\lambda=0.1,\lambda_{\max}=100$；正式正常目标 1%，攻击丢失预算初始候选为 1pp。它们是待预算／支持审查的初值，不是已证明最优配置。小家族允许损失数必须按支持取整并事先说明，不在结果出来后放宽。

合成检查使用更宽误报目标以便有限样本有事件支持，不能当 1% 研究。正式配置、角色分配、OOF 与优化器预算冻结后才进行真实训练；C 大小、攻击支持、normal 独立单元与上下文成本先审查。

**G1a 最小五条件，固定一个教师／学生／环境、三种子，共约 15 个学生 fit；辅助教师和锚另计：**

| 条件 | 作用 |
|---|---|
| H：共同 F∪C hard 继续训练 | 排除额外 C 标签、继续训练和初始化收益 |
| K：H＋工作点 KD、无风险项 | 测附加工作点 soft 项的联合效应；K−H 尚不区分教师信息和正则／权重效应 |
| R：H＋风险项、无 KD | 检查是否只是受约束 hard 训练有效 |
| M：H＋风险项＋标签替代的同系数 soft 项 | 排除教师软信息其实只是有效类／样本权重变化 |
| V3：H＋风险项＋工作点 KD | 完整候选 |

M 保留相同阈值、温度、训练步数与 soft 系数，只将 soft target 换成 $y$。$T=1,t_S=0,s_B=1$ 时，F 行的有效正类权重可解析计算，C 的共同 hard 项不变；非零阈值／其他温度时必须比较完整目标，不能用一个全局常数类权重冒充。若要进一步识别无风险时的教师独立作用，再追加无风险 matched-soft 条件，不将 K−H 直接归因于教师。

**G1b 只有 G1a 留下未解释差异才追加：** adapted EKD、PCT／Focal Distillation、成熟 CVaR-pAUC，以及 fixed hinge、关闭正常修复信用、普通概率 KD 对照。近邻适配须公开其二分类变换，并共享监督、学生、预算和评价；这些对照完成前不主张方法优于近邻。再按证据定向换强教师或加入有支持家族，不做全部因素笛卡尔积。

可否定设计的结果包括：R 与 V3 无差异、M 足以解释 V3、constant hinge 或关闭信用同样好、同预算 pAUC／EKD 更好、C 可行但 V／新来源超预算、基线全漏家族仍全漏、真实成本不值得。上述情况均保留原始结果，并撤销对应机制／效果主张。
