# UNSW 全字段 small 普通 KD：独立设计与反证审查

2026-11-05。审查对象为 `research/mechanism-20261105` 的普通 KD 最小受控方案。已核对仓库 `AGENTS.md`、`docs/INPUT_EXTRAPOLATION_RESULTS_20261105.md`、`docs/research_alignment_20261105/teacher_content_review.md`、`configs/budget-transfer-screen.yaml`、`src/ids/budget_transfer.py`、阈值与 pAUC 实现。本审查没有训练、打开 V/test 或修改原实验结果。

## 1. 本轮能回答什么

固定 UNSW 全字段、现成 all-small seed17 warmup、现成 full-F all HGB 教师和 40 次全 F 梯度更新，检验：**保留输入与教师概率的对应关系，是否比硬标签续训、保留概率边际但破坏对应关系的控制、类别条件平均软化产生更好的低误报检出。**

这一问题值得做 4 次续训。已有全字段教师 F 上的 mean `|q−y|=0.0428883`，在 λ=0.3 的归一化混合目标中对应平均目标变化 `0.00989731`，最大完整特征模式只占总 `|q−y|` 质量的 0.301%。目标没有退化成完全硬标签，也没有被一个模式包办。教师含有错误，尤其困难攻击族的目标偏移较大，不能把全部软化质量叫作有效知识。

本轮只识别这个固定起点与预算下的续训效果。它不回答从随机初始化开始的 KD 是否有效、OOF 是否优于 full-F、温度或 λ 的最优值、CIC 能否获益，也不构成最终部署验收。

`teacher_content_review.md` 中 UNSW 全字段教师救回 1,955、新增漏报 179 的比较对象是 hard24。该数字不能替代全字段教师对 all-small hard 的实际比较。工件代理本轮核实：full-F all HGB 的 C 为 TP14,448/FP76，历史 all-small hard（原续训第 25 步被 C 选中）为 TP13,969/FP78；教师救回 730、新增漏报 251，净增加 479 TP，并净减少 2 FP。救回和反向损失同时存在，且历史第 25 步模型不能代替本轮固定第 40 步 H 对照。

## 2. 四臂及同尺度目标

全部臂使用同一个原始全字段预处理器、small `[32,16]` 网络及 warmup 网络状态，保持原输入。教师采用现成 full-F all HGB 的原生 logit，固定 `q_i=sigmoid(z_teacher,i)`，`T=1`、`λ=0.3`。教师和学生具有相同输入信息，不能把结果解释成额外字段的收益。

设 F 中二分类标签为 `y_i`，每类行数为 `N_y`，采用现有代码的类平衡权重 `w_i=1/(2N_y)`，四臂均最小化 `sum_i w_i BCEWithLogits(s_i,r_i)`：

| 臂 | 目标 r | 唯一改变 | 主要解释 |
|---|---|---|---|
| H：hard | `y_i` | 无软目标 | 控制同起点继续训练本身的收益 |
| K：raw KD | `(y_i+0.3q_i)/1.3` | 保留逐输入教师概率 | 普通 T=1 KD 候选 |
| S：固定置乱 KD | `(y_i+0.3q_perm(i))/1.3` | 破坏允许置乱部分的输入对应关系 | 控制类别条件概率分布与软化量 |
| M：类别条件均值 | `(y_i+0.3mean(q\|y_i))/1.3` | 移除类内教师概率差异 | 控制使用 F 标签的类别条件平滑 |

在 `T=1`、相同逐行权重下，K 的目标与 `[BCE(y,p)+0.3 KL(Bern(q)||Bern(p))]/1.3` 的梯度完全相同，只差与学生参数无关的常数。这是普通 KD 的归一化写法。`0.3` 是 KD/hard 的相对权重，归一化后 KD 系数是 `0.3/1.3≈0.230769`，不是把传统凸组合中的 alpha 误写为 0.3。

现有 `_backward` 先做一次全 F hard 前后向，再做一次全 F KD 前后向；它没有除以 1.3。因此旧 raw_kd 同时改变总目标尺度和梯度前向行数，不能直接作为四臂公平实现。新四臂均用混合目标一次前后向，hard 也重跑。四臂相同的前向行数、优化器更新数和精度比“每臂同样 40 轮”更明确。即使 AdamW 对全局梯度缩放近似不敏感，也不能据此忽略 epsilon、梯度裁剪和数值精度的差异。

建议在训练前用合成输入验证混合 BCE 与归一化 hard+KL 梯度一致；无需在真实数据上拟合来验证代数关系。保存四臂目标、权重和 F 行身份的 hash，确认 teacher 分支无梯度、没有 pAUC 或 rank 辅助项。

## 3. 置乱控制的可识别性

优先采用**完整 feature-pattern 的 `(n0,n1)` 计数向量分层置乱**：

1. 由 F 的完整特征模式定义分组，每个模式内验证教师 q 恒定。
2. 记录每个模式的正常/攻击行数 `(n0,n1)`。
3. 只在计数向量相同的模式间，用冻结的单次排列交换模式级 q；同一模式的全部行使用交换后的同一个 q。
4. 对模式 ID 和分层键采用固定排序，以 `SeedSequence([17,353])` 初始化随机数生成器；每层先随机排列模式，再循环移位 1 位以分配来源 q。非单模式层没有模式自映射，同值 q 仍可能数值不变。保存排列与目标 hash，一次生成后所有 40 次更新复用，不逐步重抽，不尝试多次排列择优。

这种置乱保留每个标签下按行计数的 q 边际、类平衡加权边际和“相同输入对应相同教师概率”。逐行标签内置乱也能保留边际，却会给重复的相同输入制造相互冲突的教师目标。模式级控制减少了这个额外噪声来源。

分层越严格，可置乱覆盖越小。必须在训练前报告：模式/行覆盖、单模式层、相同 q 导致的实际不变比例、未改变模式占原 `|q−y|` 质量的比例、类平衡加权 `sum w_i|q_i−q_perm(i)|`、逐标签边际是否逐元素相同。若最终目标数组完全不变，S 没有识别能力，应停止这个方案并记录原因；不得仍将 K≈S 写成输入对应关系无用。若只扰动部分模式，K 对 S 的结论应明确限定在可交换部分，不能推广为所有 F 输入信息都被移除。

工件代理已在本轮训练前核实此控制可行：逐行标签内置乱会使 4,770 个模式、41,175 行出现同 x 异 q，占 F 的 47.9247%；计数向量分层置乱可覆盖 82,940/85,916 行，即 96.5362% 的 F 行和 98.3163% 的目标偏移质量。最终冻结的随机排列后循环移位构造实际改变 82,045/85,916 行的 q，即 95.4944%。逐标签 q 多重集合严格保持，同 x 同 q 也保持。这里的覆盖说明 S 确实施加了广泛干预，不能拿来表示效应已经出现。

M 使用 F 的真实训练标签计算二分类均值，属于类别条件平滑控制。混合标签模式的正常行和攻击行可能因此获得不同的 r，这是该监督规则的定义；M 不是一个仅凭输入输出 q 的部署教师。它只保留类均值，不保留概率方差、熵或每行软化量。K 同时优于 S 和 M，可排除部分“仅靠类均值软化”解释；不能将一次控制比较写成对全部 KD 机制的证明。

## 4. 起点、更新预算与终点

| 项目 | 冻结值 |
|---|---|
| 数据 | UNSW 原始全字段；F/R/C 沿用现有固定角色，禁止改变行身份 |
| 教师 | 一份现成 full-F all HGB；记录模型、F 原生 logit 和角色 manifest hash；不重训、不试 OOF |
| 学生起点 | 一份现成 all-small seed17 warmup；四臂逐参数 hash 相同 |
| 优化器 | 每臂重新创建 AdamW；lr=0.001、weight_decay=0.0001，空状态 |
| 训练单位 | 每步遍历全部 F，chunk=2048 累积梯度，完成全 F 后才更新一次 |
| 更新 | 40 macrosteps；每臂 40 次 optimizer.step；无早停 |
| 裁剪 | 全 F 梯度累积完成后 clip_grad_norm=10；记录是否触发 |
| 线程/精度 | threads=4；网络/参数 float32，logits 转 float64 后与 float64 目标及权重计算 BCE；不开 AMP |
| 主要 checkpoint | 唯一固定终点 step40 |
| step0 | 只审计共同起点、预处理和分数一致性，不能作为择优候选 |
| 训练次数上限 | 4 次续训；新增教师 fit=0，新增 warmup fit=0 |

F 有 85,916 行。每臂梯度前向行数为 `40×85,916=3,436,640`，四臂合计 `13,746,560`，不再加入第二次 KD 全 F 前向。精确 FLOPs 和墙钟时间仍应如实记录；相同行数不等于不同硬件的相同耗时。

现有 warmup 使用 40 个 minibatch epoch，每 epoch `ceil(85,916/1,024)=84` 次更新，总共 3,360 次更新。续训的 40 个全 F macrosteps 只有 40 次更新，两者不能统称“40 epoch”。本轮复用 warmup 的历史成本应单列，不能把“新增成本低”写成“从零训练只需 40 次更新”。

选择现成 warmup 的理由是回答固定起点上的教师增量，并用最低新增 fit 数排查机制。直接改成 from-scratch 会同时改变起点和优化轨迹；若按 minibatch 训练，更新数又从 40 变为 3,360。from-scratch 问题需要单独冻结训练单位与总预算，本轮不追加。

现有 `_fit_method` 对 step0–40 做 41 次 C 选择，并按 `(C TPR,C pAUC,-C FPR)` 挑 checkpoint。本轮改为 step40 唯一终点，训练过程只保存 F loss/梯度/预算日志，R/C 的 step0 与 step40 用于审计和最终比较。不得在看到结果后改用最佳历史 checkpoint 或延长到 80 步。

固定起点、全 F 梯度累积、固定排列且无 dropout 时，只改 continuation seed 通常没有新的随机因素，不能算独立重复。后续若需要 seed29/43，必须分别训练其独立 warmup、每个 warmup 再共享给四臂；这至少新增 2 次 warmup 和 8 次续训，必须另立协议和预算，不在本轮自动启动。即使这些 seed 独立，它们仍复用相同 F/R/C，不构成新数据泛化证据。

## 5. 阈值与 pAUC 的唯一口径

每个固定终点模型独立计算 R 正常和 C 正常的保守经验阈值，取二者最大值。沿用实现：允许 FP 数为 `floor(0.01×N_normal)`，使用边界分数的 float64 `nextafter(+inf)`，决策为 `float64(raw_score)>=float64(threshold)`。R 有正常 3,920、攻击 8,354 行，C 有正常 7,840、攻击 16,707 行，对应 R 最多 39 FP、C 最多 78 FP。教师、旧模型和四臂的阈值来源必须分别标明，不能混用 R-only 和 R+C。

四臂各自重定工作点才能在相同低误报预算下比较。直接把旧 logit 阈值套到新网络，会混入不同分数尺度的影响；该做法不能作为普通 KD 的主要验收。

主结果为固定终点、各自 R+C 阈值下的 TP/FN/FP/TN、TPR、FPR。并列报告 R/C 的 raw pAUC 和 McClish 标准化 pAUC，积分区间固定 `[0,0.01]`。标准化 pAUC 的随机对角线为 0.5，完美排序为 1；它既不是 raw 部分面积，也不是工作点 FPR 保证。

R/C 正常参与工作点确定，C 又已在既往 warmup 和研究决策中反复使用，所以这里的低 FPR 是经验开发指标。固定 step40 取消本轮 checkpoint 搜索，不会把历史使用过的 C 变成独立测试集。

## 6. 建议冻结的推进与停止规则

建议把下面条件预先写入机器可读协议，结果回来后逐项填 pass/fail。这里的数值是新一轮的工程推进门槛；现有 screen 的 `qualification_min_tpr_gain=0.002` / `qualification_min_pauc_gain=0.002` 原本判断教师 headroom，不能冒称已经是学生成功标准。

### 6.1 有效执行

四臂起点、F/R/C 行身份、目标和预算 hash 符合冻结清单；各完成 40 次更新；无非有限数值；没有 V/test 访问；没有额外损失、checkpoint 搜索或追加候选。任一条件失败，记为实施失败，先定位错误，不解释为 KD 有效/无效。S 目标完全未变则记为控制无识别能力，停止将其当反证依据。

### 6.2 相对 hard 的可用性

- C 的净 TP 增益至少 `ceil(0.002×16,707)=34`，对应至少 0.2 个百分点 TPR。
- C 标准化 pAUC 不下降；R 的 TPR 与标准化 pAUC 不下降。浮点指标比较使用预先固定的绝对容差 `1e-12`，不把容差当质量退化空间。
- R/C 各自 FP 均不超过 `floor(0.01×N_normal)`，且相对 H 不净增 FP。
- R、C 中每个有支持的攻击族，K 相对 H 的净 TP 均不下降。所有族均列实际支持数和事件数；没有支持的族标记不可评估，不能算通过。

这允许同一族内存在“救回 A、失去 B”的变化，因此不是沿用裁剪的零新增 FN 原标准。新训练允许改变决策边界，但必须逐族列出救回 FN、新增 FN、新增 FP、修复 FP，不能只展示净值。该门槛表明本轮尚未接受攻击族间的性能交换；若未来愿意接受交换，应在新结果之外另行明确成本函数，不能为了通过本轮改门槛。

### 6.3 逐输入教师信息的增量

为避免“一条样本领先”触发下一轮，建议 K 相对 S、M 分别也满足：C 净 TP 增益至少 `ceil(0.002×N_attack,C)`，且 C 标准化 pAUC 不下降。四臂使用同一个阈值算法，但每臂阈值各自计算。

若 K 通过相对 H 的门槛，却未通过相对 M 的门槛，则报告“相对类别条件均值控制的增量未达到预定质量门槛”，不据此将收益归因于输入相关教师信息。门槛未通过也可能是净 TP 增加 33 而非 34，或 pAUC 下降，不能直接写成“均值软化解释了全部收益”。同理，K 对 S 未过门槛不等于两臂没有数值差异。若所有软目标臂都不通过相对 H 的推进门槛，本固定方案停止，不搜索温度、λ、OOF 或辅助损失来补救。

### 6.4 收益集中与代价

对 K−H 的全部 TP 变化，按现有 `feature_hash` 精确重复组列净变化、救回、新增漏报、最大正贡献组比例。UNSW 的归档身份只有 sample_id、feature_hash、label、attack_cat，feature_hash 就是本次分割使用的完整特征模式单位，没有可复用的 group_id，不能借用 CIC 的联合组概念。删除 C 中最大正净贡献 feature_hash 组后，剩余组的净 TP 仍须为正，作为继续扩大资源投入的条件；计算时固定已得到的阈值，不在删除组后重新校准。该分析检查收益是否由一个精确重复模式包办，不是独立泛化检验。

四臂相同架构、相同预处理应具有相近部署成本。按最终主协议，模型包不超过 H 的 1.05 倍；质量门槛通过后，再按既定混合交替测量流程比较 K 与本轮 H：batch1/256 的每个既定测量块中，p95 不超过 H 的 1.25 倍。沿用既定 warmup、块数和重复次数，不能看到抖动后挑最快块。实际部署包只包含学生模型和原预处理器；教师不进入推理路径。

质量失败即可停止后续成本测量，节省实验室时间。质量通过但成本失败，不宣称完成轻量化目标；先区分测量误差、序列化/加载差异和真实推理开销。

### 6.5 三种结论

| 结果 | 可写的判断 | 后续动作 |
|---|---|---|
| K 未通过 hard 可用性或攻击族/误报条件 | 本固定普通 KD 续训方案未取得可接受的开发收益 | 停止本配置；报告收益和伤害，不自动扩矩阵 |
| K 通过 hard，但未通过 S/M 增量 | 相对控制的增量未达冻结质量门槛，尚不能据此归因于输入相关教师信息 | 保留具体差值；不自动宣称 KD 成功或追加 seed |
| K 通过全部质量、对照、组集中与成本条件 | 固定 seed17、固定起点和预算下，存在值得重复的开发信号 | 允许撰写下一阶段独立 warmup 多 seed 协议；新训练仍需另冻结 |

单 seed 的事件差异应按行、模式和组描述。一次固定置乱不是置换检验；把大量重复行当独立样本的 McNemar 或 bootstrap p 值不能解决依赖性。即使另做合适的组级统计分析，显著性也不会抵消 C 的历史选择或替代新来源确认。

## 7. 必须保存的结果与易错点

保存一份共享 step0 和四份 step40 模型及原始 R/C 分数、唯一终点的 threshold JSON、混淆矩阵、逐族/feature_hash 精确重复组事件表；保存 F 目标及 q 统计、teacher/anchor/preprocessor/row-ID/permutation hash、40 步损失与裁剪日志、实际更新时间和前向行数。四臂加载后核对起点网络状态及预处理 hash，共享 step0 只评分一次。R+C 每次共 36,821 行，共享 step0 加四个终点评分共 184,105 行。

重点防止以下误读：

- 把现成 warmup 的 C 选择隐去，将固定终点称为独立验证。
- 把 40 macrosteps 与 40 minibatch epochs 混为相同训练预算。
- 把旧 hard、旧 raw_kd 或 direct 模型作为本轮公平对照，忽略尺度、计算量或 pAUC 目标差异。
- 把某个全字段教师对 hard24 的 headroom 贴到 all-small 基线上。
- 将 full-F 训练内教师概率当作 held-out 软目标，或把实际数组相同的 OOF seed 当作教师稳定性重复。
- 用全局净 TP 掩盖稀有族损失，用相同 FP 总数掩盖新出现的正常误报事件。
- 把 K≈S 一律解释为实例信息无用，未检查 S 到底扰动了多少目标。
- 通过换 continuation seed 制造形式上的重复，或在 seed17 出现好结果后自动扩成多 seed 矩阵。

- [TabTune 论文（2026），§4.4](https://arxiv.org/html/2605.18654v1) 报告的表 4 中 hard AUC 0.863，高于其完整 KD 的 0.829。它支持保留等预算 hard 基线，不能把其数据集上的结果当成 UNSW 结论。[固定版本的作者 MLP 实现](https://github.com/Lexsi-Labs/TabTune/blob/5c014e2aaf48da4c6b9dfda1f5364dfb04d4776e/tabtune/distillation/students/mlp_student.py#L440) 含额外自适应温度/平滑设计，本轮不照搬这些因素。
- [2026 年 KD 正则化重审预印本，§8](https://arxiv.org/html/2611.01065v1) 提示固定末轮下的 KD 优势可能被 CE 早停或无教师平滑解释。本轮据此保留 matched hard 与类别条件均值控制，并明确只问固定 40 步效果。它也提示：将来若要主张“最佳可调训练方案更强”，必须另作对等选择预算比较；当前固定终点实验不能替代那个问题。
- [NeurIPS 2025 TabArena 官方论文](https://proceedings.neurips.cc/paper_files/paper/2025/hash/1697e3fb412da11dc9488249f9e7bbc9-Abstract-Datasets_and_Benchmarks_Track.html) 与[固定版本的验证协议实现](https://github.com/autogluon/tabarena/blob/2bf318ef1ccc0b549e91e03081c258e7bbee6d26/packages/tabarena/src/tabarena/benchmark/validation_protocol.py#L331) 强调区分开发选择和后续评估。本轮只取消新的 C checkpoint 搜索，保留其开发集身份。
