# 2026 年加密控制通信独立验证

TQH-C2 v1.2.5 的 48 个实验单元覆盖 Sliver/TLS、Merlin/QUIC、Mythic/HTTP 和 Merlin/HTTP2-TLS 四种配置。每个单元包含同时采集的正常背景和受控攻击。研究者按实验拓扑给连接打标签，`malicious_c2` 包含信标和任务下发。B、D 两组使用相同的 Merlin 框架。Deokjo Jeon 和 DongGue Park 以 CC BY 4.0 许可发布数据。采集时标和标签口径见[固定版本](https://zenodo.org/records/23905375)和[作者说明](https://zenodo.org/records/23905375/files/README_v125.md?download=1)。

本批把 48 个单元登记为 X 组。所有模型沿用 IoT-23 训练和正常校准得到的参数与阈值。测试时，每个单元从空历史开始，以原始 `conn.log` 的物理顺序计算已有的 60 秒历史。分析逐个单元核对正常误报和控制通信的新增、丢失。多个单元可能复用实验拓扑，48 个单元不等于 48 个独立真实网络。

| 作者标签 | 行数 | 项目判读 |
| --- | ---: | --- |
| benign | 124,295 | 正常背景 |
| benign_external | 460 | 正常外部通信，原类别单列保存 |
| malicious_c2 | 27,130 | 单列 ExternalC2，可用于评价加密控制通信 |
| malicious_recon | 880 | 单列 ExternalRecon，位于 Mythic 试验床；该标签未区分端口扫描 |

作者标签没有标明哪条连接传输了恶意文件。本来源可验证后续时段的控制通信，下载和扫描仍分别依赖有对应标签的来源。

两份作者压缩包合计 33,262,326 字节。只需 `TQH-C2_labels_v110.zip` 和 `TQH-C2_labels_D.zip`，它们已包含原始 Zeek 字段、标签和采集记录。准备程序校验整包 SHA-256，并在每个单元中检查两份日志的 UID 唯一、双向完整匹配。每条记录按连接日志的顺序编号，标签顺序可以不同。UID、地址和作者标签均不进入预测特征。每个单元的输入摘要及起止时标已[登记](../../configs/response-evidence-20261112/tqh.json)。

本机实际读取了全部 152,765 行，每单元有 207 至 12,710 行。按完成时标，首末记录为 UTC 2026-06-29 06:09:02.326 和 2026-07-23 17:08:15.951。TQH 部分连接的持续时间细到微秒以下。程序直接把原始十进制起始时间与持续时间之和向上取到毫秒，再按物理顺序取累计最大值。若先取整到微秒，30 个单元中共 67 条记录会早一毫秒。48 个单元均已通过盲输入构建、独立历史构建与逐行身份核对；真实模型评分留在实验室。[核验记录](tqh-source-validation.json)
