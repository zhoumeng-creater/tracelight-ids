# 第五轮 · 冻结模型的最终校准与测试

本协议依据第四轮 validation 结果确定四组模型。实验室首次打开保留集前，固定模型、数据分区、阈值算法、比较方向与报告口径。第四轮的模型、预处理器和选择字段直接用于推理。完整机器配置见 [protocol.json](../workflows/stage5/protocol.json)，操作见 [实验室指南](STAGE5_LAB.md)。

## 固定比较

| 数据环境 | 候选 | 参照 | 同 seed 的差值回答什么问题 |
|---|---|---|---|
| UNSW-NB15 | 42 字段小 MLP，`05-mlp` | 42 字段 RF，`00-rf` | 使用相同原始字段，小网络相对森林的检测与部署取舍 |
| 修正版 CICIDS2017 | 普通 MI24 小 MLP，`04-mlp` | 82 字段小 MLP，`03-mlp` | 使用相同网络隐藏层和训练规则，缩减输入字段后的检测与部署取舍 |

两种环境各自在本数据集上训练过模型。每组包含种子 17、29、43，四组共 12 个既有工件。每个均保留其从第四轮 train 学得的状态。所有种子进入报告，差值始终为本行候选减参照。模型字节、原始字段数和吞吐等比例用候选除以参照。两个环境的比较问题不同，分别给出结论。

正式入口核对 Git 发布提交、依赖版本、第四轮计划与完成记录、实验室原数据清单和每个入选模型的 SHA-256。第四轮原训练代码指纹为 `233644d9d52d2d785a4de3ebca007dc34ada11cbd6c323876af3848eb779aaa5`。第五轮把新评估代码、环境、数据和 12 个候选的身份写入 `STAGE5_PLAN.json`。合成数据用于软件测试，正式入口只接受上述已核验的真实材料。

## 校准与开封顺序

两阶段均用单线程 CPU 推理。每个既有模型只对其 calibration 分区的正常流量评分，保留原分区顺序，并保存正常样本 ID、分数和阈值。设正常样本数为 $N_0$，允许误报数为 $K=\lfloor 0.01N_0\rfloor$。取正常分数从高到低的第 $K+1$ 项，使用其向正无穷方向的下一个 float64 作为阈值。得分大于或等于阈值时判为攻击。边界并列时，实际误报数可能少于 $K$。

核验全部 12 份校准记录后，统一写入 `THRESHOLDS_LOCK.json`，随后写入 `TEST_STARTED.json` 再读取 test。在第一次测试后，恢复操作只核验并接续同一计划、模型、样本与阈值。测试误报率可能超过 1%；保留实测的误报数、正常分母和误报率，并在报告中标出超预算的模型与种子。此时按原方案报告结果，维持锁定阈值和比较对象。

## 分母、敏感性与报告

- **主要检测量**是锁定阈值下的攻击召回率，并列报告 test 的正常误报率。保存逐样本分数、预测标签、混淆计数、precision、Macro-F1、AP、ROC-AUC 和各家族的检出数/总攻击数。家族检出指某家族的流量被识别为攻击。分母很小时显示实际计数，已知家族在某子集缺席时标明零样本，召回率记为未定义。
- **配对**使用同一数据集、评价范围和种子对应的两份结果。报告三个配对原值，再报告固定三种子的算术平均与样本标准差。检测差用百分点表示，未定义的指标保留为空。三次训练共用数据分区，推论限于已观察到的模型随机性。
- **UNSW 重复敏感性**同时列出全体 test 和非重叠子集。子集排除在原训练 CSV 派生的 train、validation 或 calibration 中出现过相同完整 42 字段哈希的 test 流量。准备阶段已审计 82,332 条 test 中有 8,541 条重叠，涉及 1,302 个字段组，预计非重叠子集 73,791 条。两组模型复用同一掩码、同一套各模型阈值。UNSW 来源在清单中保留为未与官方散列独立比对的镜像。
- **CIC 修正版**报告原分组隔离 test 的全体结果。数据准备时已隔离完整字段重复和按双向五元组重建的关联会话。它检验同一采集环境中留出分区的表现。训练家族集中在大组、某些家族测试支持极少或缺席，均在解释结果时保留。
- **部署成本**引用第四轮同机、单线程 CPU 的模型文件字节及预处理加预测计时。各 seed 的 p95、256 行批吞吐均先取原三轮的中位数。部署成本与此次保留集检测指标各有来源。
- **案例展示**可沿用第四轮 validation 中带样本 ID 的命中、漏报及误报，界面明确标注数据分区。第五轮 test 按全体结果报告；从 test 查看单例只能说明该固定模型的一次判定，不能据此挑选展示方案、改字段、重新校准或筛选种子后重报最终结果。

## 验收

12 份阈值须先于 test 统一锁定，12 份测试预测、指标与完成记录均须通过绑定校验。随后生成两环境配对报告和带内部文件清单的 ZIP，再重读每个成员校验 SHA-256。运行完成取决于既定程序和证据完整性；检测收益和误报预算是否达到预期，交由真实数字回答。


### 发布前工程验证

2026-11-03 使用两套独立合成数据和 3 个训练种子贯通第四轮工件到第五轮报告。此工程演练缩小了训练规模、选择预算和第四轮计时重复数。第五轮实际处理 12 个合成模型，从返回 ZIP 中逐份重算校准阈值、1,548 条测试判定、总体指标与 UNSW 子集指标，均与保存值一致。包内含清单共 68 个条目，恢复后 ZIP 的 SHA-256 保持一致。另对真实第四轮归档执行输入绑定检查，核对 12 个模型身份和部署成本；这一步仅读取开发工件及清单。正式 calibration 和 test 留待实验室运行。
