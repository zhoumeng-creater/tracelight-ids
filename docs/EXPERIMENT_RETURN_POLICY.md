# 实验结果回传规范

2026-11-22 起，日常回传统一按本页执行。

**只回传本轮、本次执行生成的完整结果包。不要每轮重新制作或发送包含全部历史轮次的 `TraceLight-ALL-*.zip`。**

本页取代实验室旧 README 中“对外只提供一个总包，每轮完成后重建／更新它”的日常回传约定。后续执行者和代理不得继续按该旧条款追加历史包。

## 每次发送什么

| 内容 | 处理方式 |
|---|---|
| 本轮脚本生成的结果 ZIP | 原样回传一次，使用本次执行对应的包 |
| 本次生成的旁置校验文件 | 与对应 ZIP 一起回传；包内清单和校验记录一并保留 |
| 本轮新增、未包含在 ZIP 内的运行说明或错误记录 | 单独附上，或只与本轮 ZIP 合并为交接包 |
| 以前已经回传的各轮 ZIP、报告和模型 | 不重复发送；历史原件继续保留在实验室及既有归档 |
| `TraceLight-ALL-*.zip` 累计包 | 用作完整备份或迁移，不作为每轮默认回传件 |
| 整个项目目录、虚拟环境、下载缓存和旧原始数据包 | 不额外加入结果包；新增必需材料以该批次已冻结的清单为准 |

“完整结果包”指**本轮结果完整**，不是整个项目的全部历史。不得为减小体积删去该轮规定保留的模型、逐行分数／预测、身份、配置、阈值、训练记录、成本记录或失败证据；只保留摘要或哈希不能代替这些原件。

若本次失败，只整理本次已经生成的输出、错误记录和工件，不夹带旧轮次，也不为生成一个“完成包”自动重训。

## 当前九次固定比较

当前入口为 [RUN_CALIBRATION_REFERENCE.ps1](../scripts/RUN_CALIBRATION_REFERENCE.ps1)，运行方法见[实验室说明](CALIBRATION_REFERENCE_LAB_20261122.md)。脚本只压缩 `-Output` 指定的本轮目录，完成后生成同名 ZIP。例如：

```text
本轮输出：D:\Research Work\results\normal-reference-transfer-v2\
应回传：  D:\Research Work\results\normal-reference-transfer-v2.zip
```

这个包须保留本轮九份模型及全部规定结果。发送它即可，不要再把它加入 `TraceLight-ALL-<日期>.zip` 后发送，也不要压缩上一级 `results`、`archives` 或整个 `Graduate` 目录。

当前脚本会在本轮输出中生成 `output_receipt.json`；不要把它误认成独立的整包 SHA 文件。其他批次若生成了旁置 `.sha256` 或 `.sha256.json`，按其原协议随包发送。

实验室导航 README 的旧“总包”条款应同步替换为：

> 日常只回传本轮自动生成的结果包、本次已生成的校验文件及本轮新增说明。历史累计总包留作备份，不随每轮重复回传。
