# v4 固定协议：先辨明目标退化，再检验可行更新

2026-11-04。依据为[v3真实回传复核](RISK_V3_RESULTS_20261104.md)及[近期原文／作者项目审查](research_alignment_20261103/risk_v4_literature_audit.md)。本轮是机制修正研究，代码实现不表示新算法有效，也不构成原创性证明。真实运行仍由用户在实验室4090D拉取GitHub版本完成。

## 1. 本轮检验的三个解释

1. CIC的报警margin soft target退化：正常样本99.63%被映射到约0.5，EKD三阈值重合。普通raw-logit KL是否消除这一目标问题，而非仅减小β？保留legacy目标作同起点对照。
2. 工作点漂移还是排序损失：所有候选同时报告冻结原anchor阈值与候选自身R阈值。主评价采用后者，阈值只来自R正常行，V不参与阈值选择。
3. 代理过紧还是实际更新越界：所有方法采用共同实际事件预算评价；guard检查真实AdamW提议后的完整C，代理值保留作诊断。

**这是明示的新协议。** v3的risk额外代理准入判据保持原结论，不能用v4口径追认旧失败模型。v4不要求代理全部可行，也不能宣称解决了原代理优化问题。R重校准本身可能解释结果；需要与固定阈值指标一起报告，不能把校准收益归为KD创新。

## 2. 数据、身份与不变的实际预算

只读复用完整v3的F/R/C/V身份顺序、各seed三折教师目标和锚点模型；每次核验旧v3全部文件哈希、plan、prepared清单、train/validation文件、角色行身份。只加载可信的本人封存joblib；不拟合新教师／锚点，不读calibration/test，不重新prepare，不cap或重新分角色。

原v3的1%正常FPR、1%攻击lost-TP mass、C支持≥30的家族启用规则保持完全相同，配置不同会被拒绝。攻击损失始终相对**原v3锚点**的TP集合，分母为该族全部攻击行；不换成warm start TP集合，不用救回样本抵扣丢失。C未覆盖家族继续明确未保护。计数准入使用 `count <= floor(limit * support)`，不能用epsilon放行一个本不允许的事件。

旧v3锚点的C事件从保存的预处理／模型、原训练设备和原GPU阈值重算；候选验收采用实际CPU原始logit路径。R校准也使用CPU原始logit的float64比较，消除概率转换及float32阈值回cast。旧教师诊断中的FPR=1错误只修新计算代码，旧包保持原字节。

## 3. 共同起点和八个控制

先检查原锚点在本轮R校准后是否满足完整C实际预算。若不满足，执行最多30个完整F+C hard AdamW步，选择**第一个C实际可行状态**；整个Phase-I不读V。找不到则该seed的八个条件全部记 `no_feasible_start`，不启动后续训练、不改变限值。Phase-I步数与耗时单独记账。所有条件重置相同AdamW，从同一份warm state出发。

| 条件 | 额外目标／操作 | 用途 |
|---|---|---|
| hard | 无 | 同监督的必要简单控制 |
| legacy_boundary_kd | 原v3的中心化BCE目标 | 检验退化目标，不能冒充完整v3复现 |
| legacy_ekd | 原v3 rank-count目标／阈值网格 | 检验重复阈值及工作点效应 |
| raw_kd | 标准Bernoulli KL，raw teacher→raw student | 正确坐标的简单蒸馏控制 |
| balanced_raw_kd | KL按0.5×两类均值 | 区分样本混合比例影响 |
| guarded_hard | hard＋完整C更新门禁 | 排除“只是接受过滤”的解释 |
| guarded_raw_kd | raw KD＋同门禁 | 检验教师信息在相同门禁下的增量 |
| guarded_balanced_raw_kd | balanced KD＋同门禁 | 检验均衡与门禁组合，仍是已有机制适配 |

raw KD不减任何报警阈值。复用旧clip后的OOF raw logits，使本轮不同时更换教师；明确保留该置信度截断。HGB原来以balanced sample weight训练，不能称自然流量已校准后验；逐折权重和学生F+C权重分别记录，不假设其完全一致。暂不加入另一个未经控制的先验修正。

hard按完整F+C样本数求和归一并使用相同positive_weight；soft只在F，row KL除以全F，balanced KL为0.5×(normal sum/N0+attack sum/N1)。分块和分折不改变分母。β=.3、T=1与步数预先固定；两类均值改变mixture和尺度，不称等价权重。首步记录完整hard/soft梯度范数、夹角与final-bias分量；BCE熵常数造成的大loss不再被当作梯度证据。

## 4. AdamW后置接受的实际实现

guard从已检查可行的状态开始。先保存参数、optimizer moments／step、grad与Torch RNG，再生成完整AdamW提议。在CPU计算该候选R阈值及完整C所有实际事件预算；回调不访问V。依次检查原位移的1、1/2、…、1/256倍，接受第一个可行候选；全拒绝或异常则完整恢复原状态。

当前**缩小参数位移，但接受时保留完整提议的AdamW moments与step**；这与重新用较小learning rate执行AdamW不同，日志明确记载该惯例。拒绝时不会保留被拒提议的动量。每个提议额外CPU forward、试次、位移及无位移接受都记录；不声称Armijo下降或收敛。代码检查回调不得修改模型／optimizer／grad；临时CPU模型构造不消耗训练RNG。

接受保护仅限当前自适应训练C的经验事件；不是总体FPR、未来流量、未知家族或独立风险证书。R阈值是候选的一部分，单独变更阈值也会改变C事件。有限回溯可能全失败，安全保持不等于有效升级。若没有真实参数移动、只选step0或TPR无改善，必须如实报告。

## 5. 选轮、失败与CPU工件

所有八条件用相同准入：完整C实际预算＋主R阈值下V FPR≤1%。step0进入候选集合；合格候选按V TPR最高、FPR最低、最早步选取。门禁不使用V，选轮才读取V。每步同时保留固定旧阈值的兼容性结果与v3代理诊断，不能挑有利口径。

保存CPU学生模型、同序V逐条原始logit／阈值／判定、history、共同Phase-I和教师退化诊断、源码快照及旧v3完成标记哈希。新ZIP不重复复制旧教师/锚点，不代表新结果可脱离原v3来源审计。只有完整工件可resume验收，半程不可续训且不覆盖。

pilot：两环境均使用完整旧cohort，seed17、八条件各30步；每环境最多8学生，没有新教师/锚点拟合，但有Phase-I和旧模型查询成本。full：3seed、每条件60步，最多24学生/环境。**先看pilot的机制、可行起点、回退率和成本，不直接扩大训练。**

## 6. 仍未解决的研究要求

本轮八条件优先验证明确失效机制。成熟CVaR-pAUC、经过相同预算调参的强表格教师/学生、正式CPU重复资源测量、真正未使用来源的独立确认仍是缺口。不会把普通KL、重新校准或参数回溯命名成新颖损失。

若raw KD不优于hard，或guarded hard解释全部收益，就撤回KD增量主张；若R重校准已解释全部改善，则贡献定位为工作点／验证协议修正；若guard几乎全拒绝，则如实报告没有获得升级。论文创新性须由后续真实证据和近邻差异支撑，当前不宣称达到。
