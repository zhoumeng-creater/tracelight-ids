# 25 条 C 的独立核阅

2026-11-19。核阅 `calibration/assemble_c_candidates.py`、`summary.json`、全部 38 个候选、原 proxy/backend 访问日志及冻结解析器；未修改脚本、未运行模型。

结论：**保留 25 条 B 级正常模型记录的准入。** 脚本按完整物理 TCP 首末包构造覆盖整秒的请求包络，检查全部代理 actor；没有仅挑下载请求秒或最近请求。13 个候选因其他/VPN actor 被排除，25 个保留项的完整包络均只有作者正常内部员工 2/3。每个后台请求身份都有代理候选，代理请求身份也有后台候选；不以一个正常下载动作直接替整连接贴标签。

25 个物理 ID、25 个模型 ID 均唯一，关联 21 个动作。主分配 F=santos、V=fox，C=russellmitchell；三个来源 run 不重合。F/V 网络行仍待物化，所以当前证明的是身份分配无共享，最终训练表还须按这个已固定规则连接，不能将 russellmitchell 行补入 F/V。C 并非 25 次独立实验，不给独立二项总体保证。

发现一个具体计数差异：packet17775 的完整包络有 86 条 proxy、85 条 backend 请求；按请求 identity 多重集核对，多出一个正常员工的 `GET / HTTP/1.1`、302 代理记录，未出现多出的后台请求。脚本检查的是 identity 候选集合覆盖，不保证逐事务一一配对。因该宽包络内所有 actor 均正常，且所有后台请求均有正常候选，此差异不推翻 B 级正常标签；文稿应保留候选覆盖表述。

解析器按方法、解码路径、查询参数、HTTP 版本与状态构成 identity。服务日志来自官方完整轮转，文件 SHA 与已冻结值一致。当前源文件可以支持这一有依据的业务子集标签；它没有逐字节恢复 HTTPS，也没有证明全网正常流量。
